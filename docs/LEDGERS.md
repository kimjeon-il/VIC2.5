# 관계 원장 규약 (S0-POP v1.0)

## 공통 규칙

기본 식별자는 `pop_id`, `employer_id`, `asset_id`, `account_id`, `firm_id`, `region_id`, `good_id`, `month_index`, `transaction_id`이다. 금액은 최소 화폐 단위의 64-bit 정수, 수량은 고정소수점 정수로 처리한다. 모든 외부 입출력에서 단위 스케일을 명시한다. 코드는 아직 스케일 자체를 지정하지 않는다.

| 원장 | 주된 키 | 원본 상태·사건 | 현재 코드 |
|---|---|---|---|
| Employment | pop·employer·profession | 고용 인원·임금 | 기초 기록/집계 |
| Ownership | asset·owner | 소유 지분 | 발행·이전·보존 검증 |
| Financial | account, transaction | 경제주체별 차변·대변 | 균형 분개/잔액 |
| Inventory | holder·region·good | 물품 재고 | 초기·생산·소비·이전 |
| Production | firm·recipe·month | 투입·산출·폐기 | 미구현 |
| Order/Trade | buyer·seller·good·month | 주문·체결·대금·재고 이동 | 미구현 |
| Fiscal | government·taxpayer | 세금·보조금·급여 사유 | 미구현 |
| Demographic | pop·cohort·month | 출생·사망·이주·직업변화 | 일부 함수만 |
| Health | pop·cohort·month | 부상·치료·회복·장애 | 전투상태 함수만 |
| Military | unit·cohort·month | 징집·포로·전투손실·제대 | 미구현 |
| Political | pop·interest group·month | 지지·권리·영향력 | 후속 |

## 고용

동일 POP는 여러 회사에 노동자를 제공할 수 있지만 총 고용 인원은 해당 시점의 적격 경제활동인구를 넘을 수 없다. 분할/병합 시 계약을 인원과 함께 분배한다. 현재 `EmploymentLedger`는 기록/합산과 인구 상한 *조회*까지만 제공하며 자동 채용/임금결정은 구현하지 않았다.

## 소유와 배당

`발행 지분 = 전체 소유지분의 합`. POP, 기업, 정부 등은 소유자가 될 수 있다. 고용주와 소유자는 별개다. 배당은 결산 이익 자체가 아니라 금융 원장의 실제 지급(현금·예금 이전)에 의해서만 주주 소득에 반영한다. 지분 가치와 예금은 다른 자산이다.

## 복식부기 (부호: 차변 + / 대변 -)

각 **거래의 경제주체별 분개 합이 0**이어야 한다. 자산·비용은 차변 정규잔액, 부채·자본·수익은 대변 정규잔액이다. 은행이 신규 대출 100을 실행한 경우 예시:

| 경제주체 | 차변 | 대변 |
|---|---|---|
| 은행 | 대출채권 +100 | 고객예금부채 +100 |
| 차입 POP | 예금자산 +100 | 대출채무 +100 |

신용창출로 은행예금 총액이 늘어날 수 있으므로 `총통화량 일정` 대신 분개·예금 대응·기관 대차대조표를 검증한다. 은행 예금과 고객 예금 청구권을 서로 다른 화폐로 중복 합산하지 않는다. 대출 원금 상환은 비용이 아니라 자산·부채 감소로 기록한다.

## 실물 재고

`기말재고 = 기초재고 + 생산 + 유입 − 생산투입 − 최종소비 − 유출 − 손실`. 현재 코드의 `InventoryLedger`는 단순 초기/생산/소비/이전만 구현했으며 복합 생산 레시피나 운송 중 재고·폐기 원장은 아직 없다. 지역 간 운송을 추가할 경우 `in_transit` 보유자를 통해 위치와 소유권을 추적한다.

시장 주문은 실제 거래와 구별한다. 미체결 주문만으로 재고와 자금을 이전하지 않으며, 체결된 상품수량과 대응 대금은 동일한 거래 ID로 연결한다.

## 정합성

동일 사건을 Employment, Financial, Fiscal, Trade 원장에서 각기 기록해도 금액과 인구를 중복 발생시키지 않는다. 과세·이전지출의 사유는 Fiscal에, 돈의 이동은 Financial에 기록한다. 원장 하나에서 값이 바뀌면 파생 집계가 자동 무효화되어야 한다(구현 예정).
