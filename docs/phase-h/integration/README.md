## 4. 통합 결정의 핵심

- **단일 정본/전원장 원자성:** 국내 법/국가·정부는 C-P, 상품·금전/세관은 C-E/G, 무력교전·군인은 C-M/POP, 주권·Claim은 E, **조약·국제협력체/외교협상·국제위기는 H**, 영향력·기구 결속·위기 위험은 파생 조회.
- **국제협력체:** 헌장/다중회원·실제 총회 의결/기금·공동관세/방위 조항의 합법 집행. 회원권=산업보너스/참전권 아님.
- **영향력:** 기업 투자·무역/부채·군사지원·교류→원본 실현→A→B 비대칭 영향력 자동 산출. 세력권 편입/수치 증감 버튼 없음.
- **국제위기:** E 영토/국가/정치·무역/군사/조약 갈등의 원인 사건→다자 교섭·중재·부분합의/동결/재개→필요시 실제 C-M5 전쟁. 긴장도 100 자동 전쟁 없음.
- **시간·자원:** 월 m stage9 조약·법률/권한 변경은 기본 m+1 stage0 발효, 실제 금융/수송·군/주권은 별도 사건. 미래 전망과 실제 결과는 사유/불확실성이 포함된 툴팁으로 설명한다.
- **미지원은 미지원으로:** 현재 브랜치의 G/H 신규 C++ 구현, F 독립 물류, 일부 E 공간/국제기구 자금·실시간 긴급전쟁은 문서만 있다고 실행 가능하다고 주장하지 않는다.

## 5. 후속 실제 구현·검증 순서

1. HV-L0: 코드를 통합한 실제 기준선 선정·원본소유/중복 계약·12단계/9a~e·10a~f 충돌 감사, 버전·fixture SHA 잠금.
2. HV-L1: H 상태/명령·원장·이벤트를 C-D0 단일 World/staging/rollback에 연결.
3. HV-L2: H-D1→D7 실물·정치·군사·영토·무역/조직/영향력·위기 기능 단계별 구현/실효 조약/권한 연동.
4. HV-L3: 기존 104개+신규 72개와 기저 POP/C/D/E/G/F 범위별 회귀 실제 실행·개별 판정/오라클 로그 확보.
5. HV-L4: 저장/재생·버전 이관/오류복구, worker1/N·OS 간 정규 상태/원장 해시 동등성.
6. HV-L5: 1,200개월·복수국/조약/기구/위기·POP/기업 성능/메모리·역사제도, AI 정보뷰와 플레이어 툴팁 설명 정확성.

## 6. 정확한 현재 상태

- **HV-DESIGN:** 문서/테스트·불변식/ADR·예제 정적 확인 후 확정 가능.
