## 후속 상세 설계
H-D1 국가 관계·신뢰/인식, H-D2 외교활동·교섭, H-D3 조약, H-D4 종속·주권, **H-D5 국제협력체**, **H-D6 국가 간 영향력**, **H-D7 국제위기**(전쟁·휴전/강화 연계), H-V 통합 검증.

## 반드시 유지할 세 원칙
1. **국제협력체**는 회원국들이 조약·헌장으로 조직하는 공식 제도다. 여러 조직 중복 가입 가능, 실제 법적 의무·공동제도를 통해 효과 발생.
2. **영향력**은 경제·군사·정치·사회문화 상호작용에서 **자동 파생**되는 방향성·다차원적 조회값. '세력권 편입' 또는 '영향력 구매' 버튼 없음. '세력권'은 필요할 때 쓰는 파생 설명일 뿐 정본이 아니다.
3. **국제위기**는 분쟁에서 파생되는 다자 협상·중재 절차. 열강·2진영 강제/긴장도 임계 자동전쟁 없음; 실제 전쟁/점령/주권은 C-M/E/C-P의 사건을 사용.

본 문서는 설계 산출물이다. **Phase H C++ 엔진, 20개 인수 시나리오의 실제 시험, 장기/부하 검증은 수행하지 않았다.**
