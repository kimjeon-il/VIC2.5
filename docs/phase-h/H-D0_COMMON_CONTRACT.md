# H-D0 — 외교·국제관계 공통 설계 계약

> 계약: phase-h-common/1.0 · 기준일: 2026-11-04 · 상태: SPECIFIED / C++ 미구현·인수시험 미실행  
> 범위: 양자·다자 외교, 조약, 종속·주권 관계, **국제협력체**, **국가 간 영향력**, **국제위기**, 전쟁 개입/중재·강화  
> 작업 브랜치: work/phase-g-h-d0 · 기준선: work/phase-e-cpp-integration  
> 상위/의존: POP-D0~D3, C-D0/C-P1~P5/C-M1~M5/C-D4, C-E1~E5, D-D0/D-V(별도 work/phase-d-design), E-D0/E-G1~G5, G-D0 및 후속 Phase F(교통·물류).

## 0. 목표·설계 철학

1. 외교는 단순한 우호도 조절·전쟁 선포 메뉴가 아니라, 국가/정부/사회세력의 이해관계와 실제 경제·정치·군사·영토 구조가 교차하는 **독립된 국제관계 실행 시스템**이다.
2. **국제협력체 = 조약·헌장에 근거한 지속적 조직**, **영향력 = 상호작용에서 도출되는 다차원·방향성 있는 관계**, **국제위기 = 현실의 분쟁이 다자간 협상으로 확대될 때의 사건 절차**로 분리한다. 서로 연결하되 소속·수치·위기 상태를 혼동하지 않는다.
3. 영향력은 정책 버튼으로 직접 올리는 자원이 **아니다**. 무역·투자·외채·군사원조·주둔·외교지원·문화/교육 교류 등이 발생한 뒤 관계 및 의존 구조에서 자동 산출한다. '영향력 +10', '세력권 편입', 무근거 외교마나 등의 인터페이스를 기본 시스템에 도입하지 않는다.
4. 국제협력체는 경제·군사·정치·문화적 협력을 자유롭게 조합하며, 1국가-1조직 소속을 강제하지 않는다. **세력권은 주된 영향력의 관찰·설명용 파생 표현**으로만 사용하고, 상시 쓰기 가능한 소속 원장이나 공식 기구로 취급하지 않는다.
5. 국제위기는 Victoria 2의 열강 참여형 위기 개념을 참고하되, **위기 수치 100 = 자동 전쟁**과 열강/두 진영 강제 구도를 사용하지 않는다. Victoria 3에서 적극 참고하는 범위는 조약·다중 조항/교섭 구조다. 두 게임의 고유 수치·계산식·데이터를 복제하지 않는다.
6. 플레이어는 조약 제안·지지 선언·중재·제재 법안·동맹·외교적 요구·군사/재정 지원 등 **원인이 되는 외교적 행동**을 선택한다. 파급효과는 기존 원장과 H 관계/사건으로 처리하고, 주요 영향은 툴팁/상세 설명에 근거와 함께 표시한다.
7. 본 D0는 원본·기본 행위·시간·연계·불변식을 확정한다. 국제법의 역사적 상세 규칙, 국가 AI 평가 가중치, 위기 위험의 실증 계수, 외교관 활동 세부 알고리즘은 후속 H-D1~D7에 위임한다.

## 1. 상위 계약 우선순위와 기존 외교 요소의 통합

- C-D0와 C-P1의 **Country(국제법적 국가) ≠ Government(집권 정부) ≠ Institution/Office(권한 조직)** 구분을 유지한다. 내각 교체로 국가의 국제적 법인격·국채·기존 조약이 자동 사라지지 않는다.
- C-P의 헌정·법률·외교권한·의회 비준 절차와 C-D0의 Command→ProposedEvent→JournalBatch→StagingWorld→월말 원자 커밋을 따른다. 조약 서명/비준/발효/집행은 별개의 사건이다.
- E-D0의 Province와 sovereignty/civil_administration/fiscal_authority/military_control, Claim/Dispute, 동적 행정구역은 공간/권리 원본이다. '영토 요구'는 Claim/Dispute, '군사 점령'은 military_control, '영토 양도'는 적법한 주권 이전 사건으로 처리한다.
- C-M5에는 Conflict/WarGoal/PeaceTreaty/CeasefireAgreement/SettlementObligation이 이미 정의되어 있다. H의 포괄 Treaty·외교적 종전합의는 **현행 M5 정본을 무시하거나 이중 쓰기하지 않는다**. 연결 전에는 M5 객체에 대한 어댑터; 장차 H Treaty에 평화 관련 조항을 일원화한다면 C-M5/H 양쪽 ADR·버전·마이그레이션이 필수다. 실제 교전·전투·점령·군사손실은 항상 C-M 원본에 남는다.
- 무역 정책·관세 특혜는 H의 유효 TreatyTerm을 G의 read-only TradePolicyProjection으로 공급한다. 실제 세관 채권·현금·상품 거래·FX·무역량은 C-E/G/F가 계산한다. 같은 조약 조항이 중복 집행되지 않도록 term_id/obligation_id를 연계한다.
- D-D0 연구·특허/해외투자, POP 인구/문화·정치성향, F의 군사통행/상업통행·운송능력 등은 타 영역의 정본으로 조회하며 H에서 인구·돈·상품·설비를 새로 발행하지 않는다.
- 본 문서의 미래 목적 분담은 기존 설계 계약을 자동으로 변경하지 않는다. 소유권 이동은 ADR + 버전 증가 + 회귀 및 저장 마이그레이션에 의한다.

## 2. 안정적 데이터 모델과 관계 유형

모든 H 객체는 C-D0 typed EntityId(0 invalid, 영구 비재사용), source_event_id, provenance, revision, created/effective/expiry month를 적절히 사용한다. 명칭·국기·지도색은 ID가 아니다.

| 종류 | 필수 구조 | 권한과 원본 |
|---|---|---|
| DiplomaticRelation | directed actor_A→actor_B, relationship_kind, event/obligation refs, valid_period, revision | 외교적 사건과 유효 관계의 정본; 일률적 영향력 수치의 원본 아님 |
| DiplomaticAct | initiator authority, target(s), kind, scope, submitted/effective month, legal_basis, command/event refs | 교섭·항의·승인·중재·최후통첩 등 권한 있는 외교행위 |
| NegotiationCase/Offer | case_id, participants/roles, objectives, terms, concessions, reservations, deadlines, revision | 협상 제안/수정/동의/철회; 합의 이전에 정책 효력 없음 |
| Treaty/TreatyTerm | treaty_id, parties/roles, term_id, kind, scope, legal_basis, sign/ratify/effective/expiry, conditions, exceptions, status | **국제적 약속·조약 조항의 법적 정본** (M5 기재 내용은 연동·이관 대상) |
| TreatyObligation | obligation_id, obligor, beneficiary, duty, due_period, fulfillment_refs, breach/remedy, term_id | 의무·청구와 실제 지급/수송/군사행동 구분 |
| SovereigntyRelationship | relationship_id, principal/dependent, autonomy_rights, retained_rights, delegated_powers, obligations, effective_period, legal_basis | 보호국/속국/조공/공동주권 등 법적·사실상 관계; Country/Province 원본 대체 금지 |
| InternationalOrganization | organization_id, charter_treaty_id, founding members, purposes, institutions, governing_rules, lifespan | **국제협력체**의 공식 조직/절차 정본 |
| OrganizationMembership | organization_id, actor_id, role, rights, obligations, membership_period, admission/exit event | 다중 조직 가입 허용·헌장과 모순 검증 |
| OrganizationDecision | organization_id, proposer, voting/rule basis, adopted/effective dates, required implementation, event refs | 정족수/의결 이력; 의결만으로 타 분야 원장 자동 변경 금지 |
| InternationalCrisis | crisis_id, origin_claim/dispute/treaty_event, issues, affected territories/actors, start/month/status, participants, revision | **국제위기** 절차의 상태·이력 정본 |
| CrisisPosition/Offer | crisis_id, actor, stance, support type/conditions, mediation terms, effective_period, source_event | 지지·중립·중재·조건부 협력·독자제안·철회 |
| InfluenceAssessment | subject_A→target_B, economic/military/political/cultural dimensions, revision keys, observed_month, reason_refs, uncertainty | **조회·캐시 전용**; 별도 가변 influence 포인트 원장 금지 |

Treaty와 NegotiationCase를 구별하며, 논의된 제안이 곧 비준된 조약이 아니다. 보증·불이행·사후조정이 필요한 기록은 명시적 obligations/event ID로 유지한다. 무력 충돌의 사건/전쟁 명부는 C-M5 원본과 연결할 뿐 새 H 전투 원장을 만들지 않는다.

## 3. 국가 간 관계와 외교적 행동(H-D1·D2 경계)

### 3.1 양방향이 아닌 방향성 관계

- A→B의 위협 인식, 신뢰, 의존, 정책 기대와 B→A의 평가는 달라질 수 있다. 우호·신뢰·적대·영토 분쟁·무역 이해관계를 **한 개의 -100~+100 수치로 압축하지 않는다**.
- 신뢰/신용/평판은 조약 준수, 원조, 적대행위, 협상 파기, 장기 관계, 국내 여론 등 **실제 사건의 이력과 객관적 조건**을 바탕으로 평가한다. 시점별 인식의 차이/정보비대칭은 별도 상태와 uncertainty로 표시할 수 있다.
- 역사적 갈등, 정치제도/정권 변화, 공식 승인 여부, 상호 대사 교환, 통상·조약 권리, 군사적 위협은 구분된 관계/조건이다.
- 주권국가/정부/반란세력/식민 통치기구는 같은 개체가 아니다. 승인·교섭 상대는 그 시기의 법·정치 규칙에 따라 적격성을 판정한다.

### 3.2 외교행위와 실제 자원

- 플레이어/AI 명령은 embassy_open/close, recognize, protest, propose_term, accept/reject, mediate, guarantee, economic_sanction_policy, military_support_offer, ultimatum, treaty_ratification 등 **현실의 외교적 선택**에 대응한다.
- 권한·법적 절차·외교 채널·연락/통신시간·인력·예산·실제 지급/물자/군사 동원능력을 검증한다. 무상 '외교 포인트' 지출만으로 외교행위의 실효성을 보장하지 않는다.
- 요청의 수락 가능성은 상충하는 이해관계, 비용, 신뢰, 위험, 동맹 의무, 제3국 반응, 국내 정치 제약에 의해 결정된다. 특정 영향력 수치만 높으면 무조건 수용하는 규칙은 금지한다.
- 협상이 결렬돼도 이미 실제로 시행된 지원·동원·재정지출은 자동 복원되지 않는다. 법적으로 가능한 제재/지원은 정치·무역·군사·금융 분야의 후속 사건으로 시행한다.

## 4. 조약·종속관계(H-D3·D4 경계)

### 4.1 조약의 최소 실행 계약

- 조약은 양자/다자·공개/비공개(정보 접근 규칙)·기한부/무기한/조건부를 지원한다. 당사국별 권리·의무는 비대칭일 수 있다.
- 조항 범주: 방위/불가침/군사통행/기지사용, 통상/관세/시장 접근, 해외투자·차관/배상, 영토/국경/공동관리, 보호·속국·자치권, 군축/검증, 연구/문화·교육 교류, 국제협력체 헌장·회원 의무, 분쟁조정·중재.
- 조항별 id, 시행기관, 적용대상·지역·상품, 시작/종료, 선행조건, 일시중단/탈퇴/위반·시정 방식이 필요하다. 조항 간 의존과 충돌은 명시적으로 정의한다.
- 상태 전이 예: Draft → Negotiating → Signed → PendingRatification → Ratified → Effective → Suspended/Amended/Expired/Terminated. **서명 = 비준 = 효력 = 이행 완료**가 아니다. 비준 절차가 필요 없는 체제도 적법한 권한 근거가 있어야 한다.
- 각 조항은 목적 시스템(C-P/C-M/E/G/F/C-E/D)의 명시적 적용 이벤트·Projection을 생성한다. 단지 TreatyTerm이 존재한다는 이유로 해당 영역의 상품·국토·사람·현금을 자동 이전하지 않는다.
- 배상·원조·차관은 의무와 실제 지급을 분리; 영토 양도는 E의 유효 주권 사건, POP 국적·거주 및 재산 승계는 별도 사건이다.

### 4.2 종속·보호·주권 관계

- 정치적 종속 및 주권 위임은 **국가/정부/법적 권리의 유효기간 있는 관계**로 표현한다. 보호국/속국/조공국/자치령 등 역사적 명칭은 규칙/권한 묶음으로 해석하고 시대 전체에 단일 고정 위계를 강제하지 않는다.
- 위임 영역은 최소 foreign_policy, war_declaration, defense, taxation, customs, legislation, appointments, market_access, internal_administration, treaty_capacity 등으로 분해하며 실효 권한과 명목상 주권을 구별한다.
- 종속국이 실제로 인구·세금·상품을 상납한다면 해당 합법 의무와 실제 원장 거래를 검증한다. 명목 종속만으로 자산·주민/정부가 자동 합병되지 않는다.
- 세력권(파생된 영향력)과 종속국 지위(법적 관계)는 완전히 다르다. 우월한 경제 영향력 자체는 식민통치권·조약 비준권이 아니다.

## 5. 국제협력체(H-D5) — '세력블록'과 구분

### 5.1 구성 모델

국제협력체는 한 개의 미리 정해진 분류 슬롯이 아니라, **회원국들이 채택한 헌장/조약과 실제 제도를 가진 상설·임시 조직**이다.

- 최소 참여 주체 수, 의사결정 방식, 가입 자격, 회원 권리, 공동기구, 예산/분담금, 탈퇴/제명·해산 조건을 헌장으로 설정한다. 기본 회원국 2개 이상; 비국가 참관·가입은 적법한 규칙으로만 허용한다.
- 경제협력·관세동맹·공동시장·군사협력/집단방위·정치협의·이념/문화협력·복합체 등을 **여러 조항을 조합**해 표현한다. 처음 경제협력체였다가 뒤에 군사조항을 추가/삭제할 수 있다.
- 주도국이 있을 수도, 순환 의장국/공동지도·위원회·총회가 있을 수도 있다. 국가의 군사력/규모만으로 주도국이 법률상 자동 독점되지 않는다.
- 한 국가는 여러 국제협력체에 동시에 가입할 수 있다. 다만 실제 헌장에 배타적 회원조건·상충 의무가 있으면 해당 가입/의결을 충돌 검증한다.
- 총회/집행기구의 의결은 적용대상·정족수·표결규칙·거부권/동의요건을 충족해야 한다. 통상 특혜·집단방위·공동예산·공동 시설이 실제 효력을 내려면 별도 법률/조약/회계·군사·무역 실행이 필요하다.
- 회원국 탈퇴·헌장 개정·기구 분열/해산은 원래 조약/기여금·채무/시설 권리·잔존 의무의 처리 조건을 기록하며 기구의 리더 국가만 바뀌어도 조직 ID를 함부로 재발급하지 않는다.

### 5.2 결속력과 강제 효과 제한

- 결속력(cohesion)은 회원국 간 **조약 이행, 무역·안보 상호의존, 정치적 정책 차이, 분담금 체납, 신뢰/의견 대립, 공동의제**를 반영한 파생 평가다. '조직 경험치'나 인위적 결속력 증가 버튼이 아니다.
- 기구 회원이라는 사실 자체에 무근거 산업 생산 +10% 또는 참전 자동 효과를 부여하지 않는다. 공동 시장은 실제 관세·시장접근 규칙, 군사동맹은 발동 요건/정치적 이행, 공동연구는 실제 지식 공유/설비 도입 조건을 통해 효력을 낸다.
- 경제협력체가 군사 분쟁에서 반드시 같은 편이 될 필요는 없다. **집단방위 의무**가 있다면 그것이 발동하는지, 해당 회원국에 수행 능력/법적 권한이 있는지를 구분한다.
- 조직의 외교적 지도부 변화는 회원국의 모든 다른 외교관계를 초기화하지 않으며, 조직 구성과 **영향력 경쟁**을 별개로 평가한다.

## 6. 국가 간 영향력(H-D6) — 자동 파생 지표

### 6.1 정의·원천·방향성

Influence(A→B, t)는 A가 B의 선택지·위험·협상비용에 미치는 **관측 가능한 구조적 영향의 다차원적 파생 평가**다. B→A와 별개이며 B가 반드시 A의 요구를 따르거나 세력권에 편입됨을 뜻하지 않는다.

| 차원 | 실제 근거 데이터(예시) | 주요 해석 |
|---|---|---|
| 경제 | B의 대A 무역의존도/대체 공급망, A 기업의 B 내 투자·고용·핵심 자산 소유, 대출/채무·금융접근, 거래중단 비용 | B가 A의 경제적 선택에 노출되는 정도 |
| 군사·안보 | 무기/군수품 공급, 안보보장·군사원조·훈련/주둔, B의 독자 방위력과 대체 지원국 | B의 안보 선택에서 A가 갖는 상대적 지렛대 |
| 정치·외교 | 조약 준수·협상신뢰, 공인 지원·국제기구 투표/거부권, 정권·정치세력의 실제 이해관계와 공적 관계 | A가 B의 외교적 결정에 미치는 실효 영향 |
| 사회·문화 | 언어/교육·기술·언론·이주/인적 교류·학술/문화 연결의 실제 관측, 법·사회적 제약 | 장기적인 협력/접근 및 인식 변화 |

- 한 차원의 큰 원자료가 자동 지배력을 뜻하지 않는다. **상대적인 의존도·대체 가능성·실제 접근권·정책 신뢰도·국내 저항·제3국 대안·시간차**를 함께 평가한다.
- 무역 의존 비중은 일방적 매출액이 아니라 B의 전체 가용 시장/품목·대체관계를 기준으로 계산한다. 차관·투자·무역금융이 같은 노출을 중복 표시하면 중복 보너스를 주지 않는다. 군사지원도 선언과 실제 납품/보급을 구분한다.
- 모든 차원은 **원장/계약/사건에서 읽는 read-only view**다. 사용자가 influence_points를 직접 지급/차감하지 않는다. 표시용 단일 요약치는 선택적으로 제공하되 원본 4개 차원을 대체할 수 없고 자동적인 외교성공 문턱값으로 사용하지 않는다.
- 'A의 세력권' 지도 표시는 특정 시기·분야에서 A의 영향이 다른 국가보다 지속적으로 우세하다는 **설명용 파생 레이블**이며, H의 소속 원장/지위/권한이 아니다. A 경제 영향권 + B 군사 영향권 + C 문화 영향권이 중첩될 수 있다.
- 영향력 평가의 갑작스러운 표시 흔들림을 줄이려면 관측기간·신뢰구간·전환 히스테리시스를 **UI 파생 판단에만** 적용한다. 실제 투자·금융·조약 사건을 지연하거나 은폐하지 않는다.
- 어떤 나라의 외교요구 수락 여부는 영향력 하나로 결정하지 않고 합법성·강제능력·정책이익·국내 정치·전쟁 위험·제3국 선택을 포함한 의사결정으로 산출한다.

### 6.2 설명 가능성과 성능

- InfluenceAssessment는 (A,B,world_snapshot,month, dimension, upstream revisions, model version, confidence, explanation refs) 키로 캐시하며 투자/무역/정치/군사 등 **원본 변경 시 무효화**한다. 별도 쓰기 가능한 influence 원장은 만들지 않는다.
- 월초 기준 관계·원장 상태의 스냅샷에서 평가한다. 당월 조약·전투·무역으로 생긴 변화는 사후 사건/차월 스냅샷을 통해 반영하여 **A→G→H→G 동월 무한 피드백**을 금지한다.
- 각 차원의 구성요인과 변화사유(예: 철도투자, 무역축소, 조약 위반)를 추적할 수 있어야 한다. 원자료 없음(unknown), 0, 추정(estimated)을 구별한다.

## 7. 국제위기(H-D7) — 다자간 외교 사건

### 7.1 발생과 범위

- Crisis의 **원인**은 E Claim/Dispute, C-P 정치/독립운동, C-E/G 통상갈등·채무불이행, H 조약 위반·종속 지위 갈등, C-M 군사 위협 등 실제 사건이다. 플레이어가 '위기 발생' 버튼으로 임의 위기 수치를 생산하지 않는다.
- 잠재 갈등은 모두 즉시 국제위기가 되지 않는다. 당사자 외교적 이의제기, 분쟁의 확대 가능성, 제3국의 이해관계/개입·국내정치·위협/제재/동원 등의 관측 조건으로 사건화한다. 국내 분쟁이 국제위기로 발전할 수 있으나 모든 지역 불만을 강제로 국제사건으로 만든다거나 존재하지 않는 독립국을 생성하지 않는다.
- 위기에는 영토·독립/자치·주권/속국·통상·배상·봉쇄·조약 이행·군사/인도주의 분쟁 등 다수 쟁점과 다수 당사자를 허용한다. 위기의 영토 범위는 E Province/ClaimId/ScopeId에 매핑하며 고정 프로빈스 분할을 필요로 하지 않는다.
- **열강만 참여 가능 규칙 없음.** 당사국·보호국·인접국·조약당사자·경제적으로 연루된 국가·국제협력체 회원·중재국 등 실제 이해관계와 외교적 접근권에 따라 참여 가능. 비국가 행위자는 기존 C-P의 PoliticalMovement/InsurgentOrganization 등으로 적격성 검증한다.

### 7.2 단계·진영·협상

상태 전이 예: LatentDispute(기존 분쟁) → Internationalized → ActiveNegotiation → Settled / Frozen / Withdrawn / EscalatedArmedConflict. 위기는 일시 동결·반복 재개·부분 해결 가능하며 전쟁은 **자동적 필수 종료 상태가 아니다**.

- 역할은 claimant/respondent/supporter/mediator/guarantor/observer 등 다중이며, 국가가 **중립·조건부 지지·중재·단독 제안**을 취할 수 있다. 반드시 A진영/B진영 이분법으로 강제하지 않는다.
- 외교적 긴장/전쟁위험은 실제 동원·병력배치·확약·통상손실·선전·국내정치·신뢰·교섭기간 등에서 산출하는 위험/추정치다. 특정 임계치 100에 도달했다는 이유만으로 자동 전쟁 선언 금지.
- 국제협력체 회원국은 헌장에 따라 협의하거나 공동안을 채택할 수 있지만 **조직 전체가 자동으로 참전하거나 동일 입장을 가지지는 않는다**.
- 위기 해결안은 단일 보상만이 아니라 **H 조약의 복수 조항**으로 구성한다: 영토 양도, 공동관리, 주민투표(법/인구 적격성 충족), 군축, 배상·상환 계획, 군사 철수, 무역 특혜, 자치권, 중립화/보장, 국제중재 등. 수락/비준/발효/이행을 구분한다.
- 최후통첩 기한 경과·기습공격·선전포고로 전쟁이 시작될 수 있으나, **C-P의 적법한 명령 + C-M5의 Conflict/EntryToWar**가 전쟁의 정본이다. 전쟁 중에도 협상/휴전/강화 가능; 위기 상태와 교전 상태를 서로 동일시하지 않는다.
- 복수 위기가 같은 영토/조약을 둘러싸면 사건을 무조건 병합하지 않는다. 명시적 연결/우선순위/상호 영향만 추적하며 동일 주권 변경·배상 의무가 중복 실행되지 않도록 term/claim ID로 검증한다.

### 7.3 파급효과

국제위기가 민간·군사·정부에 미치는 영향은 실제 조약/정책·제재·동원·운송 차단·투자중단·신용위험 변화 등을 통해 C/D/E/G/F에 전달한다. 단지 crisis_tension 수치가 오른 이유만으로 기업재고가 사라지거나 POP가 사망하지 않는다. 실제 전투·제재/봉쇄는 각 분야의 유효 사건이 있어야 한다.

## 8. 국제협력체·영향력·국제위기의 상호작용

- 국제협력체는 **서명된 헌장·조약과 회원 자격**을 제공하고, 파생 영향력은 회원 여부와 무관하게 실제 교역/안보/정치 관계를 평가한다.
- 분쟁의 확대·위기 참가 결정은 양쪽 모두를 읽되, 조직 회원이라는 사실만으로 기계적인 동맹 동원/세력권 편입은 없다.
- 예: A의 B 투자 증가 → B의 A경제 의존도 상승(자동 평가) → 분쟁 시 A의 제재 위협이 B에 더 큰 예상 손실을 줌. 하지만 B가 다른 동맹의 안보지원, 대체 무역시장, 내부 정치 지지를 확보하면 A의 요구를 거절할 수 있다.
- 다른 예: 경제협력체에 함께 가입한 A/B가 영토분쟁 중이라도 군사원조는 헌장 의무가 없는 한 각 정부가 별도로 결정한다. 가입/탈퇴는 실제 조약·재정·사회적 결과를 동반한다.

## 9. 월별 12단계와 법적 시간

| Stage | H가 읽거나 산출하는 것 |
|---:|---|
| 0 opening_snapshot | 전월까지 확정된 조약·비준/발효·회원/종속관계, 외교적 권한, E 관할, G 통상 정책, C-M 교전상태를 개시 스냅샷으로 동결. 영향력 평가 기준선 설정 |
| 1 planning_and_credit | 외교행위/협상 제안, 적법한 기관·재원·통신/인력·공약의 자원가능성 검토 및 필요한 예약 |
| 2 labor_clearance | 외교기관에 실제 배치된 공무원·지원인력과 타 임무의 노동 중복/가용성 확인 |
| 3 intermediate_goods | 이미 유효한 조약/제재의 중간재 거래·군수 조달 제약을 G/C-E에 조회조건으로 제공 |
| 4 production | 정책·투자/교역 조건에 따라 실제 생산/시설 상태는 C/D가 계산; H는 별도 생산량 증가 금지 |
| 5 wages_and_transfers | 승인된 외교기관 비용·원조 지급은 C 재정/금융 원장으로 집행 |
| 6 pop_consumption_plans | 국내 여론·외교정책의 POP 인식과 소비 수요를 C/POP가 처리; H는 독립 소비 원본 없음 |
| 7 final_goods_market | 유효한 통상/봉쇄·제재와 실제 거래·배송 효과는 G/C/F가 처리 |
| 8 closing_accounts | 실제 외교 비용·원조·배상 수납과 미이행 의무/채무를 대응 원장과 교차 검증 |
| 9 saving_and_investment | 협상/비준/가입·탈퇴·정부 인준 및 새 조약·법·정책의 승인/예약. 원칙적으로 m+1 stage0 발효 |
| 10 pop_demography_and_health | C-M5의 실제 교전·군사통제·인구 사건 및 C-P 반응/위기 사건 결과 기록. 과거 단계 소급 변경 금지 |
| 11 repricing_and_validation | 외교 이력·조약 효력/의무·조직 회원·위기·영향력 캐시revision·전원장 정합 검증 후 원자적 월 커밋 |

Stage 9에서 채택한 조약은 기본 m+1 stage 0부터 적용한다. 급박한 군사적 사건/당월 유효 정전 등을 구현하려면 **C-D0/C-M5의 명시적 서브틱·효력시점 계약**을 먼저 확장해야 한다. 서브틱이 없는 엔진에서 '즉시'라고 표시해 단계 0 법률/거래·전투를 소급 바꾸지 않는다. 채택/효력/실제 이행 시각을 분리한다.

## 10. 공개 인터페이스 초안

- GetDiplomaticRelations(actor, target, snapshot) → 다차원 관계, 합법적 수단, 이력·근거.
- ProposeDiplomaticAct(issuer, action, terms, expected_revisions) → 권한 검증된 Command/ProposedEvent.
- OpenNegotiation(issue_refs, actors, eligibility, snapshot) / SubmitOffer(case_id, terms, source_command) → 변경 이력·검증.
- SignTreaty / RatifyTreaty / ApplyTreatyTerm / TerminateTreaty → 비준/발효·정책 projection·의무 변경을 분리.
- GetOrganizations(actor, month) / EvaluateCharterCompatibility(candidate, existing_memberships) / ProposeOrganizationDecision → 다중가입·헌장/투표권·배타성 검증.
- AssessInfluence(actor_A, actor_B, snapshot) → 경제/군사/정치/문화 차원별 **read-only 평가**, 설명·출처·불확실성.
- EvaluateCrisisTriggers(dispute_events, snapshot) / JoinCrisis(crisis_id, position) / SubmitCrisisSettlement → 실제 사건 기반 다자 교섭, 자동 전쟁 금지.
- GetTreatyEffectiveTerms(scope, month) → G/C-M/E/C-P/F에 전달할 유효 조항/의무/효력시점/계약 식별자.
- ExplainDiplomaticDecision / ExplainInfluenceChange / ExplainCrisisRisk → 사전 예상과 사후 실현을 구분한 툴팁 데이터.

조회는 (snapshot, effective_month, ruleset/contract versions, upstream revisions)에서 일관되어야 한다. 상태변경 명령은 기존 C-D0 원자 staging을 우회하지 않는다.

## 11. 플레이어 조작·설명 UI

- 국가별 기본 정보: 핵심 조약·국제협력체 가입, 현재 주요 국제위기·협상, 양국 관계/안보/경제의 요약만 표시한다. 별도 포인트 상승 조작은 없다.
- 영향력 툴팁: '경제적 영향력 상승' → 해당 무역 비중/차관·투자·대체시장, 원자료·기간·변경 원인을 드릴다운. 경제·군사·외교·문화가 서로 상충하면 하나의 총점으로 숨기지 않는다.
- 조약 제안 툴팁: 법적 즉시 효과(서명/비준·발효와 구별), 기업/고용/재정/군수/무역의 **예상 파급·시간차·가정·불확실성**, 비준 불가·재정/군수 병목과 상충 의무를 설명.
- 국제위기 화면: 쟁점·실제 당사국/이해관계·중재안/양보안·미확정 위험/확정 최후통첩·종료 가능한 경로를 보여준다. 모든 위기가 전쟁으로 예정된 것처럼 표시하지 않는다.
- 기본 UI에 장황한 원장 상세를 강제하지 않는다. 호버·키보드 포커스·터치에서 툴팁/상세 패널에 접근하도록 한다. 설명 데이터는 엔진의 상태·공통 규칙을 재사용한다.

## 12. 필수 공통 불변식

- HD0-INV01 Country/Government/Office/Organization 등 서로 다른 ID·권한의 혼동 금지; 정권교체로 국가·기존 조약·채무 소멸 없음.
- HD0-INV02 모든 조약·조항·회원·종속·위기 참조의 typed ID/유효기간/revision 정합.
- HD0-INV03 서명/비준/발효/이행/위반/종결은 별도 사건, 소급 집행 금지.
- HD0-INV04 조약·국제기구 결의는 C-E/POP/C-M/E 원장에 실제 이벤트 없이 화폐/인구/상품/병력을 생성·이동하지 않음.
- HD0-INV05 TreatyTerm·PeaceTreaty·TradeAgreement의 동일 조항/의무를 이중 집행하지 않음.
- HD0-INV06 실효 외교행위는 유효 정부·공직/의회 법적 권한 및 집행자원/통신 제약을 충족.
- HD0-INV07 종속국·보호국·자치권은 법적 위임권한/유효기간으로 표현; 영향력/조직 소속과 혼동하지 않음.
- HD0-INV08 국제협력체 회원 수·헌장/가입조건·중첩 배타성·의결 정족수·이력 일치.
- HD0-INV09 기구 회원/지도국 지위만으로 무조건 참전·무료 경제/군사보너스 없음.
- HD0-INV10 영향력은 원천 관측·관계 기반 read-only 평가; 임의 직접 증감·세력권 편입 원본 없음.
- HD0-INV11 Influence(A→B) ≠ Influence(B→A); 경제/군사/정치/문화 차원과 unknown·estimated·0을 구분.
- HD0-INV12 같은 무역/투자/차관/군사지원 효과의 원인 중복 보너스 또는 재귀적 자기증폭 금지.
- HD0-INV13 국제위기는 유효 Claim/Dispute/조약·정치·경제·군사 사건 근거와 당사자 적격성을 가짐; 가짜 국가/인구 생성 금지.
- HD0-INV14 위기 다자·중립·중재/조건부 참여 허용, 위기 수치 임계치에서 전쟁 자동 발발 없음.
- HD0-INV15 실제 선전포고/전투/참전/점령의 진실값은 C-P/C-M/E; 외교적 지원선언과 실제 군사행동을 구별.
- HD0-INV16 휴전·종전·배상 약정/영토 이양은 실제 의무/재고/금융/관할·POP 사건과 정합.
- HD0-INV17 여러 위기/조약이 같은 영토·의무에 영향을 줄 때 모순 주권/중복이행 금지.
- HD0-INV18 동일 Command/Event/TreatyTerm 집행은 멱등, 전역 StagingWorld 실패는 전영역 롤백.
- HD0-INV19 동일 초기 세계/시드·명령·규칙·워커 수 무관 외교 결과·의무·연관 원장 해시 일치.
- HD0-INV20 미래 예측 및 영향력·위기 리스크 UI는 확정/추정/미상을 구분하고 설명 가능한 원천 참조를 가진다.

## 13. D0 기본 인수 시나리오(후속 H-V에서 확장)

- HD0-T01 내각 교체: 국가·기존 유효 조약·외채 계속 유지, 새 권한자만 교체.
- HD0-T02 복수 조항의 통상+집단방위 조약: 서명/비준/차월 발효·각 분야 실행 분리.
- HD0-T03 관세면제 H 조항을 G가 1회 적용하며 기존 C-E5 세금/재고와 이중 분개 없음.
- HD0-T04 군사동맹 가입 자체로 군부대/장비 생성·자동 참전 없음.
- HD0-T05 경제협력체·군사동맹 동시 가입; 모순 없는 한 다중 가입 유지.
- HD0-T06 배타적 관세동맹 중복 가입은 정식 헌장 규정에 따라 거부/재협상.
- HD0-T07 국제협력체 지도국 변경·회원 탈퇴·해체에도 국가/인구/재산·기존 채무 자동 소멸 없음.

- HD0-T09 A의 경제 영향력이 커도 B가 C 군사지원·대체시장으로 A 제안을 거절할 수 있음.
- HD0-T10 A→B/B→A 방향성과 경제·군사·정치·문화 간 차이·중첩 영향권의 표시 검증.
- HD0-T11 영토분쟁이 국제위기로 발전했지만 3개 중재안을 거쳐 전쟁 없이 종결됨.

- HD0-T13 경제공동체 회원국 두 나라가 위기에서 반대 입장을 취하되 자동 탈퇴/전쟁 발생 없음.
- HD0-T14 위기 위험이 높아져도 자동전쟁 없음; 실제 전쟁은 C-P/C-M5 적법 사건으로만 생성.
- HD0-T15 휴전·강화 조항의 배상금 약정 100/실제 지급 20 → 미지급 채무 80, 이중지급 없음.
- HD0-T16 주권/보호관계 조정 이후에도 E Province·POP/국적·재산권·군사점령 분리 유지.
- HD0-T17 국제협력체 조직에 의무기금이 있어도 실제 회원국 분담금/고용/시설 없는 무료 공동사업 없음.
- HD0-T18 연동 조약·위기/Influence 캐시 변경과 저장/복구·worker1/N 결과/중복 사건 처리 결정론.
- HD0-T19 외교관 권한 없음/비준권 충돌·관할 참조 오류/중복 토지양도 → 정상 거부 또는 원자적 전역 롤백.
- HD0-T20 영향력·조약·국제위기 툴팁에서 사전예상/사후실현·근거/불확실성 차이를 설명 가능.

## 14. 후속 세부 설계·통합 검증

- H-D1 국가 간 관계/인식·신뢰/평판·외교 적격성.
- H-D2 외교행위·협상·중재·외교자원.
- H-D3 조약·복수 조항·비준/위반/갱신·국내/국제법.
- H-D4 종속·주권 위임·보호국·자치/승계.
- H-D5 국제협력체·헌장·복수 가입/집행기구·공동정책.

- H-D7 국제위기·다자 협상·위험·전쟁 개입·휴전/강화 연동.
