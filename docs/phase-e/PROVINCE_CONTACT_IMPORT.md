# 프로빈스 접촉 자료 연결

시나리오에서 이미 등록한 육지 프로빈스와, 별도로 지정한 해역·호수 ID에
검증된 원본의 공유변을 대응시킨다. `seed_contacts`는 이 자료를 Phase E에
등록하는 시작 시점 전용 함수다. 서로 다른 버전의 지도나 모서리만 닿는 행
(공유변 수 0)은 받지 않는다. 표본용 타일이나 RGB 값 자체를 시나리오 ID로
쓰지 않는다.

- 육지끼리 닿으면 양방향 이웃으로 등록한다.
- 육지와 해역이 닿으면 해안으로만 등록한다. 호수와 접한다고 바다로 처리하지 않는다.
- 해안과 국경은 운송 서비스가 아니다. 선박·철도·도로 운송에는 별도의 방향,
  근거, 운송 주체 및 도착 시간이 필요하다. 떨어진 조각을 가진 프로빈스를
  가로지르는 새 경로를 이 자료만으로 추정하지 않는다.

`vic25_province_contacts_daily`는 합성 시나리오에서 원본 공유변을 적용하고,
서비스 미등록 시 출고하지 않는 경우와 별도로 등록한 단방향 도로로 출고하는
경우를 검사한다. 두 번째 경우에는 이틀 뒤 입고되고 운송 중 저장을 다시
불러와도 같은 결과가 나와야 한다. 세계 지도의 게임 ID·소유권 대응표와 실제
캠페인 시나리오는 이 코드에 포함하지 않는다.
