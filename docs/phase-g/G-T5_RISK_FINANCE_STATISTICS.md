# G-T5 — 무역위험·무역금융·공급망 충격·통계·설명가능성

> 설계: phase-g-trade/1.0 · 2026-11-04 · SPECIFIED / NOT_IMPLEMENTED
> 의존: G-D0/T1~T4, C-E2/3/4/5, C-M 전쟁·보급, D 산업/건설/기술, E 주권/관할, H-D0 조약/국제위기·영향력, 후속 F 물류.
> 핵심: **리스크는 실제 위험노출과 사건에, 손실·금융은 실제 보유자/채권에, 국가 통계는 원장에 귀속**하며 가상 위험/보너스 수치를 별도로 살포하지 않는다.

## T5-1. 위험의 종류와 귀속

| 위험군 | 실제 원인 | 원본 사건·손실의 주체 |
|---|---|---|
| 운송/물리 | 항만 혼잡, 해상 사고, 악천후, 지연·파손·도난·부패, 철도/도로 파괴 | F/C-E5 Shipment/Transport, C-E2 Inventory loss, 위험부담자 계약 |
| 전쟁/봉쇄 | 실제 전선/해군통제·통행 제한, 기뢰/공격·징발·압류 | C-M 전투·군사통제, E 관할, F/C-E5 접근/화물, 해당 보험·채권 |
| 시장/가격 | 구매시장 수급 변화, 수요붕괴, 경쟁자 출현, 재고가격 하락, 품질 불일치 | C-E2 월말가격·Order/TradeFill, C-E3 기업 평가손익 |
| 신용/결제 | 수입기업 부도, 은행 유동성 부족, 미지급·환전 제한, 보증인 불이행 | C-E3 Loan/FinancialLedger·Bankruptcy, 계약/지급 상태 |
| 정책/외교 | 수입금지, 관세인상, 무역조약 위반, 통과권 철회, 유효 배상·제재 | C-P·H TreatyTerm/외교행위, G-T4 PolicyProjection, F/C-E5 실행 |
| 생산/공급망 | 원료 부족, 공장 파업/화재, 기술/시설 피해, 재고 소진 | C-E1/D 실제 시설·고용·상품 생산/재고·노동 변화 |
| 보건/자연 | 가축질병, 전염병, 흉작, 침수, 자연재해/기후 이상 | 인구·생산·지리/환경의 실제 사건; 상업은 노출·지연만 파생 |

**RiskExposureView** = (trade_execution/shipment/firm/market/country, risk_class, identified source refs, likelihood_or_range, exposed_quantity/value/currency, bearer, expected_delay, snapshot/revisions, uncertainty) 조회·캐시. 위험 자체의 임의 음수/확률은 실물 손실이 아니다.

기본 위험연산:
- 실제 risk bearer와 인도조건을 따르며 같은 사고가 title owner, custodian, seller, buyer의 재고를 동시에 소각할 수 없다.
- 비보험 기대손실 = 발생확률 × 사고 시 자기부담 손해. 시나리오마다 의존성이 있으면 서로 독립이라고 가정해 단순 합산하지 않고 위험군별·공동 노출(해협·대출은행·같은 상품 등)을 보존한다.
- 결제의 불이행이 발생해도 상품이 자동으로 사라지지 않고, 운송 사고로 상품이 사라져도 판매자 예금/현금이 자동 음수·소멸하지 않는다.
- 위험 추정치의 부정확성이 재현성 위반을 뜻하지 않는다. 난수는 C-D0 분리 스트림(world_seed, month, phase, entity, event, draw_index), 고정소수점·결정론 정렬을 따른다.

## T5-2. 무역금융 계약

| 수단 | 실제 권리와 제약 | 회계·이행 |
|---|---|---|
| 선급금(prepayment) | 매수자 실제 가용잔고; 미인도 위험/반환청구권 | Financial 지급 + 상품 인도 의무는 별도 |
| 외상(open account) | 매도자 신용공여/매수자 미지급채무 | 실제 상품 인도와 매출채권/채무, 만기 지급 별도 |
| 상업어음·환어음 | 실제 지급인/수취인/배서인, 기일·양도·할인·보증 | 기존 금융채권/채무의 귀속·양도/할인/추심. 원본 채권을 사본 2개로 복제 금지 |
| 무역대출·재고금융 | C-E3 금융기관/상인 대출과 담보재고·신용위험 | 실제 대출 실행분에만 예금/대출채권의 대응 분개 |
| 신용장·은행 지급보증 | 적법 은행/보증인과 서류 제시·유효기간·담보/지급능력 | 보증의 조건부 채무와 실제 대금 지급 구분. 무상·무제한 은행 보증 금지 |
| 보험계약 | 보험사/적법 상호부조자·담보범위·보험료·자본/유동성 | 실제 보험료·손해 발생·청구·검증·지급·미지급을 별도 기록 |
| 정부수출신용·보증 | C-P/C-E4 유효 법·승인·재정한도·기관능력 | 국가의 보증·예산 부담과 실제 보증 지급 시점 분리 |

**TradeFinanceFacilityId / TradeGuaranteeId / CargoInsurancePolicyId**는 G의 무역거래·위험 커버리지 연결 관계를 소유하며, 실제 LoanContract/FinancialInstitution/FinancialLedger/InsuranceClaim(기존 금융의 확장)이 금액의 쓰기 정본이다. 금융 관련 새 엔터티를 C-E3의 단일 원장으로 통합해야 하며 두 개의 대출 원본은 만들지 않는다.

- 융자·보증·담보의 **중복 사용** 금지: 같은 재고 로트를 둘 이상의 대출에 담보 제공하는 경우 실제 선·후순위 합의/중복담보 허용 법률이 있어야 한다. 담보가치 100으로 별도 우선권 없이 두 명에게 각각 무위험 100 보증 금지.
- 의무상환/조건부 보증채무/실제 지급은 다른 현금흐름. 기한이 도래해도 자금 없는 지급을 음수 예금으로 처리하지 않고 연체·부도·보증청구·회생 사건이 발생.
- 동일 매입 재고를 이미 판매한 뒤에도 물류 상실·물리적 손상/환불의 위험이 남는지 계약에 따라 판단한다. 보험 보상금은 실제 보험자의 자산/채무와 대응하여 지급하며 손실 즉시 자동 복구 금지.
- 이자·보증수수료·보험료는 각 실제 계약의 유효금액/기간/법에 따라 Financial에 분개. 예상 비용과 발생주의 비용·현금 지급을 구분한다.
- 역사적 어음·상회사금융·현물 신용은 통화·법·은행 유무에 따라 사용 가능하며 1801년에도 모든 곳에 근대 중앙은행/신용장/해상보험을 강제하지 않는다.

## T5-3. 공급망·연쇄 파급과 위기

충격 전달은 **한 번의 원인 사건 → 관련 원본 변경 → 다음 의사결정**이다.

예: 해협 봉쇄(적법 C-M/H/E 사건) → F 경로 접근/수송가능량 감소 → G의 실효 출하·입고 지연 → 목적지 C-E2 가용재고·시장수급 변경 → 산업 D 원료 부족·POP 가계비용 상승 → 무역 의존도/외교 H 영향력의 다음 평가에 반영.

- 봉쇄는 상품을 즉시 삭제하는 세계적 제약치가 아니다. 실제 노선이 막혀야 정체/대체 경로/감산이 발생. 대체 경로가 있다면 실제 운임·시차·허가/여유용량을 반영.
- **공급망 노출 지표**: 핵심 원료별 주요 조달처 비중, 대체 공급자/경로 존재, 수입재고가 버틸 수 있는 기간, 경로 병목, 금융/통화 노출, 계약 만기, 수입집중도. 모두 실제 거래·재고·원료/산업 규칙에서 파생.
- 다각화·국산화·재고 비축은 선택적 기업 운영과 실제 건설·생산/매입·정책 지원의 결과다. '공급망 안정성 +20' 직접 버튼이나 별도 무상 생산력 금지.
- 국제위기(H-D7)는 실제 무역손실·통상관계/결제위험에 반응할 수 있으나, crisis risk를 상업 손실과 다시 합쳐 자기증폭되는 동월 루프 금지. 같은 사건을 FX/가격/물류/영향력으로 무한 순환 재평가하지 않는다.
- 월 m stage10에 발생한 전투·국경/점령 변화는 m+1 stage0 이후 유효물류·통상에 적용. C-D0가 명시적으로 지원하는 세분시간 이전에는 무역 과거 단계 소급취소 금지.
- 지역/상품별 복수 위험이 같은 shipment에 겹칠 때 하나의 물품 손실을 여러 번 기록하지 않는다. 손실 수량은 출하 시점의 실제 in_transit 잔량 이하.

## T5-4. 무역통계의 정확한 정의

| 지표 | 집계의 기초 | 혼동 금지 |
|---|---|---|
| 국내 상업 거래량/액수 | 동일 국내 관할/시장 조건의 Order/TradeFill·가격 | 신규 생산·GDP를 유통 회전 횟수대로 배증하지 않음 |
| 수출입 통관 물량/관세가액 | CustomsAssessment/실제 경계 통과; 방향/상품/원산지/법적 수입자 | 소유권 이전, 수송 중 화물 및 국내 생산량과 동일하지 않음 |
| 상품소유권 기반 국경간 재화거래 | nonresident/resident 사이 실제 title-transfer 거래 및 거주지/국가 정의·평가기준 | 보관자 국가·이동 경로만으로 확정 금지 |
| 재수출/통과무역 | 동일 lot provenance, 이전 수입/소유권/경유 관세절차 | 경유/재판매를 생산·GDP·원산지 변동으로 오인 금지 |
| 무역수지 | 기간·국가/경제영역 정의·기준 통화/가격으로 평가한 수출 − 수입 | 국제수지/경상수지 전체와 동일하지 않음 |
| 기업 상업이익 | 실제 판매매출/채권 + 서비스매출 − 매입원가/운송·보험·관세·금융·임금 | 현금흐름 = 이익이 아님; 미실현 가격평가와 구분 |
| 무역의존도·시장점유 | 각 국가·상품의 실효 수입/수출 및 대체 시장·가용 공급 | H 영향력은 별도 계산한 파생 상태. 단순 수출액 = 상대국 지배력 아님 |
| 운송/신용/정책 위험 | 유효 Shipment 지연·손실·FX 미체결·채무 연체·관세부담 | 예정/예측과 실현을 별도 레이어로 표시 |

- 모든 값은 (period, geographic/residency/customs scope, currency, price_basis, shipment_vs_title_vs_customs convention, snapshot/ledger revisions, provenance)의 명시된 조건을 가진다.
- 월별 국내·국제 거래를 같은 주문 2번 시장에서 집계하지 않는다. 물리적 무역과 국제수지 개념은 다르므로 국제 결제/재화 수지 전체를 원장 기준별로 따로 계산.
- 통계 수정은 원본 거래/통관/소유권 사건의 취소·보상 이벤트를 적용한 후 다시 집계. 별도 가변 country.exports 또는 national_influence_points 원본을 생성하지 않는다.
- 시나리오 데이터가 일부 미상인 경우 0으로 대체하지 않고 unknown/estimated/provenance. GDP는 C-E2 경제 부가가치 계산을 재사용.

## T5-5. 손실·부도·보험 시나리오

테스트용 단일 통화: M사가 물품 10단위를 매입했고 출하 후 해상에서 **3단위 파손**, 7단위만 실제 도착했다고 가정한다.
1. 출하 시 M 보유 -10, in_transit +10.
2. 파손 사건: in_transit -3, 유효 손실처리 +3; title/위험부담 계약에 따라 해당 주체 손실 및 보험청구권 발생.
3. 도착 월 stage0: in_transit -7, 실제 수령지 보유 +7. 목적지에 10이 입고된 것으로 계상 금지.
4. 보험계약이 유효하더라도 claim accepted ≠ 돈 입금. 실제 보험료·채권채무와 지급능력이 없으면 자동 현금 증가/상품복구 금지.
5. 매수자가 이미 10단위 분량을 선급했다면 누가 환급/보상 의무를 지는지 delivery/title/risk terms를 통해 결정. 이미 지급된 현금을 임의 원복하지 않는다.

다른 예: 수입업자 B 부도 → A의 TradeReceivable 100 중 실제 회수 30 → 잔여 70 채무·대손정리/보험·보증 이행을 금융/법적 사건으로 진행. B 파산이 A의 기업 재고 100을 자동 복구하지 않는다.

## T5-6. 연산 성능·안정성

- G는 전세계 (국가×국가×기업×품목×경로)의 무조건 매월 전수 스캔을 피한다. 실제 거래가능 시장/상품의 희소 인덱스, 상인별 known_market, 유효 주문·정책·원장 revision의 changed-set을 사용한다.
- TradeOpportunity·GlobalTradeReference·Influence용 무역 집계는 **원장 기반 파생 캐시**로 snapshot+source revisions+valuation rule/version을 고정. 유효 규칙/경로/가격/환율 변화 시 영향 받은 키만 invalid.
- 경로탐색은 F/C-E5의 물리 망이 제공하는 feasible path 목록/용량을 활용하고 G는 동일 수송망을 독자 계산하지 않는다. 동일 목적지에 대한 경로/운임 문의는 revision이 같으면 공유하되 실제 예약은 독립적·원자적.
- 지연된 shipment/매입/대출/기한은 기간별 스케줄 큐로 평가. 오래된 원장 이력 전체를 매월 재생산하지 않는다.
- 정수 수량·Money/fixed-point·checked arithmetic·stably sorted event IDs로 worker 1/N, 저장/불러오기, 재실행의 동등성을 확보한다. seed 없는 비결정적 랜덤/float 합산순서 의존 금지.
- 100년·충격(봉쇄·금융경색·흉작)·대표 기업/시장/POP 부하에서 경과시간·메모리·실제 이벤트/예측오차를 측정. 성공·경기침체/도산은 모형 결과, 음수 재고·이중현금·고아참조는 엔진 오류.
- 단계별 적절한 자원 예약을 소유하는 원장과 단일 StagingWorld의 전체 롤백을 유지한다. 손실사건에 의한 여러 분야 동시 효과가 부분적으로만 커밋되면 금지.

## T5-7. UI 설명·권한 있는 조작

기본 화면은 주요 수출입 품목·부족상품·무역수지·관세/정책, 중요 계약·운송 차질만 요약한다. 상품/시장/국가별 상세 화면에서 아래를 제공한다.

- **행동 전 예상 효과**: 해당 조치로 가능한 수입량 범위·기업원가/이익·정부세수·POP 물가·대체조달/지연 및 국제위기·영향력 위험, 가정/신뢰도.
- **행동 후 실현 원인**: 실제 가격·량·배송·관세 수입과 예상 차이(운송병목, 환전 실패, 조약 발효 지연, 자재품질 문제 등)를 원인 원장·계약/법/이벤트 ref로 드릴다운.
- 경제·군사·외교 영향력을 직접 증가시키는 버튼·추상 리스크 제거 버튼 없음. 플레이어는 실제 투자/관세/조약/재고 확보·군사보급·정부계약 등의 원인 행동만 결정.
- 접근성: PC 호버, 포커스, 터치 환경 지원. 계산 정보는 UI 별도 공식이 아닌 엔진의 관측/예측/원인 trace로 생성.

API: GetTradeRiskExposure(scope, snapshot), GetTradeCreditExposure(actor, currency, snapshot), QuoteInsurance(contract, eligible_coverage, insurer, snapshot), RegisterLossEvidence(shipment, source_event), ProposeInsuranceSettlement(authorized, claim, funding), GetSupplyChainDependencies(region/industry, snapshot), GetTradeStatistics(scope, period, basis, snapshot), ExplainTradeShock(event_or_policy, scope, snapshot).

## T5-8. 불변식·오류·인수

- GT5-INV01 원인 없는 위험 손실/무료 보상·보험 현금/상품 복구 없음.
- GT5-INV02 사고당 물량 손실 총량은 실제 운송중 보유수량 이하, 지급/보상 청구권과 혼동 금지.
- GT5-INV03 은행·보증인·보험사에 유효 계약/지급능력/분개 없는 무료 신용 한도 없음.
- GT5-INV04 동일 채권·담보·보험권을 무근거 이중 자산/회수로 계상하지 않음.
- GT5-INV05 재수출/통관/소유권 이동·상업 서비스·GDP를 동일 거래로 혼합 집계하지 않음.
- GT5-INV06 G 위험평가·H 영향력·국제위기의 상호참조가 단일 원인에 대한 이중 손실/동월 무한 피드백을 만들지 않음.
- GT5-INV07 원장/계약·환율·세계정보 unknown과 실제 0을 구분, 모든 통계의 시점·가격·통화·scope 표시.
- GT5-INV08 캐시 stale/무작위 worker 순서로 실제 체결·원장·세이브 결과가 달라지지 않음.
