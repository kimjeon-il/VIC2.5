# Phase G — 상업·무역 상세 설계 인수시험

> 버전: phase-g-trade/1.0 · 2026-11-04 · **SPECIFIED / NOT_RUN**  
> 범위: G-D0 공통 12개 + G-T1~T5 각 10개 = **62개 명세된 고유 시험 ID**. 테스트 코드를 구현하거나 실행한 것은 아니다.  
> 상위: G-D0, POP-D0~D3, C-D0/C-D4, C-E1~E5, C-P/C-M, D-D0/D-V, E-D0/E-V, F/H 연결 시 F/H 회귀.

## 1. 실행 오라클과 채점 원칙

- 모든 인수 시나리오는 동일 초기 WorldSnapshot + ruleset + seed + commands + event schedule에서 **기대한 원장/상태**와 실제 결과를 비교한다. 시나리오가 '판매이익 증가'라고만 말하고 숫자/원장/시점을 검증하지 않으면 통과가 아니다.
- 동일 상품/돈/인구·노동·설비/운송 capacity의 중복예약 불가, PopulationSlice/Inventory/Ownership/Financial/Fiscal/Market/Customs/Shipment/TradeExecution 관통 원자성, Stage0~11·m+1 효력 및 다른 통화 구분은 **모든 해당 시험의 공통 조건**이다.
- 경제적 적자·재고부족·정치적 제재는 정상적인 모형 결과일 수 있다. 음수재고·유령예금·복식부기 불일치·사후 소급·계약 참조 고아는 HARD ERROR, 잘못된 법적/자금/경로 요청은 명시적 REJECT/부분체결.
- 각 분야가 사용하는 매출/손실/정부세수는 Finance/Inventory/Fiscal의 실제 사건 ref와 정확히 연결되어야 한다. 예측·테스트 편의용 거래는 실물 생산이 아니다.
- 기존 GD0-T01~T12는 G-D0 문서의 기대조건이 정본이고 **시험 ID를 재번호화하지 않음**. 하위 GT1~GT5 50개는 별개의 상세시험이다.
- 실행 시 결과물은 fixture 원본, 빌드·플랫폼·commit SHA·contract versions·seed, 각 테스트 assert 결과, world/ledger hashes, PASS/FAIL/BLOCKED, 중복 이벤트/롤백 결과를 포함한다. 미실행을 PASS로 보고 금지.

## 8. 대표 수치 및 시간 검증

### 8.1 상인 재판매 현금·실물

A의 생산 재고 10 → 상인 M이 1,000에 매입 → 실제 운송·관세 등 150 지출 → 최종 매수인 B에 1,400에 판매:
- 실제 title 이동 A→M→B 및 Inventory 총량 10 보존(소비/손실 없다는 가정).
- 상인 총매출 1,400, 매입원가 1,000, 명시비용 150 → 추가 비용 0 가정 시 단순 순마진 250. 현금 미지급/외상이 있다면 실수령현금과 이익·채권을 구분.
- 철 생산 10만 유지, GDP에 재판매 상품 10을 재생산으로 추가 금지.

### 8.2 관세 미수금과 수입

Shipment 과세표준 1,000, 관세10% → 부과 100, 납부 40, 미수금 60. 납부가 법률상 통관의 선행조건이라면 실제 통관 보류; 보증/후납제도가 합법이라면 별도 조건과 참조를 통해 통관 가능. 세금부과가 정부의 실제 가용 현금 100을 즉시 증가시킬 수 없음.

### 8.3 수송월과 손실

m월 철 10 출하·travel_months=2: m 도착지 재고 0, in_transit 10. m+1 위험사건으로 3 파손: in_transit 7, loss3. m+2 stage0 실제 도착·통관 시 도착지 재고 7. 위험부담자/보험금 지급은 해당 계약/금융 원장 사건으로 별도 검증. **m+2에 10을 자동 입고시키지 않는다.**
