## 최상위 일관성 규칙

1. 기업/사업장·인구수·시장·주문체결·고용·재고/소유·금전/은행·정부재정·운송 원본은 기존 C/POP/D/E(및 추후 F)에 한 번만 존재한다. G는 상업행위·계약 이행과 시장 탐색을 조정하는 독립 시스템이다.
2. 세계시장은 실제 시장의 국제가격/매물 **정보 조회**이지 가상 물품창고가 아니다. 원거리 실물 수송과 기업/은행의 실제 대금 지급을 우회하지 않는다.
3. 경제 활동은 자율적이고 플레이어는 관세·조약·정부조달·투자·인프라 등 실제 원인만 결정한다. 예상/실현 파급효과는 툴팁·상세 조회로 설명한다.
4. **C-E5의 운송/통관/FX 정본은 폐기하지 않는다.** 물류 F와 외교 H 구현 후 기능 소유권 이동이 필요하면 ADR·계약 버전업·마이그레이션/회귀가 선행되어야 한다.
5. 통상협정/통행권/제재의 법적 효력은 [H-D0](../phase-h/H-D0_COMMON_CONTRACT.md), 국내법은 C-P. 무역 정책은 유효 TradePolicyProjection으로 한 번 적용하고 무역의 실제 결과는 G/C/F 원장에 남긴다.
6. 고정 프로빈스·동적 행정구역/주권·시장/관세구역/실효 군사통제는 서로 다른 객체이며, 12단계 월별 원자 커밋·m+1 원칙을 유지한다.

## 다음 구현/통합 순서

G-V 정식 통합 검증 설계·실행이 후속 단계다. 그 전에 GV-L0 계약/원본 감사를 수행하고, T1 상업주체 → T2 시장조회·후보탐색 → T3 계약/선적/결제 → T4 법률·통관·FX → T5 위험·금융·통계 순으로 실제 C++ 엔진에 단계별 연결한다. **G-V 62개 인수, save/load/worker1/N, 1,200개월·대표 인구/국가 부하**의 실제 증빙 없이 DONE 선언 금지.
