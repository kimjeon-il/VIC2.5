# 참고자료와 참고 범위

## 우선순위

1. **Victoria 3 공식 개발자 일지** — POP 중심 경제·생산·소비·정치 연결의 설계 의도. https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-57-the-journey-so-far
2. **Victoria 3 Wiki** — POP 관련 모딩·게임 규칙 및 버전별 설명. https://vic3.paradoxwikis.com/wiki/Pop_modding
3. **Victoria 3의 공개 모딩 데이터 해설** — 직업·건물·생산방식·구매 욕구·상품 대체 규칙 비교. https://vic3.paradoxwikis.com/wiki/Modding
4. **Victoria 2 공식 설명서/위키** — 역사적 비교 목적으로 제한적으로 참고. 엔진·경제 모델을 그대로 재현하지 않는다.

## 중요 구별

- 공개된 위키/모딩 설정은 게임의 모든 C++ 내부 알고리즘과 동의어가 아니다.
- `docs/MONTHLY_RULES.md`의 가격 공식과 시장·재고 결산 방식은 **VIC2.5 독자 설계안**이다. Victoria 3의 원본 수식이라고 주장하지 않는다.
- 실제 패러독스 게임의 저작권 있는 엔진 소스·에셋·설정 파일을 이 저장소에 복제하지 않는다.
- Victoria 3의 업데이트로 계산 규칙이 변할 수 있으므로 추후 특정 버전의 자료를 실제 확인한 뒤 규칙별 출처와 날짜를 별도 기록한다.
