## 3. 수치 Fixture A — 전사·부상 1,000명

파일: [battle_1000.json](examples/battle_1000.json)

- 월초 `PopulationSlice` 현역 1,000명 / 장비(소총) 1,000정 / 실제 탄약 150발.
- stage10 단일 가상 교전: 1,000명 전원 위험집합, 전사 50·일시부상 180·장기 기능손상 70·무손상 700. 탄약 120발 소모.
- 검증식: 결과 범주 합 `50+180+70+700=1000`. 주민수 기말 `1000-50=950`. 군 현역 복무배정 생존자 950, 즉시 전투 적격 700(부상자250명이 당월 전투 불가라고 가정), 탄약 기말 `150-120=30`.
- 군인급여·유족/치료 이전은 법률과 실제 지급 거래 없이는 자동 현금지급하지 않는다. 피해의 자연사/부상 중복 불가.

## 4. 수치 Fixture B — 2개월 보급·의료

파일: [supply_transit.json](examples/supply_transit.json)

- 정부 재정계좌 200(시험통화), 민간 군수품 공급자 60상자, 단가 2, 배송료 10. 실제 지급은 공급자 +120, 운송인 +10, 정부 -130 → 고객예금 합계 200 보존.
- 실제 `m`월 공급자 60상자 출고, `in_transit` 60. `m+1`월은 운송중이라 목적지 의료처치에 사용할 수 없다.
- `m+2`월 실물 55상자 입고, 운송 중 손실 5상자. 실제 이용가능 의료슬롯 25개에서 치료 20건 수행·의약품 20상자 소모 → 목적지 재고 35상자.
- 검증식: `60 = 도착 후 잔존 35 + 실제 소비 20 + 운송손실 5`; 예산 승인·배송 예정만으로 치료 불가.

## 5. 통합 월별/긴급상황 회귀

1. **기본 1,200개월(100년):** 평시 인구·군인/예비군·급여·훈련·장비 재고·연령변동/제대, 예산·재산/부대원장 보존 검사.
2. **동원 충격:** 인구/노동자·군복무·군수수요 변화가 민간 생산·식량/의약품·군수공장·물가·세금·정부부채에 연계되며 시민 POP를 중복 생성하지 않는지 확인.
3. **장기전·군수위기:** 보급망 봉쇄/수송시간 연장/장비 손실이 전투유효병력·소비·사상자·경제/정치적 만족에 끼치는 실제 연쇄를 검증. 패전·군수부족 자체는 오류가 아님.
4. **대규모 사상자·상병:** 질병·전투/장기 손상/포로·실종/송환/유족 보조·의료/재활을 수천/수만 희소 POP slice와 함께 전이, 자연사 중복 방지.
5. **전쟁/점령/국가승계:** 동일 지역의 sovereignty/civil_administration/fiscal_authority/military_control 관계·영토변경·국적/채무/자산/실제 현금·상품 소유 이력 보존.
6. **다중 적대세력/내전:** 정치조직 지지·투표·참여자·실제 배속 군인·부대를 분리하고 전쟁 종료 후 국가/정부/군의 잔존 및 지출/재건 대조.
7. **결정론/성능:** 고정소수점/난수 스트림으로 동일 시드·명령·월별 이벤트 정렬을 비교. 10만/100만 희소 셀, 다수 부대/군수거래의 실제 wall time·메모리/병목 계측. 시험 전 임의 목표 수치 단언 금지.
8. **세이브/재시작/이식:** POP/공통/경제/군사 schema·ruleset/numeric policy/시드/스냅샷·journal/last_commit_id 함께 검사. 중복 이벤트/잘못된 타입/타국 권한 명령은 거부하고 필요 시 명시적 migration.

## 6. 설계/구현 판정

- **설계 통과:** 문서 M1~M5 + 각 게이트 + CM-INV-01~16/CM-T01~30 + 2개 수치 fixture가 서로 모순되지 않고 C-D0 12단계·POP-D2를 준수.
- **실제 구현 통과:** C++ 전체 `StagingWorld`에서 30개 시험 및 전역 원장 불변조건 성공, 장기/부하/병렬·저장·복구 결과 보고. 문서가 존재한다는 이유로 구현 테스트 PASS를 주장하지 않는다.
