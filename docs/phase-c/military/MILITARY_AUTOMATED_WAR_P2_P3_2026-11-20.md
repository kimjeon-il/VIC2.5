# VIC2.5 P2/P3 — 전투 개입을 줄이는 자동 작전 및 종전

기준: 2026-11-20, `work/military-automatic-operations-p2-p3-20261120`, P1 평시 군사정책 브랜치 후속.

## P2 지상군 자동화

- **동적 전선:** 기존 H 영토 분쟁 주장에 더해 E의 실제 **이웃 프로빈스** 사이에서 C의 서로 다른 교전국 군사통제가 마주하는 곳을 매 일간 작전 시 파생한다. 별도 전선 저장/영토 장부 없음.
- **전선 배분:** 교전국별 다중 출발점 BFS 한 번으로 최단 실재 경로를 찾는다. 지상군은 하루에 인접 프로빈스 하나만 이동하며 모든 부대가 같은 전선당 이동 제한으로 묶이지 않는다.
- **지휘 판단:** 현지의 유효병력/탄약·실장비·훈련/교리를 참고하여 우세할 때 진격, 열세일 때 방어 및 인접 아군 실효통제 지역으로 후퇴한다. 아군 병력이 약하다고 없는 장군/병력/장비를 생성하지 않는다. 무탄약 부대도 유효한 후퇴 경로는 사용할 수 있다.
- **전투:** 같은 지역에 배치된 실제 적군을 복수 쌍으로 자동 교전시키되, 같은 부대의 중복 교전은 당일 차단한다. `p0::fight` / C POP 사상자·탄약 소모의 원장 경로만 사용한다.
- **보급:** 기존 P0/P1의 F/G 자동 실탄 보급과 실제 재고·운임·운송일수·간선용량을 그대로 사용한다. 무장 없는 군대의 자동 외국 진격은 허용하지 않는다.

## P3 해군·공군·상륙

- **해전:** E에서 **같은 유효 해역을 공유**하고 실전쟁인 국가의, 실제 C 군인 승조원+P1 등록 취역함+탄약+연료를 가진 함정만 해전 수행. 전투 결과는 C 군인 사상자·재고 소모와 P1 실제 함체 HP에 반영한다.
- **봉쇄:** 유효 해역에서 위 조건을 갖춘 적대 함대가 우세하면, 동일 해역의 검증된 F/G **해상 화물 간선**을 실제 전쟁 기간 동안 제한한다. 별도 포인트나 허구의 함대는 쓰지 않는다.
- **항공전·지원:** 실제 항공 군종 POP+배정된 항공기+연료·탄약으로 인접 지역 항공 교전. 제공권은 실가용 항공기 수로 계산하고, 실제 비행 물자 소모 이후에만 육상전 지원 효과를 부여한다.
- **상륙:** 실재 원정 육군, 동원 가능한 실승조원 함선, 지급된 `landing_berth` 수송능력, 연료·탄약, 같은 E 해역, 출처가 있는 **직통 1일 해상 운송서비스** 및 점령할 실제 주장 영토가 있을 때에 한정. 보호 없는 제3국 또는 교전 준비 없는 장거리 순간이동 금지. 다일 항해/상륙 전투/수송 중 육군 손실은 아직 미구현.

## 종전·전후

- 자동 휴전 및 영구 강화는 실제 전쟁의 마지막 교전·군사력 상태에 기초하여 기존 H의 상호 비준·시차를 따른다.
- 정식 강화 조건의 영토할양은 **유효한 E claim, 실제 C 군사점령, 상대보다 우세한 잔여 육상전력, 법적 인수 행정단위**가 있을 때만 H의 기존 영토할양 조항/차월 E 관할 변경을 이용한다.
- 기존 C 법적 배상채무는 P0가 매일 사용 가능한 국고 범위 안에서 일부 상환한다. 없는 전쟁배상금·주권·인구·현금을 자동 생성하지 않는다.
- 평화/휴전 뒤 외국 내 부대는 실제 인접 아군 통제의 경로로 하루 한 번씩 국내 복귀하며, P1 상비군 목표에 따라 현역을 별도 제대 처리한다. 물리적 시설 복구는 기존 C/D 보수·건설·고용·재고에 따른다.

## 검증과 명시적 제한

`tests/test_p0_daily.cpp`에 실제 인접 육군에서 자동 선전·전선진격/교전 및 별도 해공군 원장·해상 봉쇄를 검증하는 합성 시나리오를 추가했다.

**미완성/제한:** 지휘관 개인 특성·명령통신, 다국적 연합지휘, 선박별 전술/손상 부위, 항공기 개별 파손/활주로·비행거리, 장거리 상륙 수송시간, 포로·민간인 전후 행정 송환, 역사 시기별 군사 성능 계수의 출처 보정, 대규모 세계 지도와 100년 전쟁 스트레스 인수. 이 단계는 실제 POP/물자 소비가 있는 **범위 제한 자동화 기능**이며 완전한 군사 역사 시뮬레이터 최종 인수 판정은 아니다.
