# 군사 P0 — 일간 전투·보급 및 준비태세 정본 (2026-11-20)

기존 M1~M5의 월간 **실행 시간 명세**를 현행 일간 엔진으로 대체한다. POP·실물 재고·금융·영토 원장과 하루 12단계 원자성은 유지한다.

- `p0::DailyGame::advance_day` → `daily::World::advance_day` → C/D/E/F/G/H 일간 원자 커밋. 별도 월말 군사 실행 없음.
- Stage7: `phasef::plan_army_supply`가 실제 부대 탄약 수요, 운송 중 물량, 지역 내 즉시 지급과 검증된 직통 노선 수송을 단일 임시예약으로 계획한다. 민간 화물과 재고·간선용량을 공유하며 실물/자금은 기존 C/G 정본을 사용한다.
- Stage10: 수동·자동 교전 모두 `p0::fight`를 사용하며 `IntegratedWorld::battle`만 인구 사상자·탄약 소모를 기록한다. 별도의 월간 피해 계산은 실행하지 않는다.
- `MilitaryReadiness`는 실제 현역 배속 인원·탄약·소총/머스킷/소화기 배정의 읽기 전용 파생 조회다. 참여 POP의 수를 넘지 않게 제한하며 전투·전선 위협·행군/점령·보급 수요에서 공통 이용한다.

**잔여:** 훈련·교리·사기·지휘·피로·식량/유류/정비/의료, 시대별 수치 보정, 해공전은 미연결이다. 현재 전투력 프록시는 완성형 전투모형이 아니다. 인수시험 전수·100년 장기·성능 검증도 별개다.

**검증:** `tests/test_phase_c.cpp` 기존 편제 검사에 기본/혼합 무기 준비태세 검증을 추가했다. 이번 변경의 C++ 빌드 및 CTest는 실행하지 않았다.
