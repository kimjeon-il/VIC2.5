## 연산의 상위 규약 및 미래 옵션

- **고정:** `PopulationSlice`·Financial/Inventory/OwnershipLedger 단일 정본, 월간 12단계, 명령/사건/분개, 정책 m 채택→원칙 m+1 발효, 신규동원 월말→차월 근무, 정수 보존식, 결정론적 배분, stage11 통합 커밋.
- **후속 조정 가능:** 전투 세부 확률/훈련 효과/지형·기상/전시동원 계수, 시대별 군종/병역/부대 편제·장비 사양, 포로교환·구호 효과, 전쟁 종료 협상모형, 월중 서브틱/일자, 실제 지도/해군항로 등의 공간 데이터.
- 미지정 계수는 0 또는 실측값으로 자동 채우지 말고 `unknown/estimated`, `source_provenance`, `ruleset_version`과 함께 보존한다. 테스트용 정수 수치는 `fictional_test_value`로 기록한다.

## 우선 구현/이식 순서

1. Phase B 인구·건강/복무 `PopulationSlice`/Event를 금융·고용·재고·소유와 함께 처리하는 단일 StagingWorld 완성. 12단계/중복사건/rollback 테스트.
2. M1 군민 상태/징병·모집/제대/예비군 고용 인터페이스와 병역법 의존성.
3. M2 부대/편제/EquipmentAssignment/Asset·Inventory 상태/지휘권과 실제 인원·장비 가용 조회.
4. M3 군수기업·정부예산·재고·E5 Shipment의 복합 원장 결제/입고·수송기간.
5. M4 단계10 실제 작전/사상자/탄약소모/회복과 단계11 최종 결산·재현성 검증.
6. M5 실제 전쟁/점령/종전·군축/배상/복구 및 정치·외교 연동.
7. [군사 인수시험](MILITARY_ACCEPTANCE_TESTS.md) 30개+기존 C-D0/POP/경제 회귀·100년/대규모/멀티스레드/Windows/MSVC save-replay 테스트.

**완료:** C-M1~M5 설계·수락기준. **미완료:** C++ 엔진 개발, 역사계수 보정, 군사/경제/정치 통합 장기 검증.
