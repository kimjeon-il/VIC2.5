# VIC2.5 평시 군사 P1 — 정책·상비군·예비군·군종·군비·훈련·교리·정비·비축

**2026-11-20 · 현행 일간 12단계 정본**

## 운영 원칙

플레이어는 국가별 군사정책과 예산, 부대별 목표 정원·군종·교리·장비·비축 목표를 정한다. 실제 국가 AI는 상비병력 충원/제대, 지역 예비군 등록, 시장에서 실물 군수품 매입·부대 지급, 유급 교관 훈련, 부품을 사용하는 정비를 자동 처리한다. 국고·민간 판매자·실제 POP·시설/재고·육상 실전 원장에 신규 독립 재고를 추가하지 않는다.

## 실제 C++ 구현

- `phasec::PeacetimeMilitaryProgram`: 국가·부대·군종(`army/navy/air`), 교리(`balanced/offensive/defensive/maneuver`), 상비군 목표·지역 공용 예비군 목표, 일간 충원 한도, 장비·탄약·수리부품 목표, 일간 조달량·훈련·정비량과 국고 한도·훈련/정비 인건비 등 **정책**. 역사 초기상태에서는 `set_peacetime_military_program()`으로 등록, 이후 합법적 총리가 Stage9에 변경 가능.
- `PeacetimeMilitaryState`: 검증 가능한 유급 실탄 훈련의 숙련도와 실제 지급 장비의 마모 상태. 실병력은 `PopulationSlice`/C ServiceAssignment, 장비·탄약은 C InventoryLedger, 조달자금은 C FinancialLedger가 유일 정본이다.
- **Stage7:** `peacetime_military_support`가 부대 현재 지역 내 현물 재고를 우선 받고, 실제 시장가격·공급자 상품·국고 잔액으로만 부족분을 구매한다. 무기 배정은 실제 보유 재고로 제한. 훈련은 현역 병력·사용 가능 장비·실제 탄약·교관 급여가 있어야 숙련도를 올리고, 유지비가 없는 경우 서서히 감소한다. 정비는 실제 `spare_parts`와 유급 기술지원이 필요하다. 훈련·전투에 따른 장비 마모는 실제 작전 가능 무기량을 낮춘다.
- **Stage10 맨 마지막:** `peacetime_military_staff`는 실제 POP 인구와 유효 징병법·동원 한도에서 `reserve/civilian → active` 및 초과 현역 `active → reserve`를 수행한다. 지역 예비군은 기존 민간 고용을 유지할 수 있고, 여러 부대의 지역 목표는 공용 풀 최대값으로 처리해 중복 계수하지 않는다. 같은 날 이미 끝난 교전은 새 병력을 소급 사용하지 않는다.
- **군종 분리:** 해·공군 편제의 평시 정책·조달·훈련은 존재하지만 가상의 해전·항공전은 발생시키지 않는다. 해군·공군 소속은 지상군의 전선 행군·육상 자동 교전·점령 판정에서 제외한다.
- `MilitaryReadiness`: 실제 배속·탄약·장비·마모·훈련 숙련과 교리의 **파생 능력**. 교리의 전투 효과는 실제 누적 훈련이 있어야 발현하며, 교리 변경 시 기존 숙련 일부가 감소한다.
- 저장: 기존 Phase C 스냅샷의 선택적 `VIC25_PHASEC_PEACETIME_MILITARY_1` 확장, 상위 C/D/E/G/H 일간 스냅샷을 통한 재생. 다른 POP/금융/재고 원장 데이터와 중복 저장하지 않는다.

## 명시적 P1 한계

군종 편제는 기존 Formation/Unit 위에 군종 태그를 부여한 초기 범위이며, 해군·공군 전투·전용 수송·항만/비행장·동맹작전은 P2 이후 영역이다. 군수 구매는 배치 지역의 확인된 공급자/시장에 한정되고 원거리 보급은 기존 F/G 유효 운송 경로에 의존한다. 상비군의 상세 군급료·병영/훈련시설 수용량·시대별 교리/훈련 계수·예비군 장기복무/제대법·완전한 자동 군사산업 투자·군함/항공기 정비 고유 부품·P1 국가 총예산 최적화는 아직 구현하지 않았다.

`tests/test_p0_daily.cpp`에 유료 조달·교관/훈련·인구 및 예비군 전이·저장 재생, 국고 0과 해군 지상전 배제 2개 합성 시나리오를 추가했다. 본 작업에서 전체 CMake/CTest·성능/장기 실행은 별도 검증하지 않았다.
