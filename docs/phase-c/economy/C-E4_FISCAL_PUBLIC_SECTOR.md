# C-E4 — 조세·정부재정·공공부문 상세 설계

- 상태: **설계 확정 / 구현 전** · 경제 계약 `phase-c-economy/1.0`
- 상위: [C-D0](../C-D0_COMMON_CONTRACT.md), 연계: [E1 생산](C-E1_FIRMS_LABOR_PRODUCTION.md), [E3 금융](C-E3_HOUSEHOLDS_FINANCE_INVESTMENT.md), [E5 무역](C-E5_TRANSPORT_INTERNATIONAL_TRADE.md).
- 정치 영역의 **제도·권한·법률 제정**은 C-P에서 구현하되, 경제 영역은 유효 법률을 적용한 **과세 의무·실제 현금/현물 납부·서비스 공급**을 계산한다.

## E4-1. 국가·정부·재정 주체의 분리

| 객체 | 최소 필드/역할 |
|---|---|
| `Treasury` | treasury_id, government/agency_id, currency_accounts[], debt_accounts[], fiscal_period, accounting_policy |
| `FiscalAuthority` | authority_id, governing_law, tax_types[], geographic_scope, enforcement_capacity, valid_period |
| `Budget` | budget_id, authority, month/financial_year, appropriation_lines[], forecast_revenues[], debt_service_plan, revision |
| `Appropriation` | program, legal_authority, spending_limit, effective_period, available_budget; 지출 허가이지 실제 현금 아님 |
| `TaxRule` | tax_id, legal_basis, assessment_subject, tax_base, rates/brackets, exemptions, jurisdiction_rule, due_schedule |
| `TaxAssessment` | assessment_id, tax_id, taxpayer, source_transaction_or_period, assessed_base, liability, due_month, status |
| `BenefitEntitlement` | entitlement_id, recipient_owner_or_slice_partition, law, eligibility, assessed_amount, due_month, status |
| `PublicInstitution` | institution_id, operating_government, service_type, location, staff/asset refs, capacity/rule |
| `GovernmentBond` | issue_id, treasury_id, currency, principal, coupon_rate_rule, maturity, holders, priority |
| `FiscalRecord` | source_event_id, authority, line_item, assessment/release/payment_reference, unpaid_balance |

**정부예산, 발생주의 세입·세출, 실제 국고 현금의 차이**를 유지한다. Budget의 집행한도는 돈 자체가 아니다. 실제 국고 계좌·국채채무·과세채권은 FinancialLedger에 있고 FiscalLedger는 법적 원인·부과·승인·납부 의무를 기록한다. 정부는 지역 인구·자산·기업원장을 읽을 뿐 쓰기 가능한 별도 주민수 원본을 갖지 않는다.

## E4-2. 관할권/적용법

1. [C-D0 TerritorialJurisdiction](../C-D0_COMMON_CONTRACT.md)의 주권(sovereignty), 민정(civil_administration), 과세권(fiscal_authority), 군사통제(military_control)를 구분한다.
2. 세금마다 `jurisdiction_rule`가 과세지역·거주/국적·소득원천·소유지·통관지/소비지의 근거를 지정한다. 한 지역이 복수 과세기반에 참여할 수 있으나 같은 `tax_id + taxable_event + tax_subject + authority`를 동일 기간 두 번 부과하지 않는다.
3. 이중과세 방지/면제/종속령 분배/연방-지방 세수 배분은 법률/협약과 실제 이전지출로 표현한다. 국가가 행정구역을 통치한다는 이유로 모든 세수의 현금이 중앙 국고에 자동 합산되지 않는다.
4. 영토의 군사점령이 곧 합법적 과세권 이전을 뜻하지 않는다. 점령지 징발/군정 세금은 해당 정책 및 별도 자산·재고/금융 사건으로 처리한다.
5. 법률 통과월 m의 새로운 조세·혜택 규칙은 원칙적으로 m+1부터 발효. 소급된 의무/환급은 새 월의 명시적 정정·보상사건이 필요하다.

## E4-3. 세목과 부과 기준

| 세목 | 과세 기준과 발생 시점 | 실제 원장 처리 |
|---|---|---|
| 근로소득세 | 급여계약/실제 임금과 법적 공제 적용, 단계 5 | 근로자 순수령 + 원천징수 정부계정의 대응 분개 |
| 기업 이익세 | 결산 순이익/과세소득과 공제 규칙, 단계 8 | 납세채무 발생; 단계 8 또는 차기 기한에 실제 지급 |
| 소비세/판매세 | 실제 체결·인도된 최종 소비거래, 단계 7 | 판매자/구매자/정부 세금지급·세금채무 연동 |
| 관세 | E5 실제 통관 지점과 품목·원산지·협정, 통관 단계 | CustomsAssessment → Financial 지급/채무 |
| 재산세/토지세 | Ownership의 유효 소유권·평가 자료, 해당 기간 | 소유자별 납세의무와 실제 현금 납부 |
| 인두세/역·현물세/십일조 | 법적 적격 인구·생산량 또는 자산, 시기별 규칙 | 인구를 추가 생성하지 않음; 현물은 InventoryLedger로 이전 |
| 사회보험 기여 | 적용 고용·급여/사업소득 | 정부/기금 채권, 실제 금융 지급, 법정 기여·수급 분리 |
| 국영기업 배당 | 정부의 실제 Ownership 지분·선언된 배당 | 기업→국고 실제 지급 시에만 세입 |

`TaxAssessment` (부과), `TaxPayment` (납부), `TaxArrears` (체납), `TaxRefund` (환급) 객체를 구분한다. 역사적으로 직접세 징수가 어려운 국가를 표현하기 위해 집행역량·면제·회피·부패·체납·징수비용 등을 **관측 가능한 비율/사건**으로 처리한다. 행정역량이라는 추상 점수만으로 돈을 발행하지 않는다.

**VAT 등 다단계 거래세:** 과세체계별로 입력세액 공제·면세·영세율·납부기한을 명시. 소비 단계에서 일괄 소비세를 이미 징수했다면 동일 거래에 같은 세금을 기업 결산에서 재차 부과하지 않는다. 이윤세는 매출 총액에 기계적으로 적용하지 않고 유효 과세소득을 기준으로 한다.

## E4-4. 단계별 수납/집행 절차

**단계 0:** 적용 법률·기존 국채의 이자/원금 만기, 이미 확정된 연간/월간 예산·미지급 의무·세금체납을 스냅샷으로 고정한다.

**단계 1:** 정부는 예산 허가와 실제 보유잔액·세수 예상·실행 가능한 차입을 근거로 월간 `SpendingPlan`을 만든다. **세수 예상은 즉시 가용현금이 아니다**. 지출재원 예약·필요한 국채 발행/신용 인출이 실제 확정되면 그 금액만 당월 사용 가능하다. 정부기업 계약·급여·복지·군사조달의 예산 항목을 분리한다.

**단계 2~4:** 공무원·교사·의료인·군수공장 등 공공 고용과 정부 직영 생산은 민간 경제와 **같은 노동력/설비/재료 병목**을 겪는다. 공공 서비스가 명목 예산만으로 자동 생산되지 않는다.

**단계 5:** 공무원·현역 급여·복지 현금 이전·원천징수 세금 등의 확정 실제 지급. 수혜자 적격성은 단계 0 유효 법률과 현재 사건 참조로 검사한다. 당월 지급불능이면 체불/지급연기 또는 별도 합법적 신용계약으로 처리하고 혜택 지급 성공으로 표시하지 않는다.

**단계 7:** 실제 정부재 구매와 건설/군수/서비스 조달; 재고·인도·금융결제·납세채무를 연계. 공공서비스는 실제 인력·물자·시설에서 공급량을 도출하고 주민이 실제 사용한 서비스량을 기록한다.

**단계 8:** 세금발생·징수, 미수금·체납, 채무·이자/원금 지급, 국채 보유자 명부, 부채잔액, 현금·발생주의 재정실적, 공공기관 재무 결산.

**단계 9:** 다음 월 예산·세율·새 채무조달 정책을 준비한다. 정치에서 월 m에 새로 채택한 법은 별도 지정 없이 m+1부터 적용.

**단계 11:** 정부금융계정과 금융기관/납세자 대차대조표의 교차 검증 및 월말 커밋.

## E4-5. 국채·적자·국가 신용

- 국채는 `issuer` 정부의 FinancialLedger **부채**와 보유자의 동일 금액 금융채권 및 Ownership 등록이 함께 존재해야 한다.
- 발행 대금이 실제 국고에 입금됐을 때에만 새 집행재원이다. **미매각 국채 발행 계획 ≠ 현금 증가**.
- 예산 적자 = 해당 기간 수입·지출의 회계적 차이. 현금 부족(유동성), 국가채무잔액(스톡), 부도(채무이행 실패)는 서로 다른 상태다.
- 차입 금리/수요는 정부 신용위험·화폐·금융기관·법적 제도·전시 상황·정책 규약의 함수로 둔다. 과도한 적자라고 자동으로 화폐를 생산하거나 전기 세금을 소급 징수하지 않는다.
- 중앙은행 인수/국채 매입·화폐발행을 표현하려면 **통화당국 자산·부채/준비금 변동과 실제 정부계좌 증가**를 함께 분개한다. 단순 `print_money(+N)` 버튼을 원장 외부에 두지 않는다.
- 정부가 이자를 미지급하면 연체채권, 기한조정, 채무 재조정, 부분 디폴트/인플레이션세와 같은 **서로 다른 사건**으로 다룬다. 채권자/은행/POP 자산이 임의 사라지지 않도록 대응 손실을 기록한다.
- 국가가 바뀌거나 정부가 교체돼도 국채를 자동 소각하지 않는다. 국가 승계·채무 인수/거부는 역사적 조약·법률 및 별도 Financial/Ownership 사건.

## E4-6. 공공서비스와 이전소득 구분

- 복지 이전/연금: 지급액은 가계의 실제 구매력 증가이지만 실물 재화를 자동 생성하지 않는다. 이전지출 자체를 GDP 최종생산으로 중복 계산하지 않는다.
- 교육·의료·치안·행정: `PublicInstitution`의 고용·실제 물자·시설/접근성·서비스 이용량이 교육/보건/정치 등 모듈에 전달된다. 의료시설 없이 의료예산만 있으면 치료를 성공 처리하지 않는다.
- 주택·도로·철도·항만·군수창고: 투자재 구매·건설공기·자산 형성/마모를 거치며 E5 운송능력/인구 생활환경에 반영한다.
- 정부가 공급자에게 구매한 상품/서비스·공무원 실제 제공 서비스는 회계 기준에 따라 생산/최종소비 또는 투자로 분류한다. 정부 예산 전체를 민간 GDP에 다시 더하지 않는다.
- 공적 공급의 부족 시 수혜자별 충족/미충족, 대기, 차별적 권리의 법적 근거를 남긴다. 행정역량과 재정여력은 실제 공급량에 영향을 미치며 바로 POP 정치 상태를 임의로 바꾸지는 않는다.

## E4-7. 통계와 외부 모듈

세입(발생·수납), 직접/간접세·관세·현물세 비중, 체납/징수 비용, 예산 대비 집행, 당기 재정수지, 실제 현금잔액, 국채발행잔액·이자부담, 공공 고용/생산능력/서비스 충족률, 지역·계층별 세부담률. 정치 시스템은 정책/선거 반응에 이러한 관측치만 읽고 별도 세입을 생성하지 않는다.

## E4 검증 게이트

- E4-G1: 임금총액 100/원천징수 10이면 정부 10·노동자 90으로 한 번만 배분.
- E4-G2: 예상 세입 100, 국고 잔액 0, 실제 차입 0이면 당월에 100을 임의 지출할 수 없다.
- E4-G3: 국채 100 발행·전액 인수 → 국고 지급가능잔액 +100, 정부 부채 +100, 투자자 현금 -100·채권 +100.
- E4-G4: 예산 승인 100은 실제 급여/조달 100 지급 또는 서비스 공급을 자동 뜻하지 않는다.
- E4-G5: 영토 점령·국가원수 교체·정권교체 후에도 유효 세금/채무의 이력·승계사건이 보존된다.
- E4-G6: 복지급여는 실제 가계 수입으로 반영되지만 상품수량과 GDP를 생성하지 않는다.
- E4-G7: 공공의료·교육은 노동·시설·재고/서비스 슬롯 제약을 넘지 않는다.
- E4-G8: 현물세 5단위는 실제 납세자 재고에서 정부 보유재고로 5단위 이전된다.
- E4-G9: 소비세/VAT/관세는 거래별 법적 원인과 금융현금 이전·채권으로 맞고 이중 과세가 아니다.
