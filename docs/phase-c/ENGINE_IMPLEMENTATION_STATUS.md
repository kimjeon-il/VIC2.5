## 작업한 실제 C++ 코드

1. `work/pop-phase-b`의 실제 Phase B `PopulationSlice`, 건강/교육/이주·노동, POP-I1~I4 및 CMake/테스트/벤치 구성 **12개 파일**을 `main`의 C-D4 기준 위에 Git tree로 이식. 인구를 별도 복제하는 새 POP 구현 없음.
2. [`include/vic25/phase_c.hpp`](../../include/vic25/phase_c.hpp): `vic25::phasec::IntegratedWorld`가 원래의 `phaseb::World`(인구·계약), S0 `FinancialLedger`(복식부기), `InventoryLedger`(실물량), `OwnershipLedger`(지분/채권증서)를 포함하고 **12단계 월간 StagingWorld 복사→검증→한 번 commit**을 수행.
3. 실제 실행되는 기능: 고용/원료 투입·산출/거래·가계 소비, 임금 총액·원천징수 및 소득세법 차월 발효, 은행 대출/원금상환(예금부채·대출채권 대응), 유가증권 보유/대금 교환·배당 선언/후속 지급, 실제 인수대금이 있는 국채 발행, 정부 현금 구매·물류 2개월 운송/손실/도착, 정수 D'Hondt 선거·선거권법 차월 적용, 징집법 유효 여부/현역 POP 동원 및 민간 일자리 상실, 실제 POP-D2 전사/일시부상/장기손상·탄약소모·군사적 점령권(주권 별개).
4. 외부 명령의 중복 ID 거부, 서로 다른 원장의 오류 주입 시 **월 전체 롤백**, 단계별 유효시간 검증, 도착 전 상품 소비 차단, 은행 예금 부채-고객 잔액 대응, 재고 보존, 유가증권 원장과 금융계정 수량 대조.
5. C++ 선거 의석 계산에서 `__int128` 사용을 제거하고 **정확한 정수의 연분수 비교**를 도입(Windows/MSVC 빌드 목표). 병렬 worker 결정론은 아직 실제 병렬 런타임에서 검증하지 않았다.

## 실제 테스트 범위와 결과

- [`tests/test_phase_c.cpp`](../../tests/test_phase_c.cpp)는 **C-D4-T01~48 번호를 모두 출력**한다. 하지만 **PASS 27 / BLOCKED 21 / FAIL 0**인 *부분 구현 범위*이다. `BLOCKED`도 현재 테스트 바이너리에서는 명시적으로 출력하며, 테스트 자체의 프로세스가 0으로 끝나는 것이 **48개 전부 통과를 의미하지 않는다**.
- 실제 검증 가능한 T-ID: `01,02,04,08,09,10,13,14,15,16,18,19,20,25,26,27,29,30,31,32,33,34,38,41,42,43,44` (**27개**).
- 미구현/미검증 T-ID: `03,05,06,07,11,12,17,21,22,23,24,28,35,36,37,39,40,45,46,47,48` (**21개**).
- [`tests/test_phase_c_longrun.cpp`](../../tests/test_phase_c_longrun.cpp)는 실제 Phase B의 내생 출생·사망·교육·건강·노동 변동을 월간 경제·금융·실물 재고·임금/세금·선거·은행 원금상환에 연결하여 **1,200개월×2회** 동일한 명령/초기 상태에 대한 POP fingerprint·현금/재고·ordered journal의 결정론을 검사한다. **전면적인 정치·군사작전·동적 가격/기업부도·다국가 경제위기까지 1,200개월 검증한 것은 아니다**.
- CI: [GitHub Actions `phase-c-cpp.yml`](https://github.com/kimjeon-il/VIC2.5/actions/workflows/phase-c-cpp.yml) — CMake/C++20·CTest. 최초 Ubuntu GCC 15에서 기존 S0/Phase B+신규 Phase C 테스트 **6개 CTest PASS**를 확인했으며, 이후 Linux/Windows/macOS 매트릭스를 추가하여 교차 플랫폼 후속 결과를 시험한다. 아래 보고의 실제 통과 여부는 해당 SHA의 CI 로그를 확인해 판정한다.
- 100만 POP 장기 실행, 외부 저장·불러오기, 주권/의회/정당·시위·반란 및 정식 군대 편제·보급·전쟁/조약, 다통화 교역은 **미구현 또는 미검증**. GitHub 브랜치/프로세스에서 `D4-DONE`이라고 표시하지 않는다.

## 주의할 수치 보정

초기 [C-D4 선거·동원 fixture](integration/examples/cross_domain_reform_mobilization.json)의 `600+50=650` 기대치는 같은 달에 선거권이 있던 예비군 40명이 다음 달 **현역으로 전환되어 선거권을 상실**하는 조건을 누락했다. 해당 조건을 유지한다면 차월 선거권자는 **600+50-40=610명**이다. 통합 엔진 테스트 및 이 브랜치의 D4 문서/JSON 기대값을 바로잡았다. 전사10명은 현역·기존 선거권 없음으로 잡았다.
