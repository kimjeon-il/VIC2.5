## 2. 현재 구현한 연동

- **POP·고용:** 실제 희소 `PopulationSlice`, 인구/건강/교육·병역 상태, 인구 변화, 실질 주된 고용계약과 전이/동원·전사/부상 상태 연결.
- **경제:** 실제 생산·중간투입·상품/현물가계 생산/소비·매출·임금/원천징수·은행대출·상환·부도 상각/지급제약, 주식·배당·국채·명시적 이주 재산배분, 지역별 지불가능 주문과 부족분·차월 가격, 복수 통화 원장 및 실제 상대방 유동성을 가진 쌍방 환전, 운송중 재고/도착/손실.
- **정치:** 국가/정부·국가원수/총리·정족수·내각 구성과 차월 효력, 선거권/선거·정수 D'Hondt 의석, 개인 투표 앵커와 중복 투표 거부, POP 이익집단/시위/다음달 파업 노동 감소, 소득세·병역법 및 보건서비스 법 발효, 실제 자원·급료·의약품에 제한된 공공 의료서비스.
- **군사:** 실제 인구 현역·예비군 동원/제대와 민간 일자리 변화, 부대/상급 편제/실물 장비 배속, 탄약 소모·전투/사상자·포로/실종과 POP 보건, 점령 군사통제/주권 분리, 전시 시설 피해·자재+노동에 근거한 차월 재건, 조약 배상채권/채무·부분지급.
- **공통:** 통합 12단계·월 전체 staging→검증→한 번 commit, 외부 command_id 중복 방지, 크로스원장 실패 롤백. 버전 표시 바이너리 세계 스냅샷/체크섬, 저장→다시 읽기→동일 사건 재개 및 손상 파일 거부.
