# VIC2.5 C-P3 + C-P5 — POP 정치, 이익집단, 장기 운동 및 불안정·혁명 구현 기록

**작업 브랜치:** `work/p3-p5-politics`  
**기준 브랜치:** `work/p2-politics-completion`  
**상태:** 실제 C++ 구현·저장·일간 연결·집중 회귀 사례를 추가했으나 **컴파일·CTest·CI·장기 성능 측정은 미실행(UNVERIFIED)**. `main` 미병합.  
**목표:** Victoria 3의 POP 정치·이익집단·정치운동·혁명 구조를 전략게임 수준의 시스템으로 통합하고, 기존 Phase B POP, C 정부/재정/물자, P1/P2/P4 정치, C-M 군사 원장의 단일 정본을 유지한다.

## P3-A — POP 정치성향과 실제 사회경제 충격

- `P3Attitude`(실제 Phase B `Slice` ID에 대한 참조)에 급진화/충성/관심도/쟁점별 선호·중요도·최근 관측일 저장. 정치용 별도 인구원장 없음.
- `p3_daily_react(today)`: 기왕에 조직된 실제 POP와 명시적으로 추적 중인 태도·식량 부족을 경험한 POP만 조회. 실제 실업(동일 POP 고용계약), 식량 결핍(P0/C 실제 관측)에서 급진화 변동. 반대 조건의 완화·일간 관성 적용.
- 성별·문화·종교·직업을 고정 이념으로 치환하지 않음. 법률/사건·가계 경험과 명시적 사료/시나리오 선호만 쟁점에 연결.
- `p3_reconcile_population`: Stage10 실제 인구의 사망·이동·고용변화로 더 이상 존재하지 않는 POP 정치 참조를 제거·상한 보정. 인구를 새로 만들지 않음.
- 100만 POP 세계에서 한 운동만 있어도 무조건 전 세계의 정치 상태 사본을 만들지 않도록 **실제 가입, 명시된 쟁점, 결핍 지역 중심의 희소 계산**. 인구 변경 없는 날도 날짜별 단일 커밋.

## P3-B — 실제 이익집단의 정치력과 만족도

- 빅토리아 3의 8개 기본 유형(지주·기업가·군부·종교·지식인·소시민·농촌민·노동조합)을 `P3GroupType`으로 제공하며 `custom` 데이터 유형 허용. 타입 이름으로 선천적 정치성향 설정 금지.
- 국가별 `P3Group`은 기존 C `interest_groups_`의 이름·실제 회원, P1 집권 집단, 선택적인 실제 `PersonAnchor` 지도자와 P2의 법률 쟁점을 참조. 원본 집단/정당·POP 복제 금지.
- `p3_group_view`는 실제 중복 가능 가입 인원과 해당 집단의 조직화 정도, 실제 P1 내각 참여를 이용해 정치력(clout)을 도출. `approval`은 시행 중인 P2 기본법과 해당 집단의 정책 선호, 구성원의 관측된 급진성에 반응.
- P1 `p1_legitimacy`는 P3 프로필이 있는 국가에서 실제 집권 집단의 정치력 비중을 사용하고, 구형 비활성 P3 세이브는 기존 회원 기반 계산을 유지.
- 한 이익집단→한 정당 제한 없음. P4는 P3 실제 집단 가입과 정치운동 쟁점 중요도를 선거 가중치에 반영하되 정당 득표·의석의 실제 선거 원장은 독립.

## P3-C — 장기 정치운동

- `P3Movement`가 국가·쟁점·요구하는 정책·기초 이익집단 여러 개·복수 정당·지역 범위·목표(개혁/현 체제 방어/정부 교체/자치/분리)를 가짐.
- `p3_movement_view`는 이미 존재하는 POP의 집단 가입 또는 쟁점별 실제 선호를 읽어 지지자 수를 추정한다. **중복 이익집단 가입이 있더라도 POP별 최대 지원 배정만 합산**, 실제 지지자/활동 가능 인원/거리 참가자를 구별.
- 활동성·급진성은 운동 자체의 지속된 목표에 더해 구성 POP의 경제 충격에서 관측된 태도가 반영될 수 있음.
- P2 기존 이익집단 법안 증보 협상·P4 정당 경쟁은 기 등록된 실제 정치조직·P3 쟁점을 경유해 연계됨.

## P5-A — 실물 참여·파업·정부 대응

- `P5CollectiveAction`: 청원/시위/파업/협상/법적 양보/경찰대응의 유형과 실제 POP·조직/법적 근거·날짜 기록.
- 평화적 행동은 기존 C `protest`와 P2 합법 결사/파업권, POP 실제 단체 가입·가용 참여 인원을 검사. 동일 POP를 무제한 행동에 중복 투입하지 않음.
- **P5 새 파업은 매월이 아닌 실제 다음 날 Stage0 발효**. `p5_scheduled_daily_strikes_`→`p5_active_daily_strikes_`가 기존 실제 고용계약을 사용하고 C `currently_striking`/고용자 노동 공급 계산과 연계한다. 실제 고용·생산·현금을 다른 원장에서 생성하지 않음. 하루 파업은 다음 날 자동 만료.
- 경찰 대응은 실제 P1 경찰기관·실제 유급 직원·재정·기관 처리량을 검증해야 하며, 정치 모듈은 임의 체포/부상/안정도 포인트를 생성하지 않음.
- 합법적, 충분히 조직된 고위험 운동은 경고가 형성될 때 **실제 회원 5명 이하의 일회 청원**을 자동 시도할 수 있다. 무장 행동 자동 발생 아님.

## P5-B — 정치적 불안정과 위기 경고

- `P5RiskView`: 실제 P3 지지/활동/급진성, P1 정통성 및 입법기관의 존재·P2 요구 충족 여부를 입력받는 파생 위험지표.
- `p5_daily_advance`: 정부 교체·자치·독립을 요구하는 운동의 실제 위험도가 일정 기간 누적되었을 때만 정치적 경고를 기록. 위기가 사그라들어도 이미 일어난 기록은 삭제하지 않음.
- 국가의 단일 안정도 수치에서 자동으로 반란군/무기/군사통제권을 생성하지 않음.

## P5-C — 쿠데타·혁명·무장 충돌의 실제 군사 경계

- `P5Crisis`: 운동/목표·실제 참전 부대 ID·군사통제 근거·실제 교전 건수와 날짜만 기록. 이미 C에 존재하는 배치 병력·병역 POP·소유 재고/장비를 참조한다.
- `p5_pledge_army_unit`: 실제 배치된 C 군부대와 살아 있는 병력·탄약·소총 보유를 검사. 같은 부대를 둘 이상의 독립 반란에 중복 배정하지 않음.
- `p5_designate_coup`는 이미 실제 무장 인력을 확보한 혁명성 운동에서만 가능.
- `p5_begin_armed_conflict`는 경고·지휘부대·실제 물자 조건을 충족해야 한다. **위험도만으로 내전 자동 개전 불가.**
- `p5_record_real_engagement`는 실제 같은 지역의 정부군과 이탈군을 확인한 뒤 **기존 C/Phase B `battle`를 호출**하여 탄약 소비·사상/부상·병력 명부를 변경. P5 자체 전투력/인구를 생성하지 않음.
- `p5_confirm_actual_control`: 독립적인 군사 계산/명령 결과로 이미 변경된 C `military_control`과 실제 전개 중인 이탈 부대를 확인한 뒤 정치적 군사통제 증거를 기록. 반란의 주장만으로 소유권/국경 자동 변경 금지.

**명시적 한계:** 이 단계는 C-M의 실제 전투·부대·탄약 기록에 대한 정치적 내전 어댑터다. H의 양국 간 일반 전쟁 AI/다수 전선·민정·외교의 모든 내전 절차와 완전히 동일한 내전 시뮬레이터를 구축한 것은 아니다.

## P5-D — 개혁·정권 교체·독립 이후의 정치적 합의

- `p5_settle`의 양보·자치 결과는 **실제 P2 법률의 유효한 기본법/정책 선택**으로 증명해야 함.
- 정권 강제 교체는 P5가 사전에 실제 C 주권지역으로 등록한 **국가 수도의 군사통제권**이 확인되어야 P1 다음 날 공직 변경을 예약한다. 일반 혁명은 기존 C-M 부대의 실제 교전까지 필요하고, 쿠데타는 군부 이탈·수도 실통제 증거가 있으면 유혈 교전을 강제하지 않는다. 다음 날 P1 공직 교체가 실효되면 이전에 검증된 반란군의 실제 점령지만 C 군사통제 정본에서 새 정부의 지휘권으로 정규화한다(법적 주권·국고·병력·재고 생성/중복 없음). 국가의 기존 국고·국채·법률·인구·군사 장비는 초기화하지 않음.
- 분리독립 종료는 먼저 실제 E의 주권 변경과 새 국가의 존재를 확인해야 가능. 정치적 요구만으로 새 나라/영토/부채를 생성하지 않는다.
- 정권교체 후에도 P3 역사와 실제 경제·지리·군사 원장을 보존하며, 승리했다고 모든 지역의 불만이 자동 소멸하지 않음.
