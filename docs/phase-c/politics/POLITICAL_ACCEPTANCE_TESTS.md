## B. 설계용 수치 fixture

### 선거: 1개 선거구 / 3석 비례대표

- 가상 국가 A의 해당 선거구 거주 인구 = **1,000명**.
- 법적 선거권자 `eligible=600`, 유효 등록 `registered=550`, 실제 투표 용지 `cast=420`, 유효 `valid=400`, 무효 `invalid=20`, 등록 유권자 중 기권 `abstained=130`, 미등록 법적 적격자 `unregistered=50`.
- A정당 220, B정당 130, C정당 50 = 유효표 400.
- `ListPR_DHondt`, 3석, 진입장벽 0, 후보명부 충분: `220 / 1`, `130 / 1`, `220 / 2`가 상위 3개의 몫이므로 **A 2석·B 1석·C 0석**.
- 총 주민 인구는 여전히 1,000명, 총 등록 유권자 550명, 의회 3석(대표 단위)이 별도로 기록.
- 위 인구 집단의 실제 분할과 정치 선호는 출처/규칙 기반으로 계산하며 실제 역사 선거 결과를 뜻하지 않음.

### 법률: 선거 연령 21세→18세 변경

- 가상 월 `month=240`에서 법안이 유효 발의/정족수/표결/공포를 거쳐 채택됨.
- 해당 가상 시점 18~20세 주민 40명, 21세 이상 주민 60명. 다른 제한 조건은 없으며 주민 100명 전부 등록 신청 가능하다고 가정.
- 월 240 제도는 아직 `minimum_voting_age=21`: 법적 적격자 **60명**.
- 월 241 단계 0부터 새 제도 `minimum_voting_age=18`: 법적 적격자 **100명**.
- 실제 등록/투표·승인/집행은 각 시점 별도 계산. 선거권 확대 법안만으로 투표 40표가 자동 추가되지 않음.
