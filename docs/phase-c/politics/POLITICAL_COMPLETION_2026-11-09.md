## 구현한 경로

1. **일간 정치 실행 순서:** Stage 9에서 실제 POP 정치 반응 → 인물 정리 → 선거운동 → 기존 P0 정치 명령·선거 → 자동 선거 보충 → 협상 → 예정된 법률 검토 → 국가 AI → 정치 위기 → 정치 사건·권위 → 실제 병력 기반 혁명 준비 순으로 처리. Stage 0 법률·정부 시행, C/D/E/G/H 원자적 트랜잭션과 이전 Stage 실행은 보존.
2. **P2 입법:** 3단계 검토 상태, 예정 검토일 인덱스, 성공/진전/논쟁/교착, 차질·재시도 제한, 정통성·권위 공급/사용·실제 P3 이익집단·운동 지원 및 실존 정치인/측근 영향. 기존 상·하원 의결·공포·익일 효력은 별도 합법 절차로 유지.
3. **P4 정당/선거:** 12가지 정당 유형 분류, 정당에 대한 다대다 선호와 IG 정식 당적 분리, 선거 180일 전 주간 캠페인, 실제 POP 표수의 정당별 가중치 변화. 정부 연정의 합법적 익일 변경은 P1/P4를 재사용.
4. **P1/P3/P4 인물:** 실제 PersonAnchor의 정치 역할·이념·인기도, 지도자 승계, 선동가, 정치적 망명 상태, 총애받는 측근. 신규 실제 POP는 생성하지 않음.
5. **P3/P5 운동/혁명:** 실제 P3 IG 지지에 기초한 운동 창설·종료와 조건별 유형 분류, 혁명 준비 진행 및 실제 병력·병사 지지·보유 무기/탄약 조건. 내전 전투·영토·평화는 기존 P5/E/H 소유권과 검증을 재사용.
6. **국가 정치 AI:** 실제 의석을 통한 연정, 준비 완료된 법률안의 합법적 투표/공포, 실제 운동이 요구하는 법률안 제출, 위기 대응 권위 명령. P0 정책 및 저장 원장에서 플레이어 국가를 AI 대상에서 제외.
7. **권위·콘텐츠·로비:** 권위 공급/예약, 운동 지원·억압과 POP 정치 선호, 지역 칙령 2종(실제 재료·고용·예산이 허용하는 건설 계획 상한, 실제 인력 기반 공공서비스의 접근량), 선택형 법안/위기 사건, 국가 간 IG 로비 압력. P0에서 날짜별 명령 처리.

신규 정치 상태는 Phase C의 선택적 `VIC25_PHASEC_..._1` 저장 확장 영역에만 기록하며, 기존 인구·자금·의석·군대 원장을 중복하지 않음.

## 아직 완료되지 않은 범위

- **정치 콘텐츠:** 독립적인 실행형 `content_world` 구현을 이 저장소에서 확인하지 못함. 범용 정치 사건·명령 경로는 추가했으나 국가별 역사 일지/특수 콘텐츠는 미구현.
- **소비세:** 권위 사용처의 종류만 정의. 실제 상품별 세금 부과·징수 규칙이 재정/시장 소유 원장에 연결되기 전에는 명령을 거부함.
