# VIC2.5 C-P5 — 정치적 불안정·시위·반란·내전

- 상태: 설계 확정, 군사 C-M 연동 이전
- 계약: `phase-c-politics/1.0`; POP-D2 사망·부상·이주, C-E1 노동, C-E4 국가재정, C-M 부대·장비·작전 연결

## P5-1. 불안정의 다층적 원인

정치적 불안정은 '국가 안정도 < 50이면 자동 반란'으로 처리하지 않는다. (a) POP의 개별 경제·사회 불만, (b) 정책·권리·기대의 불일치, (c) 조직화와 행동능력, (d) 법적/실제 참여경로, (e) 정부의 응답·행정·치안역량, (f) 군 지휘/물류 상태를 **서로 다른 상태 변수**로 보유한다. 대규모 불만이 있어도 조직력이 낮거나 제도권 협상에 참여하면 폭력이 발생하지 않을 수 있고, 소규모 조직이 특정 기관·부대의 실제 통제력을 확보하면 국가 권력구조가 흔들릴 수 있다.

| 객체 | 주요 필드·범위 |
|---|---|
| `GrievanceState` | population_slice_ref, issue/ref, grievance_sources, severity, persistence, uncertainty. 인원수 원본 없음 |
| `MobilizationCampaign` | movement/party/group_ref, issue demands, region_scope, supporters_ref, actual_participant_allocation, capacity, lawful_status, stage |
| `CollectiveActionEvent` | protest, petition, strike, boycott, riot, negotiation, concession, suppression 등 구별; 참가 인원·기간·장소·경제효과 |
| `PublicOrderInstitution` | 법적 권한, 실제 경찰·법원 고용/예산/설비/수송, 사건 처리량. 정본은 P1 기관+E4 공공·E1 고용 원장 |
| `FactionAlignment` | 해당 기관/부대/행정관료·정치행위자의 실제 지휘·명령 지원·불복 관계와 이력 |
| `RebellionOrganization` | organization_id, objectives(법률개정·정권/영토/자치 요구 등), command_structure, participant refs, armed_capacity_refs, territorial_claims |
| `CoupAttempt` | initiating_actors, target_offices, institutions involved, authority_dispute, outcome/appointments, source_events |
| `CivilConflict` | conflict_id, factions, armed_unit_refs, war_status, region_control_refs, peace/settlement events. 전투는 C-M 엔진 소유 |
| `PoliticalSettlement` | negotiated_law_change, constitutional_concession, autonomy/office change, demobilization, obligations/reparations, enforcement_terms |

## P5-2. 불만·행동·정책 피드백

- 입력: 실제 실업·물가/식량·영양·조세부담·생활수준/기대, 정치적 권리 및 실제 행정 서비스, 전쟁 사상·징병/재정, 지역·직능/자치 요구 등. **항상 POP/경제/군사에서 읽고 정치에서 현금/인구를 생성하지 않는다**.
- 집단의 이념적 정책 선호와 해당 요구가 충족되었는지를 구별한다. 생활수준 개선만으로 모든 문화/국가/지방자치 요구가 사라지지 않고, 모든 세금 인상이 자동 혁명을 유발하지 않는다.
- 기본 `mobilization_hazard`는 정치적 불만·조직 동원·정보/참여 접근·시위 비용·기존 전력·상대기관 반응·공간 네트워크의 **명시적 규칙 기반 결정 또는 고정소수점 확률**. 계수는 역사·제도별 보정용 ruleset에 둔다. 특정 민족/종교/성별이 선천적으로 폭력적인 것으로 모델링하지 않는다.
- 정치적 요구의 가능한 결과는 제도권 의회 협상·청원·합법 시위·파업·불매·선거 참여·탄압/체포·충돌·쿠데타·반란·내전 등이며, 하나의 불만 수치에 고정된 단선적 사다리를 적용하지 않는다.

## P5-3. 시위·파업·치안 집행의 실제 비용

1. 운동의 지지자는 실제 참가자와 다르다. `ActionParticipation`은 PopulationSlice의 실제 유효 인구와 가용 노동/복무 상태·지리 이동을 검사해 정수 인원으로 배정한다. 여러 운동의 서로 겹치는 동일 인원을 시간·활동 단위 없이 동시에 점유하지 않는다.
2. 시위·파업의 실제 교통·식량·조직비/운영비는 금융/재고/운송 또는 조직의 확인된 현물 보유로 처리한다. 불복종의 직접 영향(노동자 파업에 따른 조업 감소, 세금미납, 물류 정체)도 해당 기업/정부의 **실제 거래/생산 단계**에 반영하며 계획/실제 차이를 기록한다.
3. 단계 9에 새로 결정된 파업은 당월 단계 4의 과거 생산을 소급 감소시키지 않는다. 차월 단계 1~4에 효력을 갖는 `StrikeAssignment` 또는 앞서 개시한 계속 파업의 유효 상태를 사용한다.
4. 정부의 치안 조치는 **유효 법률/기관 권한 + 실제 경찰 인원·급여·시설·물자·이동/집행능력**을 요구한다. 무경비·무인력 치안 효과 금지. 경찰/군의 모든 사건을 동일하게 처리하지 않고 지휘·법적 임무와 작전권을 구분한다.
5. 체포/구금·부상/전사·재판/석방은 해당 POP-D2 `LegalChange`, `Illness/Injury`, `NaturalDeath/BattleLoss` 및 군사/치안 사건으로 기록한다. 부상과 사망을 합산하는 중복위험 금지.
6. 평화로운 시위에 법적 허가가 없더라도 실제 참가자를 자동 '반란군'으로 전환하지 않는다. 정부 대응의 수용/양보/탄압도 서로 다른 선택/권한/비용 및 후속 정치선호 변화를 발생시킨다.

## P5-4. 쿠데타·내전의 정치적 범위

- **쿠데타 시도**는 국가 권력기관의 실질 통제/임명권을 현재 헌정절차 바깥에서 변경하려는 사건이다. 성패는 단순 POP 지지율이 아니라 관여한 기관·지휘 계통·유효 병력·통신/보급·정부 대응의 실제 상태에 달린다. 정치 모듈은 조직/권한·정권 승계 기록, C-M은 무력 충돌/부대 배정을 담당한다.
- **내전**은 독립적인 무장조직·상충하는 통치권 주장·실제 부대/인구·지속된 충돌/영토통제 관계 등이 충족되는 경우의 `CivilConflict` 상태. 사회운동 지지자 10,000명을 자동 무장 10,000명으로 만들지 않는다. 무기·탄약·보급·병력은 Inventory/ServiceAssignment 및 C-M을 통해 확인한다.
- **군사반란·명령 불복**은 기존 부대/지휘관 관계의 `FactionAlignment` 이력으로 처리한다. 동일 병력을 정부군 1,000명·반란군 1,000명으로 동시에 복제할 수 없다.
- **분리·자치 요구**는 `TerritorialClaim`이나 `AutonomyProposal`로 표현한다. 분리독립의 군사적·외교적 결과는 C-D0의 주권/민정/과세/군사 통제 관계 변경 사건과 후속 국적·재정·부채/소유권 승계로 확정한다. 요구를 했다는 이유로 주민의 문화/국적/재산이 즉시 변하지 않는다.
- **협상·평화협정**은 헌정개정·선거·군 해산/통합·자치/영토관계·배상·체납·포로/이주/부상복구의 후속 사건을 예약한다. 모든 재건 비용과 전시 인구 손실을 독립적인 누락 없는 원장으로 관리한다.
- C-M 상세 전투·지휘·점령 엔진이 구현되지 않은 동안 정치 모듈은 **정치적 사건·동원 요구·위험 상태**만 생산하며 실제 전투/영토점령 성패를 임의 전투력 수치로 확정하지 않는다.

## P5-5. 월별 처리 경계

- **단계 0:** 전월 결정된 기존 집회·파업·비상법/명령·분쟁/군사통제 관계 중 이번 달 유효한 것 발효, 임시정부/재정/명령권 검증.
- **단계 1~8:** 이미 발효 중인 파업·통행/거래 제한·분쟁/기관 기능장애가 고용·생산·재고·재정/가격에 실제 영향을 미친다. 경제 충격 관측값을 확정한다.
- **단계 9b~9e:** 당월 불만·동원역량·조직·정부 대응 평가, 비폭력 운동/협상 및 차월 행동·치안/동원 계획. 정부교체/법률변경 효력은 다음 달 단계 0에 예약.
- **단계 10:** 유효한 병력/충돌·부상·사망·이주·구금·징집/제대 등의 POP 사건/조직/군사 원장을 검증된 사건으로 동기화. 단계 9의 새로운 정치행동이 당월 과거 노동/경제에 소급 영향을 주지 않는다.
- **단계 11:** 조직 동원·실제 참여·인구·군사 병력·장비·금융·지역 주권/과세/통제·정권권한 원장 전체 원자적 커밋/롤백.

## P5-6. 실질적 지표

경제 불만과 법적/실효적 정치권리, 지역별 수용/불신 분포, 실제 시위·파업 참여 인원·영업 중단 시간, 기관 처리능력·체납·체포/재판, 협상·입법/정부 구성 결과, 총영토 중 관할 변화 지역, 실제 충돌/사상자/이주·채무/군수비용 및 재건 비용을 별도 추적. 모든 항목을 통합 '국가 안정도 점수'로 대체하지 않는다.

## P5 검증 게이트

- P5-G1: 불만 90/100 또는 실업 30%라도 조직력·동원·법적 권한/군사자원이 없는 경우 자동 반란군/무기 생성 금지.
- P5-G2: 시위 지지 500명이어도 실제 참가 50명만 배정한 사건에서는 동원 50명이며 노동/인구 중복 없음.
- P5-G3: 월 100 단계 9 파업 결정은 월 100 단계 4 이미 확정된 생산에 소급 영향을 주지 않고 월 101부터 작동.
- P5-G4: 동원·군 지휘 불복 시 같은 100명의 병력을 양측에서 합산 200명으로 만들지 않는다.
- P5-G5: 전사 50, 부상 180, 장기 손상 70의 POP-D2 검증과 실제 부대 명부·가족 복지·경제 고용이 정합하다.
- P5-G6: 헌정개정·정권교체·분리독립 협정은 법/국가/주권/부채/인구의 유효시점 이력이 일치한다.
- P5-G7: 폭력·구금/복지·전쟁 사상은 실제 인구/의무·비용 사건 없이 명목 점수만 바꾸지 않는다.
- P5-G8: C-M 전투 엔진이 없으면 실제 전투/점령 승패 확정을 명시적으로 Unsupported로 처리한다.
