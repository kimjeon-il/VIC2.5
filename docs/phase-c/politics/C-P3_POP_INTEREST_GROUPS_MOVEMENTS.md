- 코드·불변식·한계: [P3+P5 연계 구현 기록](P3_P5_IMPLEMENTATION_2026-11-08.md).

## P3-1. 핵심 구분

`PoliticalIssue`(쟁점), `PolicyPreference`(선호), `InterestGroup`(조직적 이해집단), `PoliticalMovement`(특정 요구/쟁점의 행동 연합), `Party`(선거·의회 참여 조직), `SupportRelation`(동의), `MembershipRelation`(실제 가입), `Mobilization`(실제 행동)은 서로 다른 개념이다.

농민·노동자·자본가·지주라는 경제적 지위는 정치적 선호의 가능한 입력이지 **정치적 이념이나 정당 지지의 영구 분류키가 아니다**. 같은 직업이라도 재산·가구·지역·실제 노동환경·법적 권리·정보 접근·역사적 사건·사회 연결망에 따라 정치적 견해가 다를 수 있다. 문화·종교·성별 등의 인구학적 특성을 선천적 정치성향으로 직접 치환하지 않는다. 종교단체가 실제 정치에 영향력을 미치려면 법적 결사/특권·조직·인력·자원·사건 등 관측 가능한 근거가 있어야 하며, 신자의 인구비 자체를 종교별 자동 충성도·급진화·지지율로 변환하지 않는다(I-C1/1.1).

| 객체 | 주요 필드 / 원본 책임 |
|---|---|
| `PoliticalIssue` | issue_id, policy_domain, 대안/정책 위치의 유효 범위, 제도·시대별 존재 시점 |
| `AttitudeProfile` | profile_id, issue별 선호 분포/가중치/쟁점 중요도, 정보확신도, 제도 신뢰/불만의 분리 상태, revision |
| `AttitudeAllocation` | slice_id, partition_id, profile_id, 해당 인구 수/분포, measurement_method, source_event_id. 인구 자체는 POP에서만 소유 |
| `InterestGroup` | group_id, 운영 유형(지주단체·상공단체·노조·농민단체·전문직·종교/지역 자치조직 등), 제도적 지위·요구·권한, 운영기관/계정 참조 |
| `PoliticalMovement` | movement_id, 요구 이슈/정책/목표 지역, 조직/동원 관계, 위험/전략/활동 이력, 활동 유효기간 |
| `OrganizationMembership` | slice/partition→group/party/movement, 참여 형태, 유효기간, 겹침 분포 모델, 실제 가입 인원 참조 |
| `SupportRelation` | slice→issue/organization/party의 선호/동의 분포, 특정 시점의 지지 수 파생(회원수와 별도) |
| `InfluenceChannel` | 법정 자문권·언론 접근·협상·청원·조직 지위·의회/내각 연결 등의 **실제 접근 경로** |
| `PoliticalActivityEvent` | 조직 결성/가입/탈퇴/시위/청원/협상/캠페인/분열/연합의 제안 및 커밋 |

### POP를 사람 단위 투표자로 복제하지 않기

`AttitudeAllocation`이 1개 1,000명 POP에 대해 `issue_A` 선호 분포 400/300/300을 보유하는 것은 새 인구 1,000명을 만드는 것이 아니라 **해당 POP 1,000명을 나누어 설명하는 투영**이다. 필요하다면 POP-D0의 `allocation_partition_id`로 실제 정치적 행위나 경제적 자산과 연관된 하위집합을 원자적으로 구별한다. 정치적 분포를 과거와 연결할 때 revision·출처·추정치 여부를 기록하고 정치용 중복 인구수를 합쳐 세계 인구를 늘리지 않는다.

## P3-2. 정치적 태도와 실효 경제조건

월말(단계 8)에 관측한 `real_disposable_income`, `unemployment`, `food_need_fulfillment`, `property_exposure`, `tax_burden`, `government_service_access`, `war_casualty_exposure`, `legal_rights`, `local_security`, `policy_outcomes` 등을 **실제 경제·POP·군사·행정 원장에서 조회**한다.

기본 태도 갱신은 다차원 분포 방식이다.

```
issue_preference_next = bounded_update(
  previous_preference,
  evaluated_policy_benefits_costs,
  information_seen_and_confidence,
  social_network_exposure,
  remembered_events,
  issue_salience, adjustment_rule_version
)
```

- `evaluated_policy_benefits_costs`는 관측된 실수령 소득/물가/재산/생활서비스 및 정책의 영향으로 평가. 모든 개인에게 동일한 효용/변화를 고정하지 않는다.
- 쟁점 중요도(`salience`)와 지지 방향(`stance`)을 구분한다. 같은 세금을 싫어해도 정치참여의 우선순위가 서로 다를 수 있다.
- **정치적 신뢰·제도의 수용·생활불만·법적 권리·직접 행동 의향을 하나의 불만/충성 막대로 합치지 않는다.**
- 태도 변화는 전월→차월 관성·비선형성·불확실성을 갖는다. 동일 가격 변화를 겪어도 미리 정해진 성별/민족 보너스·페널티로 선호를 계산하지 않는다.
- 정보가 미상/검증되지 않으면 임의의 객관적 사실을 관측한 것처럼 행동하지 않는다. 미시 여론 데이터가 없는 역사시기에는 추정규칙과 분포 오차를 제공한다.

## P3-3. 이익집단/정치운동·참여와 영향력

- 가입자는 전체 POP의 일부 인원이며 같은 사람이 직업단체와 지역운동에 동시에 가입할 수 있다. **조직별 가입수의 합을 독립 참여자 총수로 쓰지 않는다.** 겹침 추정이 필요하면 공동 membership partition 또는 보수적/추정된 집합합 규칙을 명시한다.
- 조직은 실제 회비·기부금·공공지원·자산·채무를 E3 Financial/OwnershipLedger에 등록한다. `InfluenceChannel`이 있다고 예산·노동자·무기가 무상 생성되지 않는다.
- 법정 자문석·직능대표 의석·선거권·청원·파업/집회 합법성 등 조직의 법적 권한은 P1/P2에서 가져온다. 회사 소유자여서 무조건 의회 의석이 자동 생성되지는 않는다.
- 운동의 지지(`support`)는 활동 참가(`actual_participation`)와 구별한다. 8,000명이 정책 변화에 호의적이라고 8,000명이 당월 시위/반란에 참여한 것은 아니다.
- 요구가 여러 조직과 중복되더라도 같은 인구를 여러 운동의 동시 거리 동원 인원으로 중복 계산하지 않는다. 활동별 주된 동원 점유량/시간과 실제 조직·거리 접근성을 검증한다.
- 조직의 요구는 정책 목표·타협 가능 범위·시위/선거 참여·지역적 조직망을 표현한다. 특정 이익집단이 항상 한 정당만 지지하거나 한 사상만 고정적으로 지지하게 만들지 않는다.
- 제도권 정치 활동이 제한된 국가는 불법 정치활동·탄압의 법적/실효 차이를 표현할 수 있으나, 해당 제약만으로 운동이 자동 무장화되거나 사라지지는 않는다.

## P3-4. 집단의 정치적 영향력(투표권과 별개)

영향력은 신분·재산·기관 접근·선거권·조직망·언론/교육·법적 결사권 등 *실제로 존재하는 수단*에서 산출한다. 선거권 행사 시에는 P4의 법률·실제 투표 인원을 사용하며, 자금이나 행정력으로 해당 사람의 표를 임의 복제하지 않는다. 선거가 없는 국가에서도 자문기구·대토지 소유·길드·군 지휘부·지역 의회의 조직력은 존재할 수 있으나 해당 권한의 법적/사실상 경로를 기록해야 한다.

정보·기관 접근/후원은 시뮬레이션 속 정당·운동의 활동 제약으로 기능하지만 실제 세계의 특정 집단에 정치 메시지를 최적화하거나 선전 지침으로 변환하는 모델은 설계 범위가 아니다.

## P3-5. 정치적 집단의 분열/통합 및 지역 차이

- 같은 쟁점을 지지하는 여러 조직도 독립된 ID·경제계정·회원권·역사를 유지한다. 조직 합당/분열은 `MembershipTransfer`와 실제 자산/채무 이전·기록을 요구한다.
- 지역별 법률·생활수준·주류 언어/문화·교육·교통과 조직망을 다르게 반영할 수 있지만 모든 지역을 무조건 하나의 국가 여론으로 균질화하지 않는다.
- POP가 이주·직업/재산 변화·징집·부상·고령화되면 **정치적 선호/회원 가입과 실제 인원 배정의 이전**을 POP-D2 사건에서 검증한다.
- 조직이 해산되면 잔여 재산·부채·회원 관계를 청산/이전한다. 조직 ID와 과거 사건은 tombstone으로 보존한다.

## P3-6. 월별 순서와 관측

- 단계 0: 현행 정책·법적 권리·조직 등록 상태를 동결.
- 단계 5~8: 실제 소득·세금·급여·복지/조달·물가·기업생산/실업 등 관측.
- 단계 9b: 쟁점 태도/참여/운동 결성·조직지원 갱신. 단계 9c P4 선거가 필요한 경우 해당 시점 확정된 태도 분포를 읽는다.
- 단계 9e/10: 시위·폭력·군 동원/복무 상태 전이 이벤트를 처리하되 지난 임금/생산/선거를 소급하지 않는다.
- 단계 11: 분포합/이동 인원·조직재산·거래·원장 참조와 결정론 검사.

## P3 검증 게이트

- P3-G1: POP 100명에 지주단체 가입 30명·농민조직 가입 40명·환경운동 지지 60명이 있어도 세계 인구가 230명으로 증가하지 않는다.
- P3-G2: 동일인 중복회원은 가능하지만 독립 동원 참여 인원 합은 실제 가용 인원을 초과하지 않는다.
- P3-G3: 동일 경제직업의 다른 재산/지역/건강/법적 권리 분포가 서로 다른 정치적 태도를 가질 수 있다.
- P3-G4: 실질 임금·물가·교육/의료·세금 변화가 관측되지 않았는데 가계 현금·자산을 정치 원장이 따로 변경하는 사건은 거부한다.
- P3-G5: 노동자/기업 소유주/군인이 조직에 가입해도 POP 수와 기존 지분·급여가 보존된다.
- P3-G6: 운동의 정치적 지지 수를 실제 시위·파업·무장 병력으로 복제하지 않는다.
- P3-G7: 조직 합당/해산 뒤 회비·지분·회원 ID와 역사 사건이 보존된다.
