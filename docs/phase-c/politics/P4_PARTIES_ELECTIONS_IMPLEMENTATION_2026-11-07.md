## 메커니즘

- `P4Party`: 정당 국가/ID/등록·활성/공직 후보/초기 조직 가중치. 정당은 국가와 이익집단의 단일 소속을 강요하지 않음.
- `p4_autonomous_ballot`: Phase B 실제 POP 수·국적·나이·복무·지역, P3 실제 가입 인원·P4 집단/정당 가중치에서 정수 유효표를 생성. 등록/투표/기권은 별도 수치로 보존하며, 지역별 결과의 합이 POP 수를 넘지 않음. 사용자는 POP별 선거를 조작하지 않음.
- 기본 투표 모형은 캠페인용 결정론적 가중치. **정당에 대한 실제 문화/정책 성향·소득·실적/당원·선거운동 등은 아직 제한적**이며 역사 실측 투표율이라고 주장하지 않음.
- `p4_hold_contest`: 정당 등록, 해당 국가 법률상 정당 허용, 유권자/유효표 보존, 선거일, 선거방식을 검증하고 정수 D'Hondt/단일지역 plurality로 의석·당선자 산출.
- 국가 의회의 최신 의석은 **기존 C `country_elections_` 정본** 유지. P4는 선거별 불변 이력, 지방·국가원수 최신 결과, 미래 일정만 별도 저장. 대통령 당선자는 기존 P1 일별 공직 변경 사건을 다음 날 적용하고 의회 선거 결과는 즉시 내각을 교체하지 않음.
- 정당제 표시는 고정 법률 코드가 아니라 실제 선거 의석을 기반으로 산출: 장기 과반 승리면 일당우위, 2당 의석 집중이면 양당, 나머지는 다당; 기준은 조정 가능한 초안 단계.
- 선거 연산은 정기 매일 전 세계 재계산하지 않고 due date 색인으로 **선거일 이벤트에만 수행**. 해당 선거에서는 P3 가입 인덱스를 한 번만 작성. P0 컨트롤러가 없는 기본 `daily::World`에서도 선거일에 자동 집계하고, P0가 같은 날 먼저 처리했다면 due 색인이 비어 중복 집계하지 않는다.
- `VIC25_PHASEC_P4_ELECTIONS_1` 선택적 확장: 정당/가중치, 각 기관별 선거일, 결과 이력, 미발효 임기법을 보존. 저장시 파생 due 색인은 재생성하여 구형 세이브 변경 금지.
