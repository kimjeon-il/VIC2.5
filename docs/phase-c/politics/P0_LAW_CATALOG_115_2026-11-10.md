# VIC2.5 — Victoria 3 1.15 P0 법률 정본 전환 (2026-11-10)

작업 브랜치: `work/p0-law-catalog-115-20261110`, 선행: `work/politics-separation-powers-20261110`.

## 실제 반영 범위

- 2026-11-05 기준 Victoria 3 1.15 공개 게임파일 미러의 `basegame-ver/common/laws` 25개 파일에서 **26개 법률군 및 148개 선택지의 실제 식별자**와 부모/상위 법률, 기술 해금 목록, 상호 배제/선행 법률, 진보도, 가시성·특별 입법 조건 존재 여부를 분리해 수록.
- 같은 미러의 `common/amendments`에서 **71종 증보**의 실제 식별자, 적용 법률군/선택지, 일부 국가 조건, 일부 폐지 적법 조건을 수록. 자동 IG 타협은 원작 정의에 존재하는 generic-sponsor 양보에만 제한. 그 외 역사 증보는 출처가 있는 외부 이벤트·초기 시나리오 자료가 제안해야 함.
- 법률 직접/제도 modifier **894개**, 증보 직접/제도 modifier **213개**, 증보 sponsor modifier **10개**를 수치 또는 bool 정본으로 보존. 조회는 초기 불변 색인으로 처리, 별도 POP/경제/정치력 원장을 생성하지 않음.
- 기존 `P2BaseLaw` 계약과 P1/P4 임기·의석·헌정 원장을 유지. 새 카탈로그 법률군은 선택지가 그 법률군에 속해야 하며, 임의의 보통법 조항·증보를 삽입하지 못함. 이외 기존 공직 임기법 등 사용자 정의 계약은 호환을 위해 별도 유지.
- 상충되는 동시 법률군 교체/상호배제 선택은 거부하고 일반 법적 우선순위 검색은 단순화. 헌법 권한의 충돌은 여전히 오류 처리.
- 국가의 권위 공급, 원작 법률의 입법 성공률/속도 modifier, 여성선거권·공공의료권·결사 및 평화적 파업 허용 등 **해당 소비자가 존재하는 효과부터 실제 원장에 적용**.
- 국체·권력배분의 정본 법률 ID를 P1 헌정 구조로 매핑. 새 열거값은 기존 저장값 뒤에 추가함.
- 일간 Stage 9 기술 해금 판정은 D의 실제 연구 정본(`usable`)을 참조. 기술 없는 임의 해금 금지.
- 입법 3단계 정치적 확률과 법률상 의석 투표는 구분하되, 하원·상원·AI가 같은 정족수 함수를 사용하여 중복 분기 제거. P1 권력분립/거부권/재의결, P0~P5 일간 12단계는 보존.

## 미완성 — 이 목록을 완전한 게임 효과 재현으로 해석하지 말 것

1. `is_visible`, `can_enact`, 증보 `possible`/`can_repeal`의 **전체 중첩 조건식**은 현재 플래그·대표 조건만 추출했고, 원작의 스크립트 평가기가 없음. 국가별 일지/이벤트, 고유 트리거, 특수 정부/주 관계·DLC 조건은 미실행. 지원하지 않는 데이터는 새 사실로 가정하지 않아야 함.
2. 수록된 1,117개 정적 modifier는 정본 조회 API에서 접근할 수 있지만, 그 모든 효과를 C/D/E/G/H의 실제 경제·인구·전쟁 원장에 연결한 것은 아님. 현재 직접 연결된 소비자가 있는 효과 위주로 실행. 특히 `on_activate`/`on_deactivate`/`on_enact`의 중첩 효과는 별도 구현 필요.
3. `unlocking_technologies`에서 같은 법률의 복수 기술 목록은 현재 OR 조건으로 판단. 특수 `requires_law_or`와 `disallowing_laws`는 정적 법률 ID만 검사하고, 동적인 스크립트 조건은 아직 완전 구현하지 않음.
4. 한 국가에 원작 카탈로그가 아닌 기존 특수 공직/임기 법률이 있으면 기존 P2 구조로 읽을 수 있으나, 해당 부분을 원작의 26개 법률군이라고 주장하지 않음.
5. 컴파일·CTest·실제 100년 장기 시뮬레이션은 이 작업에서 실행하지 못했음. 데이터 행 수/ID 정적 검사 및 집중 C++ 검사 코드 추가만 진행. 아직 런타임 인수 완료 아님.
