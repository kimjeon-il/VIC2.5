### P2 법률 효과와 우선순위

- 사용자/시나리오가 조문 타입(`P2ClauseKind`)으로 명시한 실제 조항과 증보가 우선한다.
- 조문에 해당 사항이 없으면 활성 카탈로그 법률로부터 **지원되는 타입의 법적 제한만** 보조적으로 파생한다.
- 분야별 효과가 없는 경우, 효과를 가상으로 만들거나 임의의 현금/POP을 생성하지 않는다.
- 예: `no_health_system`인 국가는 기존 P1 공공의료기관의 실제 직원이 있더라도 공공의료 접근이 차단된다. `free_trade`에선 법적 수입 관세 상한 0, `consumption_based_taxation`에선 임금소득세 법정상한 0. 기존 P2 증보가 명시적으로 지정하면 이를 따른다.
- 중요: 현재 데이터가 말하는 '효과 없음'은 해당 법률의 모든 규칙을 구현했다는 뜻이 아니라 **도메인 효과 어댑터가 아직 없는 것**이다. 국가별 조건과 법안 서술 이벤트는 별도 구현 범위다.

### 이념·정치력 계산

1. `P3GroupType` 기본 이념은 8개 유형별 템플릿을 제공하되, 개별 국가/특수 이익집단은 `p3_set_ideologies`로 명시적 덮어쓰기를 지원한다.
2. 인물에게 실존 P1 `PersonAnchor`가 연결된 경우에만 지도자 이념을 추가 평가한다. 이념 변경 때문에 인물이 자동으로 생성되지 않는다.
3. 각 이념의 개별 시행 법률 평가를 -2~+2 정수로 합산, 지도자 이념은 2중 가중한다. 이념에 해당 법률 의견이 없다면 반영하지 않는다.
4. 법률과 연결된 이익집단 정치력 배율은 살아 있는 POP의 등록 집단원 수에만 적용하며 정치력 자원 원장, 가상 회사·인구를 따로 쓰지 않는다.
5. 이익집단 승인에는 시행 법률 선호·실제 관측 POP 급진성이 반영된다.
6. 정통성은 기초 지지집단/의석/헌정 점수에서 집권집단들의 법률 선호가 정반대일 때 추가 하락한다. 정확한 빅토리아 3 합산식 복제 대신 이미 구현된 VIC2.5의 기존 정통성 수식을 보존한다.

### 실제 연산이 추가된 부분

1. **문화·종교·정치적 차별**: 원본 Phase B POP 문화/종교와 명시적 문화권·언어·전통·국교의 관계를 기반으로 수용도 0~100을 계산. 실제 출처가 없는 국가/문화는 미판정으로 남긴다. 인종·민족 특성을 문자열 형태만 보고 자동 생성하지 않는다. 기존 P4 선거의 투표자격, 신규 C 고용계약 임금, P3 실제 이익집단 회원의 정치력에 법률별 5개 수용도 구간 효과를 연결.
2. **이주·농노제**: \`migrate_with_explicit_property_allocation\`의 실제 POP 이동·가계 현금·실물 주식 이전 전에 국경폐쇄·이주 제한과 농노제의 직업상 이동 금지 검사. 합법적 이동은 원본 인구/재산 원장에서 한 번만 처리한다. 근대 법률/정부가 없는 기존 Phase C 지리 픽스처는 구형 이주 계약을 유지한다.
3. **노예제·농지개혁**: \`slavery_banned\` 또는 농노제 해소에 해당하는 P2 유효 법률의 법적 효력일 이후 **같은 날 Stage 10**에서 기존 고용관계·POP 인원·실존 조직참여·실존 인물 식별자를 보전하며 \`slave\`/\`enslaved\`/\`serf\` POP 법적 상태를 \`free\`로 변경. 군사에 배치된 사람의 해방 명령은 별도 합법적 전역·배치 정산이 없으면 전체 일간 거래 거부. 보상/토지소유권 이전/노예매매 청산은 자동으로 만들어내지 않는다.
4. **소유권·경제제도**: 진짜 기업 \`ProductionFacility\`와 연결된 \`company:<firm>\` 증권의 주권관할을 검사하여, \`command_economy\`에서는 원본 국가 국고 외의 사적 기업지분 인수를 거부한다. 기존 주식/국고/시설의 원장을 그대로 사용하며 강제 국유화·주가 발행·합작회사 조성은 법적 승계 증거 없이 실시하지 않는다.
5. **군대/징병법**: \`peasant_levies\`는 실제 Phase B POP의 \`peasant\` 직업 또는 \`subsistence\` 생계만 징집 가능. 원본 데이터의 현재 징집비율이 확인되는 경우 정수/실인구에 대한 상한으로 사용. 외부 전투 엔진을 복제하지 않고 기존 P0 전투의 실제 병력·탄약·총기 교전에서 기존 IG 군부의 \`unit_offense_mult\`/\`unit_defense_mult\`와 유효법률 직접 효과가 사상자 판정에 영향을 준다.
6. **식민지법**: 콘텐츠 명령 \`ExternalKind::colonize\`는 법이 허용하는 실존국가만 실행할 수 있다. \`frontier_colonization\`은 실제 지도 경계가 이웃한 비주권 관할지역에만 청구권을 등록한다. 다른 정식 주권국의 영토는 이 방법으로 병합할 수 없다. 원본 Phase E 청구권만 예약하며 인구/영토 제목/식민 정착민을 즉시 생성하지 않는다.
7. **법률·이념·IG 특성 실시간 쿼리**: \`p2_active_modifiers\`/\`p2_modifier_ppm\`은 실제 시행 법률별로 검증 가능한 단순 효과만 파생. \`p3_active_traits\`/\`p3_trait_modifier_ppm\`은 실존 구성원과 승인 수준에 따른 특성만 노출. 불만 Devout 교육 접근/행정 중간관리자의 처리량, 군부 공격·방어 등 도메인 효과가 연결되며 미지의 modifier는 별도 신규 자원으로 조작하지 않는다.

### 유지한 기존 VIC2.5 정책

- 일간 원자 시뮬레이션 Stage 0–11과 실제 유효일·증보 우선순위 유지.
- Phase B/C/D/E/G/H 소유 POP/현금/주식/생산/운송/군사/영토를 복제하는 그림자 자원 금지.
