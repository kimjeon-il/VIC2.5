# VIC2.5 정치 1.15 전수 이행 현황 — 2026-11-08

## 요청과 검증 기준

요청: 빅토리아 3 1.15의 **190종 이념 선호표**, **148종 법률의 모든 실제 효과**, 경제·사회·군사 도메인 및 8개 이익집단 특성의 일간 엔진 연결. 사용자 지정 VIC2.5 차이(실제 POP·기업·국고·군사 원장 단일화, 일간 시뮬레이션, 별도 중복 원장 없음)는 유지한다.

기준:
- 최신 1.15 추출 자료: https://vic3tabula.com/en/ideologies (190종, 2026-11-05)
- 법률: https://vic3tabula.com/en/laws (148종, 2026-11-05)
- 검증 가능한 구판 데이터: https://github.com/alcaras/v3ref/tree/main/src/data (1.13.11, 172 이념/136 법률 직접 modifier 정의)
- 위키: https://vic3.paradoxwikis.com/wiki/Ideology 및 https://vic3.paradoxwikis.com/wiki/Laws

## 실제 구현된 것

- `phase_c_politics_catalog.hpp`: 26개 법률 그룹/148개 법률 ID.
- `phase_c_politics_reference_ideologies.hpp`: **172개 1.13.11 출처 이념 정의 및 3,737개 법률 선호**. 1.15의 190개 완전 자료가 아니다. 누락 18개를 가상의 중립 이념으로 채우지 않는다.
- `phase_c_politics_reference_modifiers.hpp`: **136개 1.13.11 출처 법률의 직접 modifier**. 모든 수정자를 조회할 수 있으나, 모든 modifier가 게임의 실제 도메인 연산에 적용된 것은 아니다.
- `phase_c_politics_trait_data.hpp`: **8개 이익집단 × 3개 특성 = 24개 특성**과 조건별 modifier 데이터. 활성화는 실제 가입 인원과 승인도에 의존한다.
- `phase_c_politics_identity_impl.hpp`: 출처 있는 문화/종교 특성·국적법에 따른 수용도, 실제 POP 이주 제한, 노예제 폐지/농노 해방의 실제 인구 상태 전환.
- `phase_c.hpp`: 실제 기업 증권 소유권 이전 시 명령경제의 국고 매입 제한, 임금계약의 수용도 효과, 농노·이민 법률 제한, 병역모델의 실제 동원 제한.
- `phase_d.hpp`: **명령경제에서 국가 재무부가 아닌 민간 투자자의 신규 기업 확장 제안 차단**. 실제 재무부, 건설 프로젝트, 기업 자금 및 인허가 확인을 사용.
- `p0_daily.hpp`: **노동조합 불만 특성(`state_construction_mult`)을 자율 기업 투자 시 실제 유상 건설량에 적용**. 실제 자재·노동·현금 한도를 초과하지 않으며, 최소 단위 사업이 영구 정체되지 않도록 정수 반올림.
- 기존 P1/P2/P3: 입법 증보, 실제 정치력·이념 승인·연립정부 정통성, 지지/반대, 공공기관 권리, 조세·관세·선거·결사/파업·의료 접근.

## 완료되지 않은 것 — 이 목록은 테스트가 통과해도 미완료

1. 1.15의 추가 **18개 이념과 조건부 선호 전체**: 원본 1.15 자료에서 정의·조건·예외를 확인하여 소스 적재 필요. 구판 172종을 190종으로 표시하거나 존재하지 않는 법률 선호를 추론하지 않는다.
2. 1.15에 추가·수정된 법률의 **조건부 효과 및 on_activate/on_deactivate, 기술·DLC·국가·법률 충돌 조건**: 1.13.11의 136개 직접 modifier 조회와 구별한다.
3. **모든 148개 법률의 실제 효과**: 투자 풀/소유권 자동 전환·기업 배당/정부 배당·토지·이민 풀·차별·노예 노동 시장·식민지 성장·군대 전투/징병/군수/사기·교육·의료·복지/연금·치안·세제·관세·무역 흐름의 도메인별 계산 연결 및 회귀가 아직 전수 완료되지 않았다.
4. **24개 이익집단 특성의 모든 도메인 효과**: 특성 데이터/활성화는 존재하지만 투자 수익률·연구·군사 전투력·이민 유인·생식률·금융 금리·세수·국가 권위 등 실제 계산 경로 연결이 일부에 한정된다.
5. 위 기능의 국가별·문화별·경제/군사 사례 전체를 이용한 교차검증 및 Linux/Windows 전체 회귀 검사가 필요하다.

## 구현 원칙

- 시나리오 데이터가 없는 문화·종교·기업 국적·직업은 임의 추정하지 않는다.
- 미지원 modifier를 0 또는 가상 효과로 처리하지 않는다. 조회/진단에는 노출하되 실제 반영 여부를 명시한다.
- 영토·기업 소유권·현금·POP·무기·투자금은 기존 권위 있는 원장만 변경한다.
- 사용자 지정 기존 구조와 달리 1.15의 세부 숫자나 법률 분류를 임의 간소화하지 않는다.
- 별도 작업 브랜치를 만들지 않고 `work/politics`에서 계속한다.
