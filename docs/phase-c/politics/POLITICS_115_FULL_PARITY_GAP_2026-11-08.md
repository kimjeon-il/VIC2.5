## 실제 구현된 것

- `phase_c_politics_catalog.hpp`: 26개 법률 그룹/148개 법률 ID.
- `phase_c_politics_reference_ideologies.hpp`: **190개 1.15 출처 이념 정의 및 4,469개 법률 선호**. 출처는 2026-11-07의 1.15 데이터 추출본이다. 이전 172종/3,737개 구판 데이터를 대체했다.
- `phase_c_politics_reference_modifiers.hpp`: **148개 1.15 출처 법률의 직접 수정자 812개**. 실제 게임 도메인 연산에 연결된 수정자는 이 중 일부다. 법률 간 금지 관계도 양방향으로 검증한다.
- `phase_c_politics_trait_data.hpp`: **8개 이익집단 × 3개 특성 = 24개 특성**과 조건별 modifier 데이터. 활성화는 실제 가입 인원과 승인도에 의존한다.
- `phase_c_politics_identity_impl.hpp`: 출처 있는 문화/종교 특성·국적법에 따른 수용도, 실제 POP 이주 제한, 노예제 폐지/농노 해방의 실제 인구 상태 전환.
- `phase_c.hpp`: 실제 기업 증권 소유권 이전 시 명령경제의 국고 매입 제한, 임금계약의 수용도 효과, 농노·이민 법률 제한, 병역모델의 실제 동원 제한.
- `phase_d.hpp`: **명령경제에서 국가 재무부가 아닌 민간 투자자의 신규 기업 확장 제안 차단**. 실제 재무부, 건설 프로젝트, 기업 자금 및 인허가 확인을 사용.
- `p0_daily.hpp`: **노동조합 불만 특성(`state_construction_mult`)을 자율 기업 투자 시 실제 유상 건설량에 적용**. 실제 자재·노동·현금 한도를 초과하지 않으며, 최소 단위 사업이 영구 정체되지 않도록 정수 반올림.
- 기존 P1/P2/P3: 입법 증보, 실제 정치력·이념 승인·연립정부 정통성, 지지/반대, 공공기관 권리, 조세·관세·선거·결사/파업·의료 접근.

## 완료되지 않은 것 — 이 목록은 테스트가 통과해도 미완료

1. **190종 이념의 직접 법률 선호표는 확보·등록 완료**. 단, 조건부 이념 효과 및 시나리오별 적용 조건의 모든 실행 경로는 별도 검증이 필요하다.
2. 1.15 법률의 **조건부 효과 및 on_activate/on_deactivate, 기술·DLC·국가 조건**은 미완성이다. 법률 간 금지 관계는 등록·검증했지만 이것만으로 모든 조건부 실행을 완료한 것은 아니다.
3. **모든 148개 법률의 실제 효과**: 투자 풀/소유권 자동 전환·기업 배당/정부 배당·토지·이민 풀·차별·노예 노동 시장·식민지 성장·군대 전투/징병/군수/사기·교육·의료·복지/연금·치안·세제·관세·무역 흐름의 도메인별 계산 연결 및 회귀가 아직 전수 완료되지 않았다.
4. **24개 이익집단 특성의 모든 도메인 효과**: 특성 데이터/활성화는 존재하지만 투자 수익률·연구·군사 전투력·이민 유인·생식률·금융 금리·세수·국가 권위 등 실제 계산 경로 연결이 일부에 한정된다. `phase_c_politics_effect_audit.hpp`가 특성별 실행 경로 연결 여부를 조회하며 미지원 효과를 명시한다.
5. 위 기능의 국가별·문화별·경제/군사 사례 전체를 이용한 교차검증 및 Linux/Windows 전체 회귀 검사가 필요하다.

## 구현 원칙

- 시나리오 데이터가 없는 문화·종교·기업 국적·직업은 임의 추정하지 않는다.
- 미지원 modifier를 0 또는 가상 효과로 처리하지 않는다. 조회/진단에는 노출하되 실제 반영 여부를 명시한다.
- 영토·기업 소유권·현금·POP·무기·투자금은 기존 권위 있는 원장만 변경한다.
- 사용자 지정 기존 구조와 달리 1.15의 세부 숫자나 법률 분류를 임의 간소화하지 않는다.
- 별도 작업 브랜치를 만들지 않고 `work/politics`에서 계속한다.

## 2026-11-08 조건부 법률 효과 및 24개 IG 특성 후속 작업

사용자가 요구한 148개 법률의 모든 조건부 실행과 24개 IG 특성의 모든 도메인 연결은 **아직 완료 판정 불가**다.

- `phase_c_politics_effect_audit.hpp::audit_law_modifiers()`: 원본 1.15 직접 수정자 812개를 실제 C/D/G/P0 도메인 실행 경로와 대조하여 연결/미지원 상태로 분류한다. 조건부 `on_activate`, `on_deactivate` 등 스크립트의 전수 실행을 의미하지 않는다.
- `audit_ig_traits()`: 24개 특성의 각 효과 키에 실제 실행 경로가 존재하는지 별도로 보여준다.
- 이익집단의 `country_authority_mult`, `country_prestige_mult`, `country_influence_mult`는 기존 국가 권위·위신·외교 영향력의 완전한 단일 원장이 부재하여 아직 미지원이다. 조회값이나 가상의 정치 점수를 생성해 완료로 간주하지 않는다.
- 법률의 일부 수치 수정자(예: 이민 제한 정도, 특정 직업·종교별 임금 보정, 조건부 기술·국가별 법률 효과)는 직접 수정자 테이블에 존재해도 해당 실제 일간 연산에 연결되지 않은 경우 미지원으로 남긴다.
- 기존에 사용자가 요청한 일간 계산, 실제 POP·기업·국고·군사 원장 보존, 원장 중복 금지는 계속 적용한다.
- 사용자 요청에 따라 이 작업의 신규 커밋에서는 검사/CI 실행을 의도적으로 생략한다. 따라서 이전 CI의 성공을 이번 코드의 성공으로 인용하지 않는다.
