# VIC2.5 P5-G — 지역 기반 유격전·비정규 무장투쟁 구현 (2026-11-08)

**작업 브랜치:** `work/p5-guerrilla-campaigns` (`work/p3-p5-politics` 기반)  
**상태:** 실제 C++ 코드·단일 C/POP/H 원장 연결·일간 Stage0/9/10·호환 세이브·집중 회귀 사례 작성. **빌드·CTest·CI/장기 성능/역사 보정은 아직 미실행(UNVERIFIED)**. `main` 미병합.

## 목표와 범위

빅토리아 3의 지역별 봉기·위기 일지와 장기 정치운동 방식에서 UX/진행 개념을 참조하되, VIC2.5에서는 국가 영토의 자동 분할이나 가상 반군 병력 생성 없이 유격활동을 처리한다. 정권 탈취를 위한 P5 군사정변·전면 내전과 달리, 유격전은 **특정 지역의 장기 저강도 사건·실제 무장부대·국지적 민간 접근 악화**를 관리한다. 실제 무장능력·탄약·지역·인구는 Phase C·B 원본만 사용한다.

### P5-G1 — 일지·지역별 동향

- `P5GuerrillaCampaign`: 고유 ID, 실제 `P3Movement`·주권국, 조직화·활동·보급고갈·정규전·휴전·종결 상태, 지역·연계 C 실부대, 시작/재검토/종료일, 실제 교전 누적 건수.
- `p5_begin_guerrilla`: 명시된 실제 운동을 기반으로 활동지역을 설정. 최소한 한 지역의 실제 POP 가입·쟁점 선호가 존재해야 시작. 무장부대가 없다면 **organizing** 일지만 가능.
- `p5_guerrilla_region_view`: 지역별 실제 POP 가입·이슈 선호의 중복 없는 지지자 수, 실제 C 배치군·정부군 병력, 실탄 재고, P1 지급·인력기반 경찰력, 법적 주권·군사통제, 사건으로 입증된 현재 민간 접근 차질을 파생 조회.
- 운동의 지지자 수를 모집 병력으로 간주하지 않으며, 정부가 주권과 주요 통제를 유지하는 지역도 유격전 일지가 가능하다.

### P5-G2 — 실존 비정규부대·물리적 보급

- `p5_guerrilla_extend`: 이미 배치·복무 중인 C 부대와 실제 총기·탄약 재고를 확인해 새 지역 및 지역 무장조직을 연결한다.
- 다른 유격전 또는 별개 국가적 무장 위기에 동일 부대의 이중소속 금지. 같은 P3 운동이 정규전으로 확대되는 경우에는 **같은 C 부대 ID**를 P5 전면 내전으로 승계할 수 있다.
- 보급 고갈·상실은 실존 탄약·소총·생존 전투원 부족으로 파생한다. 조직화와 실제 무장활동이 구별된다.

### P5-G3 — 검증된 저강도 충돌과 지역 실물 효과

- `p5_guerrilla_disrupt`는 **Stage10 실제 배치군·소총·탄약 소비**를 확인한 유격활동 사건으로, 손실을 C 재고 원장에 한 번만 기록. 임의의 POP 사상자·영토 점령·기업재산 손실은 생성하지 않는다.
- 실제 소모 탄약과 생존 병력에 상한을 두어 `P5GuerrillaAccessEffect`를 산출. 잠정 게임 조정치는 사건당 최대 25%·지역 총합 최대 50%, 사건 다음 날부터 3일간 유효.
- **Stage0** 효력·만료 갱신 → C `clear_household_market`, `clear_consumer_market`의 실제 매매 가능 수량 및 P1 `p1_institution_capacity`의 실제 제공 가능량에 적용. 미거래 상품·현금은 기존 원장에 남고, 미충족 소비는 기존 시장 수급으로 계산.
- 유격활동 이후 자동 무장사상자를 생성하지 않는다. 실제 교전이 있을 때만 `p5_guerrilla_skirmish`가 같은 지역의 기존 C 정부군·이탈군, 실제 배치 POP·소총·탄약을 검증하고 **기존 `battle()`**를 호출해 인구·탄약·전투 사건을 기록한다.
- **전면 지역경로 기반 교통망/역·노선별 차단·정밀 치안 예산**은 이 단계에서 추가하지 않는다. 민간 접근/공공서비스의 지역별 실제 영향까지만 구현했다.

### P5-G4 — 유격전과 정규전 간 상호 전환

- `p5_guerrilla_to_conventional`은 기존 P5 위기가 실제 **armed_conflict** 상태여야 하며 동일 운동, 동일 실부대에 대한 P5 지휘 서약, 기존 C `military_control`의 실제 지역 지배 증거를 모두 요구한다. 정치 위기의 수치가 높다는 이유만으로 정규전 전선이 생기지 않는다.
- 정규전으로 전환해도 기존 `units_`, 군 복무 POP, 재고·금융·영토 주권의 정본을 **새로 만들거나 이중 이전하지 않는다**.
- `p5_guerrilla_resume`은 정규전 실패·휴전 뒤 실제 생존 병력·무기·탄약과 해당 지역을 확인한 경우에만 기존 일지를 활성화한다. 군사통제·군수품 복제 없음.
- 비정규·정규전은 **정치적 갈등의 전투 방식**이며 독립·정권 교체는 기존 P5 정치 목표로 계속 관리한다.

### P5-G5 — 휴전·개혁·무장해제와 이력·세이브

- `p5_guerrilla_end`: 진행 중인 지역 무장활동의 정지·종결을 구분.
  - `negotiated_ceasefire`: 문서화된 합의 식별자와 일자로 **활동 중지**. 기존 POP·무기·국가 재정은 그대로. 공식 조약·완전한 무장해제를 자동 주장하지 않는다.
  - `enacted_reform`: 요구한 P3 쟁점·선택과 **실제로 유효한 P2 법률**이 일치해야 정치적 종결 인정. 연결된 국가 P5 위기가 아직 진행 중이면 동일한 시행 법률에 따른 `P5Settlement::legal_concession`을 기록해 위기를 함께 해소하며, 과거 교전·병력·재정을 삭제하지 않는다.
  - `disarmed`: 실제 C 부대가 활동 인원을 잃었거나 지급된 소총·탄약이 없어야만 무장해제 종결로 판정.
- 정규전으로 확대된 캠페인을 종결하려면 먼저 **P5의 실제 전면 위기 정산 상태**를 확인.
- 지역 유격활동이 종결되더라도 과거 사건·원본 인구·재정·무기·법적 주권은 삭제하지 않음. 사건 기반 지역 접근 차질은 법적 분쟁 종결과 별개로 원래 만료일까지 적용 후 종료.

## 일간 연산 및 성능

- 캠페인 개시·확장/실제 사건은 Stage9/Stage10 사용자·시뮬레이션 명령으로 처리.
- 운영 중 캠페인의 보급·활동 상태는 **7일 간격의 파생 due 색인**을 통해 검토. 정기 검토는 전투를 자동 발동하지 않는다.
- 실제 시민 접근 차질은 효력 시작·만료 시기에만 스케줄을 갱신하며, 효력이 있는 동안 매일 해당 지역의 현재 값만 사용.
- 비활성·미존재 캠페인은 예전 C/P3/P5 계산 및 빠른 달력일 건너뛰기 경로를 변경하지 않음. P5-G가 없는 구형 세계는 저장 형식과 성능 비용을 최대한 보존.
