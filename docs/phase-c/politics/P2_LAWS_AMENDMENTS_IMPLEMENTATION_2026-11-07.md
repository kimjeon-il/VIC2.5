**시점:** 2026-11-07  
**상태:** 실제 C++ 원장·일간 커밋·저장 확장·회귀 사례 작성 / **미검증(UNVERIFIED)** / `main` 미병합.

## 1. 구현 범위와 책임

| 구분 | 실제 코드 계약 | 특징 |
|---|---|---|
| 기본법 | `P2BaseLaw`, `p2_active_base_` | (국가, 법률 분야, 관할)당 시행 중인 기본법 하나. 법률 선택·근거·법적 위계·원문 조항을 구별 |
| 세부 조항 | `P2Clause` | 종류·표적 공직/국가·정수 값. 표면적 수치가 아니라 P4·국가세제에 실제 규칙 제공 |
| 증보(Amendments) | `P2Amendment`, `p2_active_amendments_` | 기본법에 복수 증보 추가·폐지. 배타적 증보/같은 조항 중복·서로 다른 위계 충돌 검사, 기본법 원본 보존 |
| 입법 | `P2Bill` | 제출→실제 P1 정부·P4 의석 승인→국가원수 공포→지정 일자 시행; 경과규정은 별도 전이 |
| 규범 적용 | `p2_rule` | 헌법>법률>위임 규정>조례 우선, 동일 우선순위 충돌 시 명시적 오류. 대외법/판례의 전체 규칙 엔진이 아님 |
| 국가·재정 | 기존 P1·C | 새로운 P2 POP·현금·재고·국가 원장 없음. 실제 조세법안은 유효 세율 범위에서만 허용 |
| 입법 이력 | `P2LawEvent`, 옛 법·증보 보존 | 법률 교체·증보 폐지 후 과거 버전과 제정 근거 보존 |
| 날짜 | `phase_time_apply_p2(today)` | 같은 실제 달력일의 Stage0에서 공포된 법령 효력. 월간 전용 계산 재실행 없음 |
| 저장 | `VIC25_PHASEC_P2_LAWS_1` | P1/P4/구형 C 세이브 변경 없이 필요한 세계에만 선택적으로 추가. 미시행 법안도 저장 |

기존 `p2_voting_age(country)`와 `p2_rule(country,target,kind)`를 조회해 P4의 국가별 선거연령과 기존 C 국가별 소득세 개정 상한을 결정한다. P0 기본 국가 재정 AI도 P2 세율 범위를 준수한다.

법률 전체를 매일 다시 해석하지 않으며, **공포 후 효력일이 도래한 국가/기관만 갱신**하도록 만든다. 단, 기존 Stage11 전원장 정합성 검사 비용은 별도로 측정해야 한다.

## 2. 선출직별 임기법 — P2와 P4의 경계

법률의 정본은 P2이고, 선거 실무·현직 임기·차기 선거일 정본은 P4다.

### P2에서 시행 가능한 조항

| 조항 | 값/단위 | P4 적용 |
|---|---|---|
| `term_months` | 1~240개월 | 해당 선출직 다음 임기의 법정 기간 |
| `max_consecutive_terms` | 0(무제한)~20회 | 국가원수의 연속 재임 후보자격 |
| `max_lifetime_terms` | 0(무제한)~20회 | 국가원수의 총 재임 이력 기준 후보자격 |
| `term_cycle_mode` | 조기선거 후 재설정 / 고정 주기 | P4의 정기 선거 일정 |
| `dissolution_authorized` | 0/1 | 해당 의회 해산권 |
| `dissolution_max_delay_days` | 1~365일 | 법적 해산 후 조기 선거 실시 기한 |
| `voting_age_years` | 0~120세 | 해당 국가의 실제 선거권 조회 |

의회·지방·국가원수의 임기는 **개별 P4 contest ID**로 지정한다. 국법이 바뀐다고 다른 기관 임기를 함께 변경하지 않는다.

**임기 경과 조항(`P2ElectionTransition`)**

- `future_term_only`: 기존 현직 만료일·예약 선거일을 유지. 다음 선거 당선자의 임기는 새 법률 적용
- `incumbent_as_well`: 명시된 합법적 새 정기선거일로 해당 기관의 다음 선거일을 변경. 효력일 이전으로 소급 변경 불가
- 대체 법률이 P4의 유효 임기 정보를 완전히 잃게 만드는 변경은 거부
- 증보가 P4의 구체적인 임기·주기·해산권을 덮어쓰는 경우에는 **기본법에 원래 조항이 있어야 하며**, 증보 폐지 시 원래 값으로 복원
- P4 기존 `p4_schedule_term_amendment`는 P2가 현재 해당 임기를 소유하는 경우 직접 실행을 금지해 중복 법률 경로를 방지

재임 횟수 제한은 현재 **실제 국가원수 선거의 당선자 이력**으로 지원한다. 지방수장 개인후보, 상·하원 의원 개인의 연임 횟수·중도 사퇴/승계에 따른 부분 임기 산입은 현재 P1/P4에 필요한 정본이 없어 미완성이다.

## 3. 증보의 실제 동작

- 기본법(예: 국회의원 임기 48개월)을 유지한 채 증보로 60개월 적용 가능.
- 증보의 법적 제정·공포·효력일을 별도 P2 법안으로 처리.
- 증보 폐지는 같은 법률의 원래 48개월 조항을 복원. 기존 현직 선거일은 별도 경과규정 없으면 변경하지 않음.
- 서로 다른 조항을 조정하는 증보는 복수 허용. 하나의 조항을 서로 다른 활성 증보가 중복 지정하거나, 같은 배타 집단의 증보 두 개가 공존하면 거부.
- 기본법이 다른 법률로 교체되면 기존 증보의 활성 연결은 해제되지만 법률·증보 이력은 보존한다.
- 현재 증보의 실제 효과는 **타입이 있는 규범 조항**으로 한정된다. 단순 임의 정치력 보너스·현금 생성 기능은 없음.

## 4. 입법 절차

1. `p2_submit_bill`: 실제 정부수반 확인, 법률 분야/관할/개정 목표, 효력일 및 경과규정 검사
2. `p2_approve_bill`: 존재하는 의회의 실제 득표 의석으로 의결. 일반법은 P1 정족수, 헌법급은 의석의 2/3 이상. 무의회에서는 P1의 직접통치 권한이 있는 경우만 가능
3. `p2_promulgate_bill`: 실제 현직 국가원수의 공포와 지정 효력일 예약
4. `phase_time_apply_p2`: 개정·추가·폐지·교체에 따라 P2 유효 조항 갱신, 해당 P4 선출직 일정/자격 갱신 및 법률 이력 기록

P0 `LegislativeOrder`는 세 단계를 서로 다른 날짜에 제출할 수 있으며, 같은 날 제출하려면 정책 순서대로 적법하게 실행해야 한다.

**현재 미구현:** 다단계 의회 심사·상하원 별도 의결·거부권과 재의결·국민투표·협상 확률·P3 지지에 따른 증보 자동 제안. 이번 코드는 본격적인 빅토리아 3식 입법 협상 전체가 아니라 **P2의 기초 법적 상태와 실행 규칙**이다.
