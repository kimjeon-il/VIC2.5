# VIC2.5 — P2 잔여 정치 기능 보강 (2026-11-08)

**작업 브랜치:** `work/p2-politics-completion` (직전 `work/p2-laws-amendments` 기반)  
**상태:** C++ 코드·일간 연결·직렬화·집중 회귀 3개 작성. **컴파일/CTest/CI/장기 벤치마크 미실행, UNVERIFIED, main 미병합.**

## 1. 법률 선택지의 실제 효과

`P2ClauseKind`를 단순법률 설명에서 실제 권한·행정·경제/POP의 사전조건으로 확장했다. 단일 규범은 P2가 소유하고, 효과는 기존 단일 정본을 가진 분야가 실행한다.

| 법률 선택지/조항 | 실제 적용 경로 | 효과 |
|---|---|---|
| 국가별 선거연령·여성선거권 | C 국가별 선거, P4 독립 선거, P0 기존 선거 | 실제 POP 나이/성별과 법적 자격 확인. 없는 법률 데이터는 기존 버전의 허용 기본값으로 유지하며 역사적 정확성을 주장하지 않음 |
| 선출직 임기·주기·연속/통산 횟수 | P4 elected contest, 개인별 `P4PersonTerm` | 의회·상원·지방의회/지방수장·국가원수 단위로 재임 횟수/후보 자격을 조회. 실제 이름/POP 참조가 있는 경우만 개인 임기 기록 |
| 공공의료 권리 | C `provide_public_healthcare` | 법률의 허용/금지. 실제 지급 임금·의사·의약품·병원 슬롯을 여전히 요구 |
| 공공기관 등급 | P1 `p1_institution_capacity` | 0~5단계 법적 등급에 실제 인력·예산·시설을 대조. 허구의 수용인원 생성 불가 |
| 징병 허용 여부 | C `mobilize` | 실제 인구의 병역 전이 시 유효 국가 군사법 적용 |
| 고용계약 최저임금 | C `hire` | 새 계약의 법정 월임금 하한을 적용. 기존 계약·체불 변제는 원본 노동/금융원장에 남김 |
| 수입관세 법정 상한 | H `adopt_tariff_daily`/월간 `adopt_tariff` | 권한이 있는 정부라도 초과 관세 명령은 거부. 수입품 가격·현금은 H/G/C 실제 거래에서 처리 |
| 정치적 결사·평화로운 파업 | C `join_interest_group`, `organize_from_food_grievance`, `protest`; P0 기본 반응 | 유효법에 따른 **합법적** 결사·파업 권한. 불법 지하운동·파업 탄압과 그 결과는 P5 후속 |
| 소득세 허용범위 | C `propose_tax_law`, P0 국가 AI | 기존 P2 조세법 상한·하한과 대조, 현금·납세자 생성 없음 |

이 구현은 **범용 법률 카탈로그의 타입 검사와 대표 분야의 실질 효과**까지다. 빅토리아 3의 모든 개별 법률 선택지가 실제 지리·POP·재정에 동일한 수준으로 연결되었다고 보지 않는다. 토지·소유권/노예제·금융/통화·고급 교육/이민·치안·사법·식민·무역계약의 전체 효과는 후속 분야 연계가 더 필요하다.

## 2. P3 이익집단과 자동 증보 협상

- 국가/법률 분야/이익집단/증보 조건과 요구를 `P2GroupDemand`에 등록.
- 실제 P3 `membership_`와 B 인구·해당 주권국에 기반한 지지 비율을 검사.
- 조건 충족 시 제출 중인 법률안에 다중 증보를 자동으로 협상하고 `P2NegotiatedAmendment`에 법적 근거·해당 시점의 지지 인원·수락일 저장.
- 동일 조항의 상충, 배타 증보 및 기존 기본법에 없는 P4 임기 개정을 방지.
- 이미 하원 의결을 거친 법률안에 뒤늦은 증보 삽입 금지.
- 법률이 공포되고 시행되는 날에만 실제 증보를 기본법에 부착. 과거 P3/pop/재정과 사건을 중복 기록하지 않음.
- 매일 전 세계 과거 법안을 스캔하지 않도록 **미처리 법안의 파생 색인**을 사용하고 저장·복구 시 재생성.
- 이익집단의 요구 자체는 자료·시나리오 입력이 있어야 하며, P3 이념/정책성향을 추정해서 임의로 증보를 만들어내지 않는다.

## 3. 실제 양원제

- P1 `bicameral` 선택을 확장.
- P4에 `upper_chamber` 유형을 새로 추가. 상원은 별도 선거시기·의석·POP·법적 권한을 가지며, **기존 C 하원 단일 의석 원장을 덮어쓰지 않는다**.
- P2 `p2_register_upper_chamber`는 P1의 양원 헌법과 실제 P4 상원 contest를 참조.
- `p2_approve_bill`은 하원 의결 후 상원 승인을 대기하며, `p2_approve_upper_bill`에서 실제 상원 의석·여당/야당 표·과반수(헌법급 특별다수)를 재검사.
- 두 의결을 모두 기록해야 국가원수 공포 및 법률 효력 예약 가능. 이전 의회 회차가 뒤바뀌면 기존 승인 재사용 금지.
- 기존 P0에 `LegislativeAction::approve_upper` 추가.
- 과거 법안/회계 상태와 양원 의결 기록을 별도 선택적 확장에 보존.

**제약:** 지금은 표결 가능한 선출 상원 한 개와 하원 한 개의 법률 의결을 구현. 임명상원·부분교체 상원·양원 협의회·상원과 하원의 고유한 권한 범위, 다수 번안·재의결 및 상원의 거부권 예외는 모두 완전 구현이 아님.

## 4. 지방수장·의원 개인별 연임·중임

- P4 `local_head`, `upper_chamber` 유형 추가. 기존 `legislature`/지역 의회도 개별 후보 명부를 참조할 수 있음.
- P4 `p4_nominate(contest,party,person_ids)`는 실제 C `PersonAnchor`와 Phase B POP 시민권·주권/지역을 검사. 가상의 주민·정치인 생성 금지.
- 정당표로부터 실제 개인에게 배분된 의석을 `P4PersonTerm`으로 추적: 해당 공직의 총 당선 횟수, 연속 당선 횟수, 현직 여부, 마지막 당선일, 정당.
- P2 법률의 `max_consecutive_terms`, `max_lifetime_terms`을 국가원수뿐 아니라 **실제 후보 등록된 하원·상원 의원과 지방정부 수장**에게 적용.
- 현직 재선 실패 시 연속 당선 횟수 초기화. 임기 제한을 넘는 후보는 당선 처리 불허.
- 기존 `P4Party.head_candidate`만 있는 세이브는 실명 후보·POP이 없는 상태로 유지하고, 임의로 개인 임기 원장을 채우지 않는다.

**제약:** 당선 횟수와 연속 임기 계산은 구현했지만 선출되지 않은 임명관, 중도사퇴·사망·승계에 따른 부분 임기 산입과 여러 직위 간 임기 통산, 개별 의원의 표결 행동은 독립적인 후속 구현이 필요하다.

## 5. 호환성·실행

- 기존 P1/P2/P4 세이브 필드 배치를 변경하지 않고, 새로운 상태가 존재하는 경우만 `VIC25_PHASEC_P4_PERSONAL_MANDATES_1`, `VIC25_PHASEC_P2_POLITICAL_PROCEDURES_1` 선택적 확장을 부착.
- 기존 `P2Bill`, `P2BaseLaw` 저장 구조 유지. 신규 상태는 구조체를 새로 정의하고 별도 확장에 저장.
- `daily::World`의 날짜별 Stage0 시행 및 Stage9 협상은 기존 C/D/E/G/H 원자적 커밋을 통해 처리. 기존 월간 독립 엔진은 변경하지 않음.
- 신규 `tests/test_p2_advanced.cpp` 3개 집중 통합 시나리오: 상원/의원/시장 재임 이력과 세이브, P3 자동 증보 협상·하원/상원 의결·다음날 효력, 임금/징병/관세 위법 명령 롤백.
- `CMakeLists.txt`에 실행 가능한 회귀 타깃을 추가하였으나, **이번 작업에서 컴파일·CTest·CI 및 대규모 장기 시뮬레이션은 실행하지 않았다**. 아직 정상 실행을 인증할 수 없다.
