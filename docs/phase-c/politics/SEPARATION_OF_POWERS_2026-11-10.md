# VIC2.5 입법·권력분립 확장 (2026-11-10)

작업 브랜치: `work/politics-separation-powers-20261110`. 기존 P1~P5 원장과 일간 Stage 0/9 실행 순서를 유지한다.

## 구현 순서와 소유권

1. **헌법-정부 연동:** P2 헌법급 `governance_principles` 및 `distribution_of_power` 법률의 실제 효력 발생 시 P1 헌정 구조를 변경한다. `P1Constitution` 기존 저장 레이아웃은 유지한다. 지원하지 않는 국가체제 선택은 거부한다.
2. **국가원수 거부권:** `P1LegislativePowers`에 없음/재의 가능/절대 거부, 재의결 정족수, 서명 기한, 의회 정당 발의권을 둔다. 대통령제는 별도 헌법 규정이 없으면 재의 가능 거부권을 기본값으로 한다. 다른 체제는 기본적으로 거부권 없음. 헌법급 법률의 `constitutional_*` 조항으로 변경할 수 있다.
3. **상·하원 재의결:** `P2Assent`는 최종 의회 승인 이후에만 열리며, 기존 실제 P4 의석 원장을 사용한다. 재의 가능 거부권은 해당 헌법의 특별다수로 상·하원 각각 재의결할 수 있다. 기한 경과 시 서명 간주, 거부 후 30일 내 재의결이 없으면 법안 실패. `p2_promulgate_bill`은 서명 또는 재의결 증거를 요구한다.
4. **독립 발의:** 총리뿐 아니라 실제 해당 국가 의회에서 의석을 가진 등록 정당도 발의 가능하다. 발의자 권한과 의회 의결은 분리한다.
5. **철회·정치 반발:** 제출 상태 법안 철회, 재시도 제한, 해당 법률을 지지하는 기존 운동의 급진성 상승.
6. **입법 확률·협상:** 실제 IG 지지/반대·승인도·급진성을 반영한 확률 가중치, 급진적 반대집단의 협상 거부. AI는 새로운 법률 선택지에 대한 실효 조항을 보유한 기존 역사적 템플릿이 없으면 거짓 법률 효과를 만들지 않는다.

## 명령 및 저장

- P0 `LegislativeAction`: `introduce`, `approve`, `approve_upper`, `sign`, `veto`, `override_veto`, `withdraw`, `promulgate`
- P1/P2: `p1_legislative_powers`, `p1_set_legislative_powers`, `p2_sign_bill`, `p2_veto_bill`, `p2_override_veto`, `p2_cancel_bill`
- 선택적 저장 확장: `VIC25_PHASEC_SEPARATION_POWERS_1`. 기존 `P1Constitution`, `P2Bill` 바이너리 순서 및 인구/의석 원장은 변경하지 않는다.
- 기존 세이브에서 승인되었지만 `P2Assent`가 없는 과거 법안은 이전 공포 경로를 유지한다.

## 제한과 확인 상태

- 헌법상 사법심사/법원 독립, 완전한 역사적 헌법 조항별 거부권 예외, 모든 Victoria 3 1.15 이념·이벤트·법률 효과의 정확한 데이터 대조는 이번 작업 범위 밖이다.
- 정당별 의석을 실재 표결 단위로 사용하며 의원 개인의 반란표·기권표는 별도 생성하지 않는다.
- 전체 빌드, 전체 CTest 및 장기 게임플레이 회귀는 요청에 따라 생략했다. 코드 참조와 괄호 균형의 제한적 정적 점검만 실시했으며, 런타임 정상 동작이 확인되었다는 뜻은 아니다.
