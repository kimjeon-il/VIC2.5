# VIC2.5 C-P1 — 국가·정부·헌정기관·행정체계

- 상태: 설계 확정, 구현 전
- 계약: `phase-c-politics/1.0`, 기준일 2026-11-03
- 상위: `phase-c-common/1.0`, `phase-c-economy/1.0`, `pop-design/1.1`

## P1-1. 설계 원칙

정치체제를 `monarchy` 또는 `republic` 같은 단일 enum과 보너스로 환원하지 않는다. **국가의 국제법적 존속**, **헌법상 권한**, **현재 정부 구성**, **실제 행정 및 물리적 통제**, **주민들의 체제 인식**을 분리한다. 의회·정부·국가원수·지방행정·사법부는 각각 다른 기관이며, 하나의 제도가 없어도 다른 제도가 존재할 수 있다.

| 객체 | 핵심 필드 / 책임 |
|---|---|
| `Country` | `country_id`, 외교적 법인격·존속 이력. 총인구·국고·국채의 별도 원본 금지 |
| `ConstitutionalOrder` | `order_id`, 유효기간, 헌정 권한·기관 성립 규칙·우선규범·개정절차·source_provenance |
| `StateOffice` | `office_id`, 종류(head_of_state/head_of_government/minister/judge/commander/local_office), 임명·승계·해임·임기 규칙, 권한 범위 |
| `OfficeTenure` | `office_id`, `holder_id`, `from_month`, `until_month`, `appointing_event_id`, 적격성·유효성; 동일 시점 단독직 중복 금지 |
| `PoliticalActor` | 필요시 이름 있는 통치자·정치인·관리의 안정적 ID, 이력과 이해관계·직위; **독립 인구수는 없음** |
| `PersonAnchor` | 실재 인물 1명을 특정 `PopulationSlice` 분할에 귀속한 참조. anchor별 실제 인구 1명만 점유, 다른 단독 인물 anchor와 중복 안 됨 |
| `Government` | `government_id`, 국가, 정부수반, 집권 지원기반, 시작/종료, 집행권 관할. 국고와 주민을 소유하지 않음 |
| `Cabinet` / `MinisterialPortfolio` | 내각·부처, 임명권·업무 관할·책임·예산 승인 출처. 부처 운영비는 E4 계정/실제 고용·재고 |
| `Legislature` / `Chamber` | 의회·상하원, 구성 방식·임기·의석 정원·입법/감사/불신임/예산권 |
| `SeatTenure` | chamber/seat/bloc/party/candidate 귀속, 개시·만료·결원 사유. 의석은 **사람 수가 아닌 대표 단위** |
| `Judiciary` / `Court` | 법 적용/심사·재판관 임명·관할·집행기관 연결. 집행력은 인력·재정 제약 |
| `PublicInstitution` | 정부 부처·관료 조직·교육·치안·선관위 등; `C-E4 PublicInstitution`과 **동일 ID 정본** 사용 |
| `AuthorityGrant` | `actor_or_office_id`, `power_kind`, 법적 근거, 범위·상위법, 유효기간·재위임 조건 |
| `AppointmentDecision` | 임명·선출·승계·파면·해산·정권 구성 사건, 선행 의결/승인·효력시점 |

## P1-2. 국가와 통치권, 정당의 분리

1. `Country`는 계속 존재하면서 여러 `Government`가 순차적으로 교체될 수 있다. 내각 사퇴나 군주 사망으로 `Country`, 국채, 국고, 인구를 새로 만들지 않는다.
2. `ConstitutionalOrder`는 행정부 구성방법, 입법기관, 선거·국가원수 임명/승계, 거부권·비상권력·사법심사 등을 **조합**한다. 군주국에도 선출 의회가, 공화국에도 임명제 상원이, 식민정부에도 제한적 지방의회가 존재할 수 있다.
3. `HeadOfState`와 `HeadOfGovernment`는 **역할**이다. 동일 정치행위자가 겸직할 수도, 분리될 수도 있다. 임명·대리·섭정·집단지도부의 법적 근거가 있어야 한다.
4. 다수당·연립정부·궁정/군정 내각·임명정부는 서로 다른 `GovernmentFormationRule`로 구성한다. 정당 없는 국가에서 자동으로 가상 정당을 생성하지 않는다.
5. `StateOffice`가 명목 권한을 갖더라도 실제 영향력은 인사·기관 충성·정책 집행·통신·물류·예산 등 관측 가능한 관계로 판단한다. 법적 권한과 사실상의 지배를 한 지표로 합치지 않는다.
6. 정치 지도자와 의회 의원이 별개 인간 객체라면 반드시 POP 주민 집계에 포함되거나 자료 미상 집단/외부 인물로 근거 있게 취급한다. 필요한 경우만 `PersonAnchor` 1명을 예약하고 나머지 대표성은 의원 블록/의석의 정수 집계로 처리한다. 한 대표석마다 임의 주민을 추가 생성하지 않는다.
7. 여러 종속국·제국·연방·지방국가는 `Country` 및 중앙-지방·종속·보호 관계를 별도 `AuthorityGrant`/외교 관계로 기록한다. C-D0의 주권·민정·과세권·군사통제 관계와 충돌하지 않는다.

## P1-3. 권한과 헌정절차

권한 종류: 법안발의(`propose_law`), 입법의결(`vote_law`), 거부·재의(`veto`), 공포(`promulgate`), 예산안 제출/승인, 세금 신설 권한, 내각 임명/파면, 불신임, 의회 해산, 군 지휘·동원 승인, 외교조약 승인, 사법심사·행정명령 등.

`IsAuthorized(command, stage, effective_law, office_tenure, jurisdiction)`은 명령마다 **적용 법률·유효직위·지역적 권한·의결/정족수 선행조건**을 검사한다. 국가원수나 플레이어가 개인적 의지로 법을 즉시 바꾸는 지름길을 만들지 않는다. 헌정 절차가 없는 절대 권한은 해당 시기 유효 법률이 그 권한을 지정한 경우로 한정한다.

- 정부수반 교체·선출·승계는 독립된 `AppointmentDecision`이다. 단계 9에서 확정된 정권구성은 기본적으로 **다음 달 단계 0**부터 효력을 갖는다.
- 법적 공백과 대행권(`caretaker`, `regency`, `interim`)은 유효 헌정규칙에 따라 설정하고, 예산 집행권이나 의회 해산권 등 한도를 표시한다.
- 선출된 의회의 표결, 상원 동의, 군주 재가, 주민투표, 판결 등에 서로 다른 승인 필요조건과 실패·대기·재시도 경로를 정의한다.
- 해산된 의회의 기존 법률과 공공부채는 계속 유효하다. 새 의원 선거/임명은 실제 기간과 사건을 거친다.

## P1-4. 중앙·지방 권력과 행정역량

`AdministrativeJurisdiction`은 (기관, region, 분야, 유효기간) 관계이며 C-D0의 `TerritorialJurisdiction`과 대조한다. 중앙-지방, 연방-주, 자치령, 점령지의 **정책결정 권한**, **집행기관**, **재정 귀속**을 별도 필드로 표현한다.

행정역량은 '행정력 100'이라는 무상 자원 대신 다음 병목을 함께 검증한다.

- 법적으로 허용된 집행권과 유효 기관/업무 범위
- 실제 채용된 공무원·교사·경찰/법원 종사자의 `EmploymentLedger` 계약·자격
- `FiscalLedger`의 예산 승인 + `FinancialLedger`의 실제 급여/운영비
- `InventoryLedger`의 실제 사무·통신·치안·의료 물품, 건물·설비, E5의 지역접근·운송/통신
- 업무 사건량/처리량/잔여 대기·지역 행정 네트워크, 관련 POP의 권리 행사·복종·신뢰 상태

예시형 `processed_cases = min(valid_requests, staff_supported_capacity, facilities_supported_capacity, funded_operation_capacity, access_capacity)`; 시대별 인력당 처리건수는 규칙 파일로 관리한다. 처리 실패·체납·행정 지연은 기한/사유를 기록하고 조용히 즉시 집행된 것으로 처리하지 않는다.

## P1-5. 통계·연산 경계

의회정원/실제 재적/결원, 정부 임기, 법적 권한분포, 각 부처 실제 예산/고용/업무 처리량, 지방정책 격차, 정권/국가/헌정질서 이력을 산출한다. 주민수와 정치적 지지는 POP 기반 조회값이다.

- **0단계:** 지난 월 확정된 공직/권한/지역관할 변경 발효.
- **1~8단계:** 현행 권한에 의한 정부 집행과 경제 예산/계약의 실제 결과.
- **9단계:** 적격 임명·연정·정권 구성·해산 의결과 차월 효력 예약.
- **11단계:** 같은 단독직위 중복·기간 역전·무권한 결정·의석 정원 위반·국고/인구 이중 원본 검사.

## P1 설계 게이트

- P1-G1: 국왕 사망 또는 총리 사퇴로 국가·POP·국채가 새로 생성되거나 삭제되지 않는다.
- P1-G2: 동일 단독 직위에 양립 불가한 2명 동시 임명 거부, 겸직·섭정 예외는 규칙 명시.
- P1-G3: 의회 없는 국가에서 정당 득표와 의석이 자동으로 발생하지 않는다.
- P1-G4: 중앙·지방·영토 점령지의 권한·예산·과세권을 혼동하지 않는다.
- P1-G5: 공무원·시설·재정이 없는 새 행정부에 즉시 무제한 집행능력이 생기지 않는다.
- P1-G6: 정치 지도자 `PersonAnchor`가 POP 유일한 인구수에 중복 합산되지 않는다.
- P1-G7: 내각 교체와 기존 법/고용/세입/재고 원장이 독립적으로 보존된다.
