### 정치력/정통성 임시 계산

- 집단 지지 = 해당 **국가**의 P3 실제 가입 인원 중 집권 집단 가입 인원의 비율
- 의회 지지 = 같은 국가 P4 실제 의석 중 정부가 연결한 정당 의석 비율
- 헌정 적합성 = 정부 신임 조건 충족 여부 (불명인 경우 50)
- `정통성 = floor((50×집단지지 + 30×의회지지 + 20×헌정적합성)/100)`
- 각 구성요소에 대해 `observed_groups`, `observed_election` 확인 가능. 자료가 없는 부분은 50의 중립값이며 **검증된 역사적 정통성이 아니다**.
- **P3의 이념별 정책 선호, 무차별 정치력 및 정치적 갈등 감점은 별도 작업**. 8개 이익집단 타입은 고정 열거형이 아니라 P3 시나리오의 그룹 ID로 보유.
