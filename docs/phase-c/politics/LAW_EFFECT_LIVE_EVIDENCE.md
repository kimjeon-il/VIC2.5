- **56행:** 법이 직접 지목한 증보 이해집단 13, 실제 직업별 소속 인원 정치력 13, 정본 국가 기본법의 이해집단 정치력 23, 실제 가동하는 교육·복지·보건 기관 단계 7. 일반 경찰·내무기관 혼용, 근거 없는 직업, 후원 조건을 끌어오지 않는다.

- **10행:** 가동에 들어간 공장의 법정 보상 비용 4, 프로젝트의 실제 현금 보상 가격식에 반영한 보상률 5, 같은 고용주·지역의 실제 POP 불만 1. 이 중 원본 키 이름이 투자 수익인 5행은 이 프로젝트의 보상 가격식만 검증했다. 원작 투자풀로의 수익 귀속이나 이체를 구현·검증한 것이 아니다.

- **2행:** 전통주의(−50%)와 농본주의(+50%)가 확인된 농민 지분의 일일 민간 건설비 산정에 반영된다. 실제 자금으로 승인·지급된 프로젝트만 검증했으며, 추가 자금·체불을 만들거나 기존 체불 제한을 풀지 않는다. 원작 투자풀 적립이나 전체 직업의 투자 효율을 입증한 것은 아니다.

- **30행:** 기존 코드가 이미 적용하던 법률별 직업·지분 효과를 실제 대금이 지급된 일일 민간 건설 주문으로 추가 검증했다. 이 30행은 새 경제 기능을 추가한 것이 아니다. 원작 공용 투자풀의 적립·배분까지 입증하지 않는다.
- **1행:** 산업 금지법 아래 확인된 귀족 주주가 실제 월간 가계 지갑에서 회사 자본으로 출자한다. 지분·영업수입은 바뀌지 않고, 가짜 지방·사용자 정의 법률, 무자금, 무지분에는 적용하지 않는다. 국고나 공용 투자풀이 관여하지 않는다.
- **2행:** 농민 징집과 전사 계급 법률의 군수품 비용 −10%를 적법한 국고 주문의 실제 결제·재고로 확인했다. 사적 매수나 고정 계약 가격까지 바꾸지 않는다.

- **3행:** 기존 오스트리아 국무회의 증보 세 종류가 실제 효력일에 자발적 내각 개편만 막는 동작을 각 원본 행과 대조했다. 외국, 잘못된 모법, 지방 조례에는 적용하지 않는다. 내각 개편 금지 자체는 기존 기능이며, 이번에는 해당 증보의 법적 근거를 확인해 검증 기록에 넣었다.

## 보류: 해당 법률을 맡을 실체가 필요한 부분

| 항목 | 아직 필요한 연결 |
|---|---|
| 단기 감세의 실제 징수와 주 세금 징수력 | 즉시 지급 `wages_under_law`는 세율/부문/행정 손실을 적용하지만 체불 지급 `phase_time_settle_wage_arrears`에는 국가 세율만 남고 과세 발생지·부문이 보존되지 않는다. 양 경로에 공통 징수 기준과 소득원천을 연결한다. 이미 기록된 임금채무·관세·법정 세율은 바꾸지 않는다. `state_tax_capacity_mult`는 징수액 보정이 아니라 확인된 주별 과세 기반·행정 징수 한도가 먼저 필요하다. |
| 종교별 임금 6행 | 신규 채용만 바꾸면 기존 계약의 급여가 누락된다. 예약·부채 발생·사업비 예측과 시나리오별 지급에 공통 임금 기준 및 실제 수령자 종교 근거가 필요하다. 최저임금 순서·과거 부채 고정 원칙도 명시한다. |
| 정부 배당 효율·재투자 | 실제 국고 배당은 `pay_dividend`에서 지급되지만 징수 손실 보정과 재투자 배분은 다른 기능이다. 특히 재투자에는 순수령분을 어떤 법정 투자 지갑/회차에 귀속해 실제 건설에 쓰는지, 잔액·재지급·중복 사용을 막는 원장이 필요하다. 일반 증권 배당을 회사 전용 배당으로 간주하지 않는다. |
| 내무기관과 전쟁 지지도 | 내무기관은 일반 경찰과 별도 식별되는 가동 단계가 필요하다. 전쟁 지지도는 실제 승전·패전·사상자 영수증에서 독립 지표와 평화 판단으로 이어지는 경로가 필요하다. 일반 불만·정치운동 급진성·군 사기 등으로 대신하지 않는다. |
| 부문별 집단소유 전환 | 실제 회사/시설과 산업 부문, 종업원 또는 집단의 소유 지분, 전환 상한과 대가를 소유권 원장에 함께 기록해야 한다. 가동 공장의 국유화에 성공해도 다른 소유권 전환이 자동 검증되지는 않는다. |
| 조약항과 법률상 지정 관문 | 조약과 항구·해당 시장의 연결, 통행 주체와 실제 상업 경로의 근거가 있어야 한다. 광저우·규슈 규정도 별도 관문 판정이 필요하다. 일반 고립주의 제한을 조약항 예외나 모든 화물·운하에 확대하지 않는다. |

지금 당장 추가로 확정할 새 항목은 제안하지 않는다. 후보인 배당 효율은 실제 지급 경로가 있지만 징수 손실과 보너스의 정확한 합성 및 회사/국고 범위를 검증한 뒤 별도 판정한다.

## 재실행 안내

`python3 scripts/verify_phase_c_baseline.py`는 48개 설계 사례 ID와 27개 고정 원본을 확인한다. 60행 문서의 8개 근거 실행 파일을 기준으로 하되, 186행 현황에는 Phase D, Phase G 상업, 일일 시뮬레이션 및 내각 개편 실행 파일 4개를 추가한다. 다음은 배치 선택식이며, 이 목록 전체를 이번 집계에서 다시 돌렸다는 뜻이 아니다.

```sh
ctest --test-dir build -C Release --output-on-failure \
  -R '^vic25_(phase_[cd]_tests|phase_gh_(commerce|diplomacy)_tests|p0_daily_(tests|longrun)|p1_cabinet_reform_lock_tests|p2_advanced_tests|p3_p5_politics_tests|politics_(catalog|domain|identity)_tests)$'
```

선택식은 현재 `CMakeLists.txt`에 등록된 이름 12개와 일치한다. 이번 독립 집계는 위 진단을 직접 호출했고, 일반 계약 검사·네이티브 표적 검사와 호스팅 전체 CI는 각각 별도 근거로 보고한다. 전체 CI는 [통합 검사 실행 이력](https://github.com/kimjeon-il/VIC2.5/actions/workflows/merge-all-integration.yml)에서 이 코드가 포함된 `main`의 해당 실행을 찾아 확인한다.
