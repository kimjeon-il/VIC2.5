# 정치 자율 순환 후속 구현 — 2026-11-13

기준 브랜치: `work/politics` (`ca798563`). 일간 Stage 0~11 및 기존 C/P1~P5/E/H 원장 유지.

## 1. 국가 정치 AI의 법률 개혁 선택

- 기존 국가 내 **효력이 있었던 목표 법률 템플릿**을 우선 재사용한다.
- 없으면 1.15 중앙 법률 카탈로그에 **실제로 존재하는 법률군/선택지**로만 새 `P2BaseLaw`를 작성한다. 이전 법률의 조항은 복제하지 않으며, 법률 ID와 법률군이 참조하는 기존 효과 경로를 사용한다. 미지원 조건부 효과까지 자동 구현됐다는 뜻은 아니다.
- 정식 정치운동의 실제 요구를 우선하며, 운동이 없어도 집권 이익집단의 실제 정치력과 법률 선호를 평가한다.
- 동시 법안·재시도 제한·법률 간 상호 배타 조건을 미리 검사한다. 기존 3단계 제정, 상·하원, 거부권, 공포를 우회하지 않는다.

## 2. 혁명·내전 자동 진행

- 기존 `p5_auto_prepare_revolutions`는 실제 군인, 부대, 탄약, 무기를 검증한 후에만 무장 위기를 시작한다.
- 새 `p5_auto_resolve_crises`는 실제 운동 압력이 소멸한 위기를 종결하고, 실제 법률 개혁이 효력을 얻은 비무장 위기를 합의로 종결한다.
- 실제 군사 점령 증거가 수도에 있고, 쿠데타이거나 실제 교전이 기록된 혁명이며, 살아있는 후계 정치인이 있는 경우에만 기존 `p5_settle`로 정권 교체를 예약한다. 영토 소유권·국고·병력·무기를 새로 만들지 않는다.
- **미완성**: 다수 전선의 전투 AI, 실제 전투 결과를 이용한 전면 자동 점령, 분리독립 신국가의 영토·국고 이전 및 자동 평화협상. 이 작업은 C/E/H 도메인 소유자와 별도 연결해야 한다.

## 3. 기존 content 엔진의 정치 명령

- `content::ExternalKind`에 `propose_law`, `bolster_movement`, `suppress_movement`를 추가했다.
- JSON 효과는 `law_domain`/`law_choice` 또는 `movement_id`를 명시해야 한다. 해당 국가의 실제 정치 상태와 기존 법률·권위·운동 자격을 검증한 뒤 Stage 9의 정식 `p2_propose_catalogue_reform` 또는 `p1_activate_mandate`를 호출한다.
- 별도의 정치 법률·인구·권위 원장 없이 기존 content의 원자적 `native_.advance_day(plan)` 트랜잭션을 이용한다.
- **미완성**: 1.15 역사별 일지 데이터 전수 이식, 정치적 국가 형성·외교조약의 복합 효과, UI 콘텐츠 선택지 전수.

## 검증 상태

변경 C++ 파일의 괄호/주석/문자열 균형과 기존 선언·호출 위치를 정적으로 확인했다. JSON 외부 정치 효과의 정상/불완전 스키마 회귀 테스트 코드를 추가했다. 전체 C++ 컴파일, CTest, 장기 정치 자율 순환, C/E/H 전쟁·평화 통합 회귀는 실행하지 않았다. 따라서 3개 영역의 **기본 실행 경로 확장**이지 완전 인수 판정이 아니다.
