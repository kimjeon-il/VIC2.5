# C-D4-4 — 교차 시나리오·기대값·검증 오라클

**상태:** 테스트 시나리오/오라클 설계 확정 · `phase-c-integration/1.0` · [색인](README.md)

## 1. 오라클의 계층

- **정확한 정수 오라클:** 인구·전사/동원·표/의석·상품 수량·현금/예금·채무·소유지분·유효법률/월·ID·보관자·생존자. 모든 값 완전일치(정수/고정소수점, 명시된 반올림).
- **관계/인과 오라클:** 실제 돈 지급/자금예약, 상품 인도, 법률 적용월, 정부/군사 권한, 구성원/부대의 실제 참조. 충격이 반드시 특정 정치적 결과를 낳아야 한다는 오라클은 불허.
- **통계 대조 오라클:** GDP 생산/지출/소득 및 실제 장부 분류가 명확한 fixture에서는 정확히 재현, 역사 입력의 추정·기간/재고평가 불명인 경우 진단 오차와 원인기록(강제 숫자 보정 금지).
- **비교/메타모픽 오라클:** 초기 상태/seed·명령·event order를 동일하게 했을 때 동일 결과; 독립 지역의 처리순서/worker 수만 바꿨을 때 동일 최종 정본.
- **위기 동학 오라클:** 흉작, 파산, 실업, 시위, 동원, 패전, 물가 급등의 발생 자체는 실패가 아님. 해당 결과를 발생시킨 실제 인구·상품·금융·법/군사 사건과 지표가 일치해야 한다.

## 2. 복합 fixture A: 선거·임금·법률·예비군 동원·전투

기계 판독 예: [cross_domain_reform_mobilization.json](examples/cross_domain_reform_mobilization.json).

**개시 월:** `m=240`, 가상 한 지역/한 통화 국가. 실제 POP 총인구=1,000명, 민간 상태800/예비군100/현역100. 유효 현역100은 **당월 선거권이 없는 법적 집단**으로 가정하며 이후 전사10은 유효 유권자 집계에서 제외(새 유권자 증가와 섞이지 않도록 설계). 다른 출생·자연사·이주는 0, 한달 내 나이 상한 통과자 0.

**경제:** 민간·예비군 중 300명 주된 계약(이 중 **40명은 m월에 동원될 예비군**). 기업 예금500/가계예금0/정부예금0, 모든 예금에 기존 은행 부채/자산의 대응 초기화. 단계2에서는 300명이 적법하게 근무한다. 단계5 기업 총 임금 지급300=가계 순수령270+세금 원천징수30. 기업200/가계270/국고30; 단순 내부 고객예금 이체만 있었으므로 합계500 보존. 이 fixture의 군인급료/군수구매는 **해당 월 별도 지급기한이 없는 계약**으로 가정하며 추가 금융 거래 없음.

**정치:** 단계9c 유효 선거권자600, 등록550, 실제 투표420(유효400·무효20), A220·B130·C50표, 3석 D'Hondt = A2·B1·C0. stage9d에서 적법한 입법 절차/공포를 통해 다음 달부터 연령 제한을 낮춰 m+1의 선거권자 **50명 추가**. 새 50명은 m월 전사자 및 기존의 미성년 만기/전직자와 **별개의 살아 있는 집단**으로 규정; m월 선거에 50표가 자동 추가되지 않는다.

**군사:** 단계1에서 기존 법에 따른 예비군 40명 동원명령은 유효하고 자금/훈련/수용 능력이 확인되어 있음. 단계10의 **기존 월초 현역100명만** 교전. 전사10·일시부상20·무손상70, 포로/실종0; 생존 현역90. 그 뒤 예비군40명(기존 민간 취업자)을 새 현역으로 전이하되 **m월 전투에 참여하지 않음**. m월말 최종: 주민990, 현역130(기존 생존90+신규40), 예비군60, 민간800. 근로계약 40개는 다음 달 효력으로 종료(인원 40), 따라서 다른 신규 구인/복직 없다는 추가 가정 아래 m+1 단계2 기존 인력 배정은 260명. m+1 선거권자 = `600+50=650`(전사10명이 원래 법적 유권자가 아니었으므로 다른 조건 불변).

**핵심 시간 검증:** m월 급여300/투표420는 후속 10단계 전사/동원으로 소급 취소되지 않는다. 새 법은 m월의 선거 결과를 다시 배정하지 않는다. 실제 `PopulationSlice`, `EmploymentLedger`, `FinancialLedger`, `Political/ElectoralLedger`, `ServiceAssignment`·`HealthProfile` 변경을 **같은 월간 StagingWorld**에서 교차 검증 후 커밋한다.

## 3. 복합 fixture B: 군수조달·2개월 운송·교전·점령/주권

기계 판독 예: [logistics_war_occupation.json](examples/logistics_war_occupation.json).

**개시:** A국 현역100명(거주 A, 부대는 B 영토 근처), B국 X지역 주민500명(그중 B국 현역20·민간인480), 전 세계 주민600명. B국 지역 X의 `sovereignty=B`, `civil_administration=B`, `fiscal_authority=B`, `military_control=B`. 장기 운송 경로 A→X가 가상으로 존재하고 2개월이 필요하다. 통화 하나, 국고 현금200, 군수업자/수송업자 각 0, 대응 은행/금융원장 초기화.

**월 m:** 군정부가 의약품60상자(단가2, 지급120), 운송비10을 적법 예산으로 실제 지급. 국고200→70, 군수업자0→120, 수송업자0→10. 실물은 생산업자 재고60→in_transit60, 현장 재고0. `m+1` 현장 이용가능 약품0.

**월 m+2:** 운송 중5상자 손실, 지역 X 현장 의약품55상자 입고/보유자/소유권 권리 정합. 단계10 기존 A국 현역100명과 B국 현역20명 사이의 가상 교전에서 A국 전사3·일시부상7·무손상90, B국 전사·부상0·무손상20(기존 탄약5발 사용 후 인접 B국 통제지역으로 실제 후퇴); 의무시설은 실제 의약품7상자·의료인/시설 슬롯7 이상이 있고 치료 7건을 시행하되 **치료가 즉시 부상을 완치하지 않는** 규약. 사용 후 현장 의약품48상자, 손실5·사용7이 기록됨. 전투 결과 지역 X `military_control=A`가 효력 있는 별도 사건으로 확정되어도 **sovereignty/civil_administration/fiscal_authority=B**는 계속 유지. B 주민500명은 여전히 B거주·B국적, A의 군사인구 생존97명이므로 월말 세계 주민597명.

**원장 오라클:** 고객예금합200 보존(신규 대출/화폐거래 없다고 가정), 화물 `60=운송손실5+치료소모7+재고48`, 인구 `600-3=597`, 군사통제A/주권B, 이미 종료된 구매/운송비 지급에 소급 수정 없음. 전투 부상자7명은 군 현역상태 유지(건강 프로필만 급성부상), 생존 현역97명.

## 5. 미구현 영역을 꾸며내지 않기 위한 규칙

- 합성 fixture를 실제 역사/전쟁 통계로 주장하지 않는다. `fictional_test_value=true`, `fixture_schema_version`, `source_provenance`와 근거를 저장.
- 정치 설계 `phase-c-politics/1.0`의 실제 구현이 없는 동안 선거/정치 기대값은 **수학적 fixture와 설계 오라클**만 검산 가능하다. 통합 C++ PASS라고 주장 불가.
- 전투·주가/가격 변화 확률계수, 선거행동/시위/지휘·항복의 모수는 별도 ruleset/역사보정이 필요. 이를 임의로 채우지 않은 상태에서는 누적 위험/정합성 테스트만 통과 가능.
- 실제 정치적 태도·특정 현실 정당 지지 예측이나 전쟁의 현실 피해 예측은 이번 fixture의 목적이 아니다.
