# C-D4-5 — 교차 분야 통합 테스트 매트릭스 (48개)

**상태:** 구현 인수시험 설계 확정 / 실제 테스트 미실행 · `phase-c-integration/1.0` · [색인](README.md)

## 1. 실행/증빙 규칙

- 모든 테스트는 `fixture_id`, 시작 `WorldSnapshot` 해시, seed, ruleset/numeric policy, schema/contract versions, ordered command IDs, 단계 0~11 이벤트 로그, 예상/실측 `WorldFingerprint`, 교차 원장 불변식 검사 결과를 출력한다.
- 단독 원장 검사 통과만으로 C-D4 성공이라고 하지 않는다. stage11 한 번의 통합 Commit/Abort와 **영역 간 자산·인구/선거·병역 동기화**를 반드시 시험한다.
- `positive`: 적법한 사건에 실제 기대 상태·전월/차월 효과가 일치. `negative`: 실패가 예상되는 위법/미확보/중복 거래는 **거부/명시적 축소**, 원월 상태가 변하지 않아야 한다.
- 각 테스트에는 이전 POP-D0~D3, [C-D0 수락 기준](../C-D0_COMMON_CONTRACT.md), [CE 검증](../economy/ECONOMIC_ACCEPTANCE_TESTS.md), P 계약(P 정본 등록 후), [CM 검증](../military/MILITARY_ACCEPTANCE_TESTS.md)과 상호 참조 매핑을 유지한다.
- 테스트 01~48은 아래 6개 그룹의 **고정 집합**이다. 그룹 내 순서와 병렬화는 독립 검증 및 정확한 seed/규칙 아래 변경 가능하나 fixture 결과가 바뀌어서는 안 된다.
