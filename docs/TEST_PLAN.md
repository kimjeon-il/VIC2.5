# 검증 규약 및 테스트 상태

## 지금 실행 가능한 테스트

`ctest --test-dir build --output-on-failure`: 현재 단일 테스트 바이너리에서 다음을 검증한다.

- POP 전투 손실: 1,000명 가운데 전사 50·일시 부상 180·장기 손상 70 → 전체 950명.
- 과도한 전투 손실/인구 이동 거부, POP 사이의 실제 인구 이전.
- 경제주체별 차변·대변 합계 0, 대출에 따른 예금 생성, 불균형 분개 및 중복 거래 ID 거부.
- 기초 재고·생산·소비·이전량 보존, 재고 초과 이전 거부.
- 기업 지분 보존, 고용의 인구 상한 조회.
- 월별 계산 12개 단계 순서와 월 증가.

## 구현 완료 후 추가할 필수 불변조건

| 분야 | 항등식/검증 |
|---|---|
| 인구 | 기말 = 기초 + 출생 − 사망 + 유입 − 유출 |
| 연령·성별·건강 | 모든 하위 코호트 합과 POP 총인구 일치 |
| 복무 | 군인 인구와 민간 고용의 중복 집계 금지 |
| 고용 | 총 취업·실업·생계생산 = 경제활동인구 |
| 급여 | 기업 임금지급 = POP 수령액 + 원천징수 및 법정 공제 |
| 실물 | 기말 = 기초 + 생산 + 유입 − 투입 − 최종소비 − 유출 − 폐기 |
| 금융 | 경제주체별 분개 균형 및 기관 대차대조표 일치 |
| 은행 | 고객 예금청구권과 은행 예금부채 대응 |
| 소유 | 발행지분 = 소유자 지분 합 |
| 배당 | 지급된 배당의 합 = 수령한 배당의 합 + 관련 원천징수 |
| 무역 | 실물 출하·운송 중·입고량 일치 |
| 재현성 | 초기값·시드·규칙 버전 같으면 결과 바이트 동일 |

## 장기 시나리오 (아직 실행되지 않음)

1. 기본 100년(인구·자산·산출·고용·실업·소비·가격·은행 건전성).
2. 인구 급증(농업·고용·주거 병목과 계층별 생활수준).
3. 흉작/식량 부족(가격, 재고, 영양·사망률, 재정·이주 반응).
4. 은행 위기(대출 회수·신용 위축·실물 생산 반응).
5. 전투 인구 충격(부상·장애·사망·제대에 따른 장기 노동력과 복지 재정).

경기침체나 실업 자체는 테스트 실패 조건이 아니다. 이유 없는 돈·재고 생성, 비정상 순환, 원장 불일치, 비결정적 결과를 실패로 본다.
