# 가계 소유 사업의 자동 배당

*참조: 로컬 Victoria 3 1.13.11과 [Paradox의 건물 소유권 개발일지](https://forum.paradoxplaza.com/forum/developer-diary/victoria-3-dev-diary-110-building-ownership-foreign-investment.1647879/).* 빅토3에서는 노동자 소유 시설의 배당이 소유 노동자에게 돌아간다. VIC2.5의 첫 연결 범위는 **등록된 살아 있는 가계 한 곳이 단독 소유한 민간 사업**이다. 소유 구조를 추측하거나 금융구역·장원·혼합소유를 대신 구현하지 않는다.

- 테스트 또는 시나리오가 네이티브 정책의 회사별 운영자금을 명시하면, 매월 1일 의무 급여 정산 후 실제 소유 가계에 배당할 수 있다. 플레이어가 건물마다 버튼을 누를 필요는 없다. 이 정책은 아직 역사 시작 파일이나 기본 플레이 화면에 노출하지 않는다.
- **실제 상품 판매대금**에서 장부의 비용과 이미 지급한 지분 배당을 빼고, 실제로 남은 가용 현금이 운영자금 한도를 넘은 만큼까지만 지급한다. 기초 자금, 대출, 보조성 일반 지급, 채무 면제 이익을 판매로 세지 않는다. 이 수치는 재고 평가를 포함한 발생주의 이익과 같지 않다. 이전 저장에 이미 합쳐져 있는 매출은 되살려 소급 배당하지 않는다.
- 유효한 가계 소유권이 없거나, 회사가 파산·체불·채무 상태이거나, 미지급 배당 약정이 있으면 건너뛴다. 기존 예금·은행·주식·정부 배당 방식과 직업을 늘리지 않는다.
- 지급액은 실제 회계의 기존 회사 현금에서 가계 현금으로 옮겨 간다. 같은 판매대금은 재배당하지 않는다. 새 수익이 있어야 다음 달 지급액이 다시 생긴다.

검증 시험은 가계가 배당으로 추가 식품을 구매하는 경우를 기능 비활성·소유권 없음·판매 없이 현금만 받음·대출 보유·채무 면제·운영자금 부족과 비교한다. 월 경계 저장·재개, 두 번의 지급 뒤 추가 판매 없이 재지급하지 않는 경우, 참여자 현금 합계도 확인한다. 장기 시장 안정성이나 모든 빅토3 소유 유형이 구현됐다는 뜻은 아니다.
