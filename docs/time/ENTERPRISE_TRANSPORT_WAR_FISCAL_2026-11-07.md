# VIC2.5 기업청산·전 세계 교통망·다전선 AI·국가예산/국채시장 추가 구현

**중요:** 요청대로 빌드, CTest, CI, 실행 회귀 및 성능 측정을 모두 수행하지 않았다. **실행 정상/호환성 PASS 주장 불가.** 다음 내용은 실제 소스에 커밋한 기능 경로의 범위이며 정식 기능 인수와 동일하지 않다.

## A. 기업의 파산 이후 청산

변경: `phase_c.hpp`, `phase_c_snapshot.hpp`, `phase_d.hpp`, `p0_daily.hpp`.

1. 기존 급여채권·기업 부채/지갑·사업장·재고·자산을 파산 후에도 남긴다. 청산 개시가 물자·계약상 채무를 임의로 지우지 않는다.
2. 정상 매수인의 실제 C 현금으로 파산기업의 지역/품목 **실재고**를 현행 거래가격에 매수하도록 하며, 자금/재고 예약 조건을 사용한다. 명시된 입찰뿐 아니라 재고목표가 부족한 실제 생산기업의 제한된 자율 매수도 가능하다.
3. **완공된 제조 사업장**은 매수인이 실제 제안한 금액만큼 지급하고 매매한다. Phase D의 준공 프로젝트 소유자까지 동일한 하루 트랜잭션에서 변경한다. 현장에 다른 채굴권·미완료 연구 등이 있으면 단순 소유권 이전을 거부한다. 자산에 근거 없는 새 평가액을 붙이지 않는다.
4. 임금체불 청구는 실제 현금으로 우선 상환한다. 그 후 남은 은행대출을 상환할 때는 G 담보신용 잔액부터 실제 원장에 맞춰 정리하며, 미지급 은행대출을 자동으로 면제하지 않는다.
5. **청산 완료**는 현금·재고·사업장·유가증권·건설 WIP와 남은 임금·대출·이자·배당 등 잔존 청구가 없을 때만 기록한다. 완결 사실은 선택적 `VIC25_PHASEC_ESTATE_CLOSURES_1` 저장 확장에 보존한다.

잔여: 실제 국가별 파산법 우선변제순위, 세금채권·담보권 세부 구조, 사법적 채무면제/법원절차, 평가/경매의 광범위한 자동 시장 등은 독립 모델 필요. 현재 청산은 게임 공통 규칙에 따른 **실물·금융 정산**이다.

## B. 세계 교통망 실측 자료 연동

변경: `scripts/build_verified_transport_links.py`, `verified_transport_seed.hpp`, `phase_e.hpp`, `phase_gh.hpp`, `phase_gh_snapshot.hpp`.

- 외부 도로·철도·해로·하천·항공 선형 GeoJSON/GeoJSONSeq와 실제 Phase E Province 폴리곤을 공간 결합해 원본 피처 ID가 연결된 물리 링크를 생성한다.
- 실제 **운송사·용량·운임·일수·유효 시작/종료월**은 별도의 입증된 서비스 CSV에서만 읽으며, 원본 지리선만 보고 운송량/운임을 만들지 않는다.
- C++ 초기화기는 `geographic_links.tsv`, `transport_services.tsv`를 받아 실제 E 링크와 G 교통간선을 생성한다. 초기화 날짜에 존재하지 않은 노선은 적재하지 않는다.
- 노선은 출처 식별자·원본 SHA-256·유효 시작/끝 월을 포함한다. G 경로선택은 해당 월에 유효한 실제 검증 간선만 고려한다.
- GH 스냅샷 **v0.8**에 출처 및 역사적 유효기간을 저장한다. 이전 v0.2~v0.7 판독 경로를 유지한다.
- 기존 F/G 구간별 운송·실물 환적/보험/용량 공유 실행과 연동 가능하다.

**미달:** 세계 전체 실제 소스 파일과 역사적 노선별 처리용량/요금을 저장소에 **아직 다운받아 적재하지 않았다**. OSM 데이터 자체는 현재 관측 지도이고, 과거 서비스 정보와 다르다. 이는 세계 전역을 수용하는 출처검증형 이관 파이프라인이지 **세계 전체 구축 완료**가 아니다.

- 기존 전쟁 상태별 휴전·조약 비준·영구 종전 로직과 연동한다.

잔여: 다군단 협동작전·다국적 참전/동맹·적군 정보·유류·식량 군수·해/공전·포위/해상 상륙/지휘자 특성·별도 강화협상 AI·동맹국 통과권 등은 아직 미완성. 본 구현은 **복수 전선의 제한적 실제 군사·보급 순환**이다.

## D. 범용 국가 예산과 국채시장

변경: `phase_c.hpp`, `p0_daily.hpp`, 기존 국가/은행/국채 저장 확장.

- 실제 국고 현금·수입/지출·대출원금·실발행 국채와 쿠폰 채권을 국가별로 조회한다.
- `NationalBudgetEnvelope`으로 국가별 현금 유동성 목표·공공지출 상한·국채 발행한도·전체 발행원금 상한·쿠폰 상하한·만기를 규정한다. 여러 국가에 동일 엔진 적용.
- `BondBuyerOrder`로 실제 현금을 가진 민간 투자자의 매수 한도/최소 요구수익률·현금 유보액을 받는다. 적격기업은 자신의 **실현 가능한 유동 현금** 및 시나리오 이자율에 따라 제한적인 자율 매수도 제안한다.
- 동일 국가 내에서 투자자별 **최소 요구 쿠폰 오름차순**으로 결합하고, 실제 은행예금에서 현금을 국고로 옮긴다. 미매각 국채를 정부가 자체 발행해 돈을 만드는 경로는 없다.
- 의료시설처럼 실제 서비스 제공자와 인력·재고·법적 권리가 확인된 공공 지출은 국가별 총일일 예산상한과 국고 유보액을 넘지 않게 한다. 기존 명시적 `PublicBudgetProgram`도 같은 국가 상한을 공유한다.
- 국채 이표이자·미지급액·만기 원금 및 기존 국가별 소득세·관세/분담금은 C 금융·소유권·정부 원장에 연결한다.

잔여: **국가/투자자의 실제 역사적 재무제표·상업 금리·상환 순서**, 유가증권 시장가격/할인발행, 해외통화·외국인 자본, 정부 자체 정책 학습, 지출의 자동 수요-효율 최적화, 모든 국가의 완전 자유채권시장은 별도 구현 필요. 정책/근거가 없는 국가·투자자에게 현금이나 금리를 임의로 부여하지 않는다.
