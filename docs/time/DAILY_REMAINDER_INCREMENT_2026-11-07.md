## 이번 차수에서 직접 추가한 코드

### 1. 병참·복합 무역

- **실제 주권국 국고 계정에 저장된 실탄**만 전선 부대 보급에 사용할 수 있도록 `phase_f::plan_direct_army_supply`를 추가. 전쟁 중인 실제 국가·부대의 병력과 보유 탄약을 비교해 수요를 계산한다.
- 보급 명령은 G의 증명된 실제 유효기간·비용·일수·월간 수송용량과 현재 C 국고 현금/무역 예약을 함께 확인한다. 아직 도착하지 않은 화물도 재주문량에서 차감해 동일 화물을 중복 발주하지 않는다.
- 같은 지역 내 국고 보유 실탄은 C 재고 원장 내 주권국 → 해당 부대 실물 이동으로 지급한다. 다른 지역의 실탄은 기존 `daily::Command::cargo_dispatch`에 넣어 **실제 Stage1 예약과 향후 Stage0 도착**을 사용한다. 새로운 탄약/화폐/장비를 만들지 않는다.
- 민간 자동운송과 군수계획은 공통 `phasef::DayPlanningReservations`를 사용하고, 운송 명령이 전혀 없으면 `daily::World` 복사를 생략한다.
- G 다중구간 경로는 **오늘 출발하는 첫 구간**만 오늘 용량을 예약한다. 후속 구간은 진짜 중간 허브에 도착한 날의 남은 운송용량을 검사한다. 미래 구간이 현재 포화됐다는 이유만으로 장거리 화물을 출발하지 못하게 하던 문제를 수정한다.
- 후속 간선이 역사적으로 폐지되거나 폐쇄되었을 경우 G는 화물이 실제 보관된 허브의 C 재고를 유지한 채 **다른 검증 노선**을 찾고, 확인된 새 구간이 없으면 이동을 보류한다.

### 2. 세계 교통망 입력·역사 이력

- [Geofabrik OSM 지역 추출](https://download.geofabrik.de/)과 [OpenHistoricalMap](https://www.openhistoricalmap.org/)을 별도 원본으로 구분. 현재 OSM 지형 선형만으로 옛 영업시간·처리용량·운임을 만들어내지 않는다.
- `build_verified_transport_links.py`: 도로·철도·하천은 실제 선형이 두 지역의 **공유 지리 경계**를 통과할 때만 연속 간선을 만든다. 행정구역의 대표점만 가깝다는 이유로 고속철·고속도로를 연결하지 않는다.
- OHM의 `start_date`, `end_date`를 연·월·일 제공 정밀도에 맞춰 해석. 연도만 있는 개통일을 임의로 **1월 1일**로 바꾸지 않는다. 날짜 정밀도가 낮은 경우 **완전히 존재가 입증되는 월**만 사용하고, 명시된 운송서비스의 유효기간이 해당 기간 밖이면 거부한다.
- `merge_verified_transport_regions.py`: 대륙·국가별 실제 결과 파일을 SQLite 기반으로 하나의 세계 TSV에 합치고, 중복 링크 충돌·서비스와 지역 연결 불일치·물리 노선 존속기간 불일치를 검출한다. 원본별 SHA-256·라이선스 메타데이터를 유지한다.
- `verified_transport_seed.hpp`: 선택적 `physical_line_lifetimes.tsv`의 실제 선형 존속기간과 서비스 유효기간을 대조한다. **게임 개시 후 건설되는 미래 교통간선도 초기화 자료에 보존**해, 실제 해당 월이 되면 경로 계산에 나타나도록 한다.
- **한계**: 세계 전체 OSM/PBF와 역사 철도·항로의 실측 영업자료를 내려받아 이 저장소에 적재하지는 못했다. 입력 파이프라인은 구현했지만, 전 세계 실측 교통망 완료 상태는 아니다.

### 3. 다중 전선 전쟁 AI

- 한 전쟁의 처음 신고된 위기 Province 외에도 실제 Phase E **국가별 실존 영토 클레임**이 입증된 지역을 같은 전쟁의 추가 전선으로 포함한다. H는 이를 중복 원장에 저장하지 않고 E 클레임 및 C 법적 주권에서 계산한다.
- 각 실제 전선·각 전쟁 당사자별로 E 인접 그래프를 한 번 역방향 탐색해 가능한 한 걸음짜리 보급로/행군 경로를 도출한다. 같은 전선에 여러 부대가 있을 때 전 세계 경로를 부대마다 중복 탐색하지 않는다.
- 실제 병력·탄약·상대 전선 병력·접근 가능 거리로 지원 우선순위를 정하고, 하나의 부대를 하루에 중복 행군시키지 않는다. 보급되지 않은 부대·제3국 경로 통과는 금지.
- 군사통제는 실제 적군 병력이 더 이상 남아 있지 않은 **물리적으로 비경합 중인 지역**에서만 변경한다. 단지 적 부대에 탄약이 없다는 이유로 생존 병력을 지우고 자동 점령하지 않는다. 법적 영토 이전은 별도 협정으로만 처리한다.
- H 휴전 판단은 **해당 전쟁의 모든 실제 전선**에서 전투 가능한 부대를 조사하고, 이미 유효한 휴전이면 장기간 무교전 뒤 별도 종전 조약을 제안한다.
- **한계**: 포병 수송·수상/항공 작전·군수 소비 회계와 보급거리·동맹군·전시경제의 전면 AI는 여전히 제한적이다.

### 4. 기업 청산과 국가 예산

- **임금체불 우선순위**: 실제 고용계약의 C Stage5 임금채권 발생 후, 각 기업의 현실 지급가능 현금으로 체불임금을 먼저 상환하도록 정렬. 그다음 법적으로 장부에 기록된 기업의 배상금/배상 채무, 이후 은행대출의 실제 상환을 처리.
- 회사의 자산·부채·현금·외화잔액·건설 WIP·금융채권·의료기관 운용권 등이 남아 있으면 청산 완료 처리를 차단. 정부 국고는 민간기업 파산 30일 규칙을 적용하지 않음.
- 발행된 기업 지분 `company:<firm>`이 실제로 존재하면 **순자산 매각대금만** 비례 분배. 기존 주식은 C OwnershipLedger에서 소각하고 지분 보유자의 실현 투자손익을 복식부기로 인식한다. 주주가 확인되지 않으면 임의 분배 금지.
- 국가 예산은 별도 사전 정책이 없는 경우에도 실제 법률상 의료기관 지출·등록된 공공서비스와 실제 미지급 국채이자를 토대로 기본 현금 예산안을 파생한다. 증명된 국고 수입 이상으로 원금 발행 한도를 무한정 늘리지 않는다.
- 실제 은행금리 자료가 없으면 기업의 국채수익률을 임의로 추측하지 않는다. 검증된 매수의사·매수인 현금·이자율이 있을 때만 발행되며, 채권시장 거래를 통화 발행으로 취급하지 않는다.

## 여전히 남은 본질적 기능

1. 실제 세계 역사별 전국·대륙·해양 교통 연결의 대규모 입력/확정과 날짜별 물류망 **실측 자료 확보**.
2. 국가별 파산법·담보권 우선순위·법원과 은행금융/국제신용·부실자산 회수의 광범위한 제도·시장 모형.
3. 군단·군종·동맹·해상 전력·전시 보급의 전략/작전 전체, 다변수 전장 평가 및 휴전 조건의 복합 협상.

5. 모든 코드의 컴파일 적합성, 롤백·금융/재고/인구 보존, 세이브/로드 역호환, 대규모 CPU/RAM/재생 성능 검증. **이번 지시에서는 실행하지 않음**.
