## 코드에 추가한 기능

### POP·가계

- `phase_b::Engine::advance_day`의 교육/직업훈련 연간 기회 발생률을 해당 출생월의 실제 달력 일수에 나누어 일별로 적용. 코호트 `birth_month`와 월경계 자격분류는 유지: 원본에 없는 출생 **일자**를 생성하지 않음.
- `p0::DailyGame`에서 단순한 계약임금의 일별 정수 급여를 실존 `HH:<household-id>` 계정으로 송금. 실제 계약고용·지역 주권·기존 국고 계정/세율과 연동; 자금 예약은 Stage1, 실제 원천징수/지급은 Stage5. 시나리오가 이미 급여 지급을 명시한 고용주는 중복 적용하지 않음.
- 자금이 부족하면 실제 가용 현금까지만 지급하고, 부족 임금을 이미 지급된 것처럼 기록하지 않음. **미지급 임금의 채권·임금체불 원장 및 자동 정산은 아직 없음.** 계정이 없는 가구·정부를 만들어 내지 않음.
- `HH`가 실물 보유한 상품을 먼저 소비하고, 필요량의 나머지만 기존 C 시장/재고·현금에서 구매. 기본 수요는 식량 1단위/인/일, 의복 1단위/인/월이며 캠페인 `Policies`에서 조절 가능. 이는 게임 lot 기본값으로, 역사적 실측 수치가 아님.
- 같은 POP/상품에 명시적 Buyer가 있으면 자동 구매를 건너뛰고, 실물/구매력 때문에 충족되지 않은 **식량** 수요만 기존 정치 불만으로 전달.

### 금융·국가 AI

- 실제 C 대출원금을 기준으로 `ACT/365` 일별 단리 발생. 이자율은 실제 시나리오에서 `seed_annual_bank_interest_ppm`을 설정한 경우에만 활성(기본 0, 임의 역사금리 없음). 별도의 은행 이자미수금·채무자 미지급이자 분개를 사용하고 보유 현금으로 상환; 예금/원금·G 무역신용 사용액과 혼합하지 않음.
- 이자 정수 잔여분·정책값은 선택적 `VIC25_PHASEC_BANK_INTEREST_1` 저장 확장으로 보존. 실물은행 계정/채무자 미지급계정 없으면 진짜 이자가 발생할 때만 생성.
- 기존 국가별 세금·국고 프로젝트 위에 현실의 국고 현금보다 실제 C 은행대출이 많은 국가는, 이미 선거에서 입증된 정당이 단독 법정 의결정족수를 충족할 때 **월 첫날** 다음 달 소득세율의 제한적 인상을 제안. 국법 효력·국고·입법구조는 기존 C 정본.
- 관측된 식량 부족을 겪은 나라의 기존 식량 수입관세를 합법적 국가정부가 0으로 낮추는 기본 반응. 별도 명시적 플레이어/캠페인 정책과 충돌하는 국가/상품은 건드리지 않음.
- H의 활동 중인 국제기구 의무 분담금을 실제 회원국 국고와 실제 조직 계정이 있을 때만 자동 납부. 부족분은 다음 날 재시도하며 외교 승인·허구 결재를 생성하지 않음.

### 물류·성능

- F/G 운송경로 탐색에서 실제 일별 정보가 확보된 간선만 후보에 올리고, 비용 우선·실제 일수 차순 정렬. F의 명시적 검증 운송일수 오버라이드와 G의 간선 값이 충돌하면 거부. 과거 `transit_months`는 별도 월간 API 보존용.
- C의 기존 InventoryLedger에서 시장별 판매자 후보 색인을 **하루 한 번** 만들고, 가계별 구매는 현재 남아 있는 실재고·공유 예약량만 참조. 모든 가구마다 전 세계 재고를 처음부터 반복 검색하지 않음.
- C 일간 실행은 C/D/E/G/H의 원자적 트랜잭션과 기능별 사전조건 검사·Stage11 전원장 검증을 유지하되, C의 **매 단계 전세계 전체 검증 12회**를 최종 Stage11 한 번으로 축소. 이전 단계의 명령이 실패하면 여전히 스테이징을 폐기한다.
- 이전 단계에 도입된 `day_budget.hpp`, 네이티브 G 화물/저장·F 경로, 재생자원 일별 갱신, 국가별 세율·국고 및 중복 Actions 통합은 유지한다.
