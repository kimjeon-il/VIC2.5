## 운영 규칙

- `daily::World::advance_day()`는 하루당 하나의 C/D/E/G/H 원자적 커밋만 수행한다. 월초 법률 효력 등 날짜가 월초인 사건과 **월간 자동 시뮬레이션 재실행**은 다른 개념이다.
- POP 인원·노동·재고·계좌·부채·운송용량에는 기존 권위 원장만 사용한다. 신규 G 화물 메타는 예정 도착일, 도착지, 손실 정보만 가진다.
- 과거 세이브에 없는 실제 생년월일·운송 일수·국고 잔액을 만들어 넣지 않는다.
- 국가별 재정은 국고를 명시적으로 `seed_country_treasury(country,wallet)`로 연결하거나 실제 해당 국가의 동일 이름 금융계정이 있을 때만 지출 가능하다.
- 새로운 `TransportEdge.transit_days`는 검증된 실제 운송일수로 설정하며, 0은 **미확인**으로 남긴다.
- **현재 상태는 부분 구현 / 검증 전.** 브랜치를 main에 병합하지 않았다.

## 남은 핵심 차단

1. 자동 국고 지출, 채권/이자, 임금-가계계좌 연결, 가계 수요, 모든 기업·국가의 자율 의사결정 완성.
2. 기존 `birth_month` 코호트에 대해 역사자료가 제공하는 날짜 정밀도에 맞춰 일별 자격 효력 처리. 없는 과거 `birth_day`를 임의 생성하지 않기.
3. 실제 F/G 다중수단 전 세계 물류, 통관·외환·보험 계약, H 전쟁/평화 및 국제기구 실행의 일별 자율화.
4. 초대형 월간 → 일간 마이그레이션의 저장/재개, 모든 회계 보존·결정론, 성능/게임플레이 실측. 이번 요청에서는 **전부 검사 생략**.
