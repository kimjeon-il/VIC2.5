## 별도 수치·역사연구가 필요한 항목

- 지식 그래프·시기별 발견·지역/기관의 기존 알려진 기술/서류 접근, 연구목표별 불확실성/난도·전이확률/실험재·예산·역사적 연구기관/계약.
- 교육·문해율/숙련의 학습효율·수용역량, 기술 교류의 거리/언어·사회제도/비밀·유효 운송/통신서비스의 실제량, 현장 장비/기계 개량·공정수율·감가·안전/환경/경제·군사적 영향.
- 현대 OECD R&D/혁신 통계는 **설계의 개념 참고**, 1801년의 경제주체들이 현대 통계기준에 따라 연구비·특허/문해/산업 활동을 자동 보고했다는 주장은 하지 않는다. 실제 역사 계수 확인 전에는 `unknown/estimated`와 provenance, 검사 fixture는 `fictional_test_value`.
