## V3-7. 우선순위·오류 처리 및 예외

- `DV-INV-01..36` 전체는 **모든 테스트와 월별 stage11**에서 검산 가능한 조건을 의미하지만 특정 테스트에서 해당 객체/사건이 없는 경우는 `NOT_APPLICABLE`로 명시하고 의도적으로 주입한 음수/이중계상을 PASS 처리 금지.
- `RuleViolation`과 `LegalSimulationOutcome`를 분리. 정상 자재 부족/공사 지연·파산·연구 실패/기술도입 정체·전투 패배는 실제 사건과 원장 정합이면 정상 결과. 재고/인구 음수, 유령 예금·지식/설비, 이전 월 재생·법 효력 역행은 HARD ERROR.
- 생성되지 않은 객체/참조·불가능한 수치 스케일·오버플로/알 수 없는 규칙·정당한 권한 없는 인수/징발은 전체 월 거부, 정합성을 숨기는 자동 복구/무음 무시 금지.
- 각 불변조건은 `(id, domain, month, stage, entity_refs, expected, observed, numeric_policy, event_ids, violation_code)` 형식의 실패 진단을 낸다.
