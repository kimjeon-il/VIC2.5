> **상태: 시험 명세 확정 / 실제 C++ 72개 실행 전** · `phase-d-integration/1.0` · 2026-11-04
> 상위: [DV-V1 아키텍처](D-V1_ARCHITECTURE_SCOPE.md), [DV-V2 시간/DAG](D-V2_EXECUTION_DAG.md), [36개 불변조건](D-V3_INVARIANTS.md), [D-V4 오라클](D-V4_SCENARIOS_ORACLES.md).

## 검증 프로파일

- **SAFE-REQUIRED:** `DV-T01..72`은 기본 `I2-SAFE` 기준의 실제 실행 테스트. 미지원 동월 비저장 전력 요청은 `DV-T63`에서 정확한 Reject/Atomic Abort로 PASS해야 한다. `I2-DISPATCH` 성공 시나리오를 안전 프로파일에 강제로 포함하지 않는다.
- 성공 시 `WorldHash`, `JournalBatch`, POP/고용/재고/금융·자산/지식·정치/군사·월말 검증을 실제 실행한다. 실패 기대값은 정확한 오류코드와 모든 원장·ID/예약/달의 **완전한 롤백**을 검사.
- 각 fixture는 가상 수치 `fictional_test_value`, typed ID, 단위/통화/가격 로트, ruleset/version/seed 및 정확한 예상 이벤트·출력. 세부 C++ 테스트 구현이 없다면 `NOT_RUN`이며 번호/문서 정적 검증만으로 PASS 불가.
- DV-T01..72는 기존 `DD0-G01..24`, `DC-T01..45`, `DI-T01..45`, `DT-T01..45`, `D4-T01..48` 및 POP/CE/CP/CM 회귀를 **대체하지 않는 독립 통합시험**. DV-T72는 집계 게이트이지 미검증 항목의 blanket PASS가 아니다.
