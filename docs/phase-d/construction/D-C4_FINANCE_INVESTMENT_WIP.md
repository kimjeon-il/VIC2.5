# VIC2.5 D-C4 — 건설비·투자·지급·건설중자산(WIP)·부도

> **설계 확정 / C++ 구현·시험 미실행** · `phase-d-construction/1.0` · 2026-11-04  
> 상위: [D-D0](../D-D0_COMMON_CONTRACT.md), C-E1(기업·생산/설비), C-E2(시장), C-E3(금융·투자), C-E4(재정), C-E5(무역), C-P(법/예산). [색인](README.md)

## C4-1. 네 가지 서로 다른 금액

1. `EstimatedProjectCost`는 향후 예상 원가/공사비, 조달/부족·가격변동·차입비용·우발손실 등을 포함하는 **계획값**이다.
2. `CommittedContractValue`는 유효 계약상 앞으로 발생할 수 있는 지급의무/한도이다. 아직 지급/수입이 발생하지 않았고 실제 현금 잔액이 아니다.
3. `CertifiedWorkValue`/`AccruedPayable`는 실적·약정상 의무가 **검수/귀속**된 발생주의 금액이다. 지급과 다르며 수급자/발주자의 채권·채무를 FinancialLedger에 기록해야 한다.
4. `PaidCash`는 실제 FinancialLedger를 통해 결제된 금액이고, WIP(`ConstructionInProgress`)는 사업 소유자의 정당하게 자본화한 **비현금 건설중 자산 장부가액**이다.

**중요:** `work_done`/`WIP`/`contract_value`/`cash_balance`/`construction_goods_stock`은 서로 다른 개념이며 합계로 새로운 국부·화폐/공정 실적을 생성하지 않는다.

## C4-2. 주체별 투자재원

| 주체/방식 | 출처·확정 조건 |
|---|---|
| 기업 잉여/유보금 | 실제 기업 예금/현금 및 유효 출금권, 다른 예약과 중복 불가 |
| 민간 투자/증자 | 주주·투자자의 실제 납입(OwnershipLedger 지분 발행/대가) |
| 은행/상인 등 차입 | C-E3 `LoanContract`/`LoanDrawdown` 실실행; 승인한도만으로 현금 증가 금지 |
| 국채/예산/공공투자 | C-E4 `BudgetAuthority`/`SpendingPlan`/발행 인수대금/공공부문 분개; 예상세수는 현금 아님 |
| 협동조합·가계·자영/현물 | 가계/기업의 실제 계좌, 실물/노동·자가건설 `OwnAccountActivity` |
| 국외 투자/외상·무역신용 | 권한/외환·관세/수송, 실제 금융채권/채무·자산권, 무단 1:1 환전 금지 |
| 보험·이행보증·담보권 | 유효 계약과 보험금/보증 청구의 발생·지급을 별도 사건으로 분리 |

- 국가 건설 대기열과 민간 건설 대기열에 법률 고정 비율의 '건설력'을 나누지 않는다. 기관/기업별 실제 예산, 법적 발주 권한, 투자 수익률·경합 자원에 따른 독립 프로젝트 제안/수락과 현장별 계약을 사용.
- 투자자 의향, 정부 예산 승인, 국채 발행 계획, 미인출 신용한도는 **당월 구매 가능한 지급재원으로 더하지 않는다**. 신규 발행 주식의 평가액도 실제 납입 없이 건설비 재원 아님.
- 공공필수 기반시설은 기대손실이라도 유효 공익/규제/예산 근거가 있으면 합법적 발주 가능. 민간투자는 예측 수요·가격·순현금흐름·금융조건에 따라 결정하며 **이익이 난다고 무조건 전국 공장이 자동 증설되는 규칙 금지**.

## C4-3. 재정·현금·예약 규칙

- 기존 C-E3 `FundingReservation`이 금액/통화/계좌/유효기간의 단일 정본이다. `ConstructionFundingPlan`은 계약과 예약을 연결하는 **참조/예상 현금흐름 계획**이며 재원을 다시 저장하지 않는다.
- stage1: 공사비를 원가종류·계약별로 분해해 시공사 운전자금(임금/재료/장비)과 발주자/투자자 지급여력을 평가한다. 실제 자금·여신 실행 후 서로 독립적인 예약 확정.
- stage2: 확정된 인건비 지급재원 내에서만 유효 고용. stage3: 실제 현장재료/서비스 인도와 대금 또는 정당한 지급채무 발생. stage4: 실제 작업·시공서비스/진행. stage5: 실제 임금/원천징수. stage7: 다음 공정을 위한 투자재·설치자산 조달(이미 지난 stage4로 소급 금지). stage8: 검수와 계약 조건에 따른 비용/매출·세금·WIP/미지급·이자/부도 결산.
- stage8 실제 공사실적에 따라 새로 생긴 미수금/현금을 이달 stage1 지급예약으로 소급 사용할 수 없다. 실현된 stage8 수입은 다음 달의 계획/확정 재원 입력으로 사용 가능.
- stage9a의 신규 투자계획/증자·계약금 계획은 다음 달 stage1의 권한·실제 자금 검증부터 효력. 단순 `ProjectApproval`와 `ProjectStart`는 별개이다.
- 동일 계좌/현장 자재를 두 발주자·두 공사·군수 생산이 경합할 때 C-D4 순서/예약 테이블로 충돌 해결. 증명 불가능한 자금/상품은 무조건 누락이 아니라 미확보로 기록.

## C4-4. 계약별 발생주의/현금주의

| 계약형 | 기성고/원가 위험 | 필요한 원장 사건 |
|---|---|---|
| `fixed_price` | 기한·검수된 계약총액/변경명령에 따른 매출, 초과원가는 원칙적으로 시공자 부담 | 시공원가 + 검수된 계약상 청구권·지급과 별도 |
| `unit_price` | 실제 검수된 공정 로트 × 유효 계약단가(통화/정수 반올림) | 단가 버전·검수 근거, 계약상 채권/채무 |
| `cost_plus` | 검증된 적격 실제원가 + 합법적 수수료, 한도/예외 규칙 | 실원가 입증 없이 '추정원가'로 현금 청구 금지 |
| `time_and_material` | 검증된 노동서비스/장비시간/재료와 계약 수수료 | 중복 청구 및 일하지 않은 인원/임금의 원장 교차 검사 |
| `own_account` | 가계/기업이 직접 자재·노무 투입, 타 시공사 매출 없음 | 자기 생산의 적법 장부 비용/현물과 WIP·시설권리 연결 |
| `labor_obligation` | 법적 권한 아래 실제 노동서비스/현물, 금전 임금 필수 가정 안 함 | POP/노동적격·부역과 실물·인적 비용/기타 배분 근거 |

- `ProgressCertificate`(검수실적), `PaymentClaim`(계약 청구), `PaymentSettlement`(실지급), `RetentionPayable`(유보금) 분리. 청구 ≠ 시공 ≠ 현금결제. 하도급의 매출은 원도급의 중간서비스 구매와 맞춰 전체 공사의 최종 산출이 이중 집계되지 않도록 한다.
- `risk_allocation/title_transfers`에 따라 건설중 결과의 소유/통제 귀속을 정한다. 발주자가 작업성과를 단계별 인수하면 발주자 WIP에 자본화 가능; 개발업자가 판매용 건물을 보유하는 경우에는 개발업자의 적법한 재고/개발자산 계정에 관리하다 실제 소유권 이전 사건에 따라 판매/자산 이전.
- 자기소유 현물투입(예: 농가 목재·노동)의 현금 거래가 없어도 실물/노동 사용은 원장에 기록되며 WIP의 원가 평가는 출처 있는 유효 규칙으로 설정. **현물가치를 새로운 화폐예금으로 증액 금지**.

## C4-5. WIP·고정자산·국민계정

- WIP는 `FinancialLedger`의 실제 회계 자산/장부 계정(법적 통제주체의 권리·경제적 소유근거를 `OwnershipLedger`로 검증). `ConstructionProjectRegistry`는 `WIP_account_ref`와 검수·원가/인도 사건을 참조하는 뷰만 가진다.
- `WIP_close = WIP_open + capitalizable_cost_or_accepted_transfer − commissioned_transfer − write_off − valid_disposal_adjustments`. 같은 프로젝트/공정에 동일 비용을 두 번 자본화 금지.
- 공사장 투입 원료/판매용 재고(실제 InventoryLedger), WIP 장부값(FinancialLedger), 준공 후 물리 설비/자본자산(C-E1 CapitalAsset), 자산 소유권(OwnershipLedger)을 구분한다.
- **건설 서비스/공사의 실물생산**은 stage4의 적법 실적과 기업 생산/부가가치 회계에 들어가고, **최종 투자/건설중 자산 형성**은 정당한 인수/경제적 소유 귀속 시점에 기록한다. 고정자본형성/재고변동 구분은 실제 자산 소유·계약/국민계정 규칙에 따름. 완공 시 이미 기록한 공사 가치를 GDP에 **다시 가산하지 않는다**.
- 건설업자가 직접 구매한 철강/목재를 중간소비로 사용했다면 공사산출/투자의 최종액에 그 중간재를 별도의 최종투자로 다시 더하지 않는다. 다수 하도급의 중간서비스도 중복 최종산출 금지.
- 손상/멸실·재시공은 손실/자산감액/보험채권이 어디서 발생했는지 별도 추적. 공사비가 늘었다고 실물 시설 가동능력 자동 증가 금지.
- 감가상각과 경제적 손실의 구분: WIP 정상 대기 중인 비가동 시설에 **이미 설치되어 가동 중인 설비와 동일 감가상각률을 자동 적용하지 않는다**. 다만 실제 보관열화·사고·자산손상은 반영; 자본화 가능한 차입원가는 시대·회계 정책에 명시된 경우에만 허용.

### C4-5a. 수치 검산 예시 — 원청 한 달, 가상 통화

계약 시공업자 B가 발주자 A의 공장 건설에 철강/목재 등 실제 재료 원가 60, 노동 원가 40을 소비하고 stage4에 공정 1단위를 실현·검수했으며 계약상 기성고 가액은 120이라고 가정(세금/운송·기타 고정비/부가작업 없음; **fictional_test_value**).

1. B의 원가: 중간재 소비 60(실물 재고 감소와 비용/매입 대응), 임금 40(금융 대차 + 실제 POP 소득).
2. B의 검수된 시공매출 120 → B `contract_receivable +120`과 A의 공사대금채무 `payable +120`; B의 매출원가 100, 계약상 영업차익 20(기타비용 제외).
3. 계약상 소유권/통제가 A에 귀속되므로 A `WIP_asset +120`, 대응 `accounts_payable +120`. WIP 생성만으로 예금 +120 없음.
4. A가 이후 실제 120을 지급하면 A의 예금 -120, B의 예금 +120, 대응 매출채권/매입채무 -120 (은행간 결제 등 C-E3 규칙).
5. B의 해당 월 **부가가치 60 = 시공 산출 120 − 중간재 60**; 이 단순 fixture에서는 임금 40+영업차익 20. 건설 최종 자산형성 120은 별개 국민계정 항목이며, 60+120을 단순 합쳐 공사의 GDP로 계산하지 않는다.
6. A가 차월 준공/가동할 때 `WIP -120, installed_capital_asset +1 (책임 있는 book_value=120)`로 재분류. **준공 자체로 새로운 매출 120이나 현금 120을 추가 생성하지 않음**.

실제 구현에서 은행예금의 상대부채, 기업의 회계 차변/대변, 계약 미수/미지급, 화폐별 분개 등을 정합한 `JournalBatch` 단위로 기록해야 한다. 위 수치는 역사 실측·Victoria 3 게임 파라미터가 아니다.

## C4-6. 비용·변경·부실·파산

- 자재가격 상승·수입관세/환율·임금 상승·공사기간 지연/이자·하자/재시공·사고는 실제 원가/계약기한·현금흐름을 변경. `BudgetOverrun`은 (검증된 예상 총투자비 − 유효 프로젝트 예산)의 조회값이지 바로 음수 현금분개 아님.
- `ChangeOrder`가 없으면 고정가 계약의 초과원가를 공공 국고/발주자에게 자동 이전하지 않음. 추가 청구·계약 위반·연체금도 실제 권리/계약·재판/행정권한에 따름.
- 시공기업 부도: 유효 `Default/ResolutionEvent`로 기성채권·임금체불·하도급 미지급·보증/담보·현장재고·장비·WIP, 발주자 계약승계와 새 시공자 선임 사건을 처리. 이미 진행된 공정이 무료로 사라지거나 완료되지 않음.
- 발주자 파산/국가 재정난: 실제 공사대금 지급불능·중단/재협상·자산/채권자 귀속은 법적 우선순위와 Financial/Ownership을 통해 처리. 승인된 예산이 무한 지급재원 아님.
- 공사가 취소되면 기지급 비용은 자동 환불되지 않으며 실제 잔여자재·선급금/수령액·보험/보증 청구·자산 손실·청산 WIP를 검산. 국유화·외국 투자 분쟁/점령도 원장상 권리 승계 사건이 요구됨.

## C4-7. 수락 게이트

- 같은 예금 100으로 건설자재 100과 임금 100 중복 예약 불가; 미실행 대출/미판매 국채/예상세수만으로 지출 불가.
- 60 자재+40 노동/120 기성고 fixture의 WIP·매출/비용·채권/채무·GDP 회계 중복 없음.
- fixed-price·unit-price·cost-plus·현물 자가건설에서 과거 원가·청구권·실지급이 정합, 통화 ID 없이 덧셈 불가.
- 공공시설 건설비는 유효 예산·발주권·실제 지출근거로만 지급; 국가가 수익증가를 명령해도 현금 새로 만들지 않음.
- 계약자/발주자 파산·공사취소·보험 청구 후 이전 상태/자산/금융/자재·계약 잔액이 유효; 부분 실패 시 전체 월 롤백.

**상세 시험:** `DC-T28..T36`.
