## 기본 건설과 선택 시나리오

- **기본 건설:** 민간 산업은 예상 수익·실수요·자금에 따라 투자와 입지를 판단한다. 플레이어는 세금·법률·공공 인프라로 여건을 바꾸며 민간 건물의 부지를 일일이 정하지 않는다. 공공사업은 우선순위와 지출 한도를 정하면 집행은 자동화하고 직접 지정은 예외로 두는 것이 목표다. 시나리오에 이미 있는 개별 공공 발주와 의회 절차는 일반 민간 투자와 분리한다.
- **공통 처리:** 일반 발주·자동 증축은 실제 자재·노동·재원, 진행률과 중단 사유, 지급·건설 중 자산(WIP), 준공을 한 흐름으로 처리한다. 허가 신청·검수·재시공은 기본 단계나 필수 버튼이 아니다. 유효한 소유권·발주권과 실제 자원 한도는 그대로다.
- **선택 시나리오:** 시나리오가 명시한 프로젝트만 허가·검수, 선행 WorkPackage·양생, 불량·재작업, 외상 준공 등으로 세분화할 수 있다. 선택된 조건은 임의 우회하지 않되, 일반 자동 증축이나 기본 화면의 필수 조건으로 확대하지 않는다. 패키지 공사는 시나리오가 전용 작업을 명시해야 하며 일반 자동 투자에 등록해도 패키지 작업으로 자동 전환되지 않는다. 이하의 상세 모델·시험에서 해당 조건을 다루는 것은 기본 적용을 뜻하지 않는다.
- **준공 시점:** 일간 본편은 실제 작업·지급·WIP를 검증한 뒤 다음 날 시작 시 가동한다. 별도 월간 설계·인수 예시는 다음 달 시작을 기준으로 보존한다. 둘 다 작업한 날 또는 기간에 소급 가동하지 않는다.

## 설계 결정 개요

1. 건설은 **시공 생산서비스/실제 노동·자재·장비**를 요구한다. 건설사·자영업/부역·직영은 기존 C-E1 원장 주체이며, 무상 국가건설력·국가고정 건설순위/무료 건설 포인트 금지.
2. `ConstructionProjectRegistry`는 공사/검수의 원본만 소유. 인구 `PopulationSlice`, 고용 `EmploymentLedger`, 현금/채권·WIP `FinancialLedger`, 상품 `InventoryLedger`, 장비/설비 `CapitalAsset`, 권리 `OwnershipLedger`, 법/관할 C-P를 다시 만들지 않는다.
3. 기본 공사는 프로젝트 단위로 진행하고, 선택 시나리오의 `WorkPackage`는 물리 단위의 실제 작업/DAG/최소 기간·품질을 가진다. 공사 지연·실패·비용초과가 실제 모형 결과가 될 수 있다.
4. 계약 승인·예상 자금·건설 중 자산의 회계가치·실제 지급·준공 후 시설 능력을 분리한다. WIP 자본화와 원재료/하도급 매출을 최종투자/GDP에 이중 반영하지 않는다.
5. 실제 시공일의 최종 검증에서 `ready_for_commission`이 된 시설은 **다음 날 시작에 가동**한다. 월간 인수 예시는 다음 달 시작을 사용한다. stage10 재난/전쟁 손상은 그 효력에 반영한다.
6. 기존 stage0~11, 정치 9a~9e, 인구/전투 10a~10f, 전체 World 1회 atomic commit/rollback을 유지한다.

## 외부 게임 참고의 한계

Victoria 3의 국가 건설대기열/건설 부문·재료/고용·생산방식 및 민간투자 개념을 **문제 설정 참고**에만 사용한다.
- [Paradox Victoria 3 Dev Diary #36 — Construction](https://store.steampowered.com/news/posts/?enddate=1646328679&feed=steam_community_announcements)
- [Paradox Victoria 3 Dev Diary #71 — Autonomous Investment](https://www.paradoxinteractive.com/games/victoria-3/news/dev-diary-71-autonomous-investment-in-1-2)
- [Victoria 3 Wiki — Buildings](https://vic3.paradoxwikis.com/Buildings) / [Production methods](https://vic3.paradoxwikis.com/Production_methods) (접근제한/버전별 내용변경 가능)

VIC2.5는 실제 기업·노동·소유/채무·재고/운송·기성고/WIP를 기준으로 독자 규칙을 확정한다. 원작의 게임 파일/수치/코드·텍스트를 복제하지 않는다.

Victoria 3의 1.2 자율투자 설계처럼 정부 발주와 민간 자동 투자를 분리한다. 기본 플레이의 피로도를 줄이기 위해 정부가 민간 공장 부지를 지정하도록 요구하지 않는다. 또 완료한 공공 발주를 민간 증축 견본으로 삼아 새 공사를 만드는 것은 허용하지 않는다. 공공 우선순위·지출 한도 화면은 후속 구현 범위다.

## 구현 및 검증 상태

- **실행 경로 확인:** 일간 건설은 기존 자재·고용·현금 원장과 실제 지급 및 WIP를 사용한다. 상세 WorkPackage와 검수는 명시 시나리오에서 기본 건설과 별개로 처리한다.
- **검증 구분:** 25개 불변조건(`DC-INV-01..25`)·45개 인수 항목(`DC-T01..45`)·35개 ADR(`DC-ADR-001..035`) 및 두 합성 예시는 설계 범위다. 현재 문서 갱신이 45개 전체 자동화 인수·장기 성능·실제 역사 사례를 검증했다는 뜻은 아니다.
