# VIC2.5 D-C1~C5 — 건설 시스템 인수시험·불변조건

> **설계 확정 / C++ 시험 구현·실행 전** · `phase-d-construction/1.0` · 2026-11-04  
> 45개 개별 시험 `DC-T01~DC-T45` + 25개 건설 불변조건 `DC-INV-01~25`. [건설 색인](README.md)  
> 상위 `D-D0/DD0-G01..24/DD0-INV01..14` 및 기존 C-D4/POP/CE/CP/CM 회귀를 삭제·대체하지 않는다.

## 1. 시험 원칙

- 모두 **실제 World/StagingWorld/JournalBatch/원장에 연결되는 실행 시나리오**를 구현할 것을 요구한다. 이 문서는 시험의 수치·예상 결과에 대한 **사전 계약**이지 PASS 보고서가 아니다.
- 월별 고정수치 fixture는 `fictional_test_value`와 unit/currency/good/lot/seed/ruleset_version을 명시. 실제 역사자료로 오해하면 안 된다.
- 성공 경로는 월별 `commit_id/JournalBatch`와 인구·금융·소유·재고/설비·시공 결과를 검산. 오류 경로는 **예상한 코드 및 월 전체 Abort**(월 인덱스, ID allocator, 예약/캐시/정렬 해시 포함) 대조.
- 국내/국외·공공/민간·현물/현금/부분준공과 전투·재해/전통 노동을 섞은 가상 3개 지역+2개 정부+건설·광산·제철·은행 기업, 연구소·군사부대, 주거/도로/철도 인프라를 기본 fixture로 둔다.

### 정상적인 경영상/사회적 결과
