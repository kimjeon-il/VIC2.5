# VIC2.5 D-I5 — 산업화·구조전환·기업 생멸·산업정책

> **설계 확정 / C++ 구현·시험 미실행** · `phase-d-industry/1.0` · 2026-11-04  
> 상위: [D-D0](../D-D0_COMMON_CONTRACT.md), D-I1~I4, D-C1~C5, POP-D0~D3, C-E1~E5, C-P1~P5, C-M1~M5. [산업 색인](README.md)

## I5-1. 산업화는 결과이지 단일 점수가 아님

산업화는 **실제 신규 자본재 설치/확충, 경제주체의 고용·교육·숙련 변화, 생산 레시피/에너지·운송망·시장 접근, 기업 금융·제도/정치권한이 시간에 따라 상호작용하며 산업별 생산/고용/생산성·소득구조가 바뀌는 과정**이다. `country_industrialization_level += N` 같은 독립 원본이나 건설/기술 자동 점수는 금지한다.

`IndustrialStructureSnapshot`(조회): `country/region, month, industry_class_id, site_count, employment_from_ledger, output_and_value_added, capital_stock_from_assets, physical_energy/material use, export/import, wages/household_income_distribution, location_cluster_refs, ruleset_hash`. 숫자는 기존 POP/고용/재고/금융/시설/시장·무역 원장과 대조.

- 농업·수공업·공장제/서비스업의 **상대 비중**이 달라지고 신규 고용/이주·소득분배·정부세입/군수공급/정치적 집단 구성이 변하는 경로는 실제 사건과 통계에서 나타난다.
- 농민·자영/예속 노동자가 도시 임금근로자로 바뀌는 것은 `PopulationEvent`/`EmploymentLedger`의 직업/계약·실제 이주/교육/법적 지위 변화로만 처리한다. '공장 한 개 완공'만으로 인구가 새로 생기지 않음.
- 산업화가 항상 복리 성장을 강제하지 않는다. 공업화 실패·농업 생산성 정체·탈산업화/전쟁 산업 붕괴·산업적 불평등·기술정체·금융위기와 회복이 모형의 정상 결과일 수 있다.

## I5-2. 투자·기업 성장·신규 진입

1. `stage8`까지 실제 영업·대출/계좌/이자·시장·비용을 결산. 이익·손실·현금흐름은 다름.
2. `stage9a` 기업/가계/정부의 **다음 월 이후** 설비/사업장 투자·기술 도입/훈련/기업 신규 설립 제안(`IndustryInvestmentProposal`)을 생성. 미래 수요·가격·운임·자원·정치 불확실성 등은 버전 있는 예측 입력.
3. 월 `m+1` stage1에 합법적 실제 자금(보유 예금·신주납입·실행 대출·공공 출자/조달), 재료·노무/설비 서비스·부지/사용권, 법·기술 적합성을 검증하고 임금·재료·투자별 지출을 예약. **미실행 신용/계약·이익예상으로 공장 무료 증설 금지.**
4. 신규/증축 시설은 D-C `ConstructionProject/WorkPackage`·자재/시공/기간/안전검수/준공을 거치고 **차월 stage0부터 유효 생산능력**으로 전환. 설비상품의 재고 수량과 `CapitalAsset` 두 번 계산 금지.
5. 기업의 출자·합병·분사·사업장 소유/운영 이전과 폐업은 C-E3 `OwnershipLedger/FinancialLedger`, C-P 법인/자산권, C-E1 `Firm/ProductionSite`·Employment·Inventory, POP/정치/군사로 이어지는 일관된 사건 묶음.
6. 은행·자본시장 제도가 없는 역사적 경제에서도 자영/가구기업, 사적인 상인신용·관계 금융/현물투자/정부사업 등 **해당 시대의 합법 제도**로 투자가 가능. 현대 은행 시스템·유한책임회사/증권시장 강제 금지.

### 기업의 기대 수익률과 행동

`ProjectedNPV` 및 `expected_operating_margin` 같은 계획/비교값을 계산할 수 있으나 그것은 월간 투자금액을 새로 생성하지 않는다.

- 산업별 경쟁, 노동·에너지/운송비용, 부채/금리·판매수요/재고, 기업의 사회적·정치/법적 지위, 공공의 전략 수요/비영리 의무 등에 따라 투자가 발생·취소·연기될 수 있다.
- 공공/군수 산업은 명시적 유효 예산·조달·권리/정책 사유가 있으면 예상손실에도 운영할 수 있으나 원장에 실제 보조/채무가 있어야 한다.
- 산업의 신규 진입과 기존 기업의 증설/퇴출은 임의 국가별 quota나 개별 공장 레벨 증가 대신 **기업·사업장·설비/시장 사건**으로 집계된다.

## I5-3. 쇠퇴·파산·청산·기업재편

- 제품시장 축소/경쟁/기술대체·현장 유량·채굴경제성 악화/봉쇄, 가파른 임금·연료비 상승/노후시설·질병/전쟁 피해, 금융기관 부실 등이 생산·이윤·현금흐름·부채상환에 영향을 준다. 영업손실/유동성 부족과 법적 부도/기업소멸은 서로 다름.
- `FirmResolutionEvent`는 고용계약 종료/체불·POP 실업/직업 전이, 실제 창고·설비 자산 처분/매각·소유권·담보, 미납 세금/국채/대출·주주 손실/채권자 순위, 유효 산업시설 유지/철거·부지 변경/재활용을 연결한다.
- 공장이 문을 닫아도 설비·토지가 현존하면 `CapitalAsset`는 `idle/retired` 등 상태로 남아 회생/매각/폐기 가능. `FirmId`/`SiteId` tombstone/lineage는 재사용하지 않는다.
- 주가·기업 자산평가 상승은 판매대금/실현 이익과 다르고, 기업 파산이 은행의 모든 예금을 근거 없이 삭제하게 해서는 안 된다.
- 환경/산재·전쟁 피해/노후시설 폐기·재시공은 D-C5·C-M4 및 실제 보험/원장 손실에 따라 처리.

## I5-4. 산업정책과 역사의 제도

| 정책 | 권한/실제 효과·제약 |
|---|---|
| 공공투자·국영화·산업시설 건설 | 유효 C-P 법률·C-E4 예산, 실제 자재/노무/시설 D-C 공사·C-E3 소유권 이전 필요 |
| 보호관세·수입쿼터·수출규제 | C-P/C-E5 통관·실물 선적/계약·관세/해당 원장의 실제 세액과 가격 변화 |
| 생산보조금·구매보장 | 유효 권한·재정채권/지급·실제 상품생산/인도, 보조금만으로 실물 산출 생성 금지 |
| 산업교육·직업훈련·연구 보조 | 실제 학교/연구기관 시설·자금·교원/장비와 POP 교육/숙련 및 D-T 연구/지식 전이에만 효과 |
| 기술이전/특허/면허·표준 | D-T `KnowledgeRegistry`·`SiteTechniqueAssignment`와 C-P 법률·실제 공정/설비·지급 |
| 노동법·안전·환경규제 | POP 적격/노동계약·사업장 안전/생산·환경배출·세금/벌금 의무에 적용 |
| 철도·항만·전력망·주택/보건 | D-C/C-E5의 실제 건설·수송 서비스, POP 주거/의료의 실제 공급 제약 |
| 전시 동원·통제경제 | C-M 군수조달/징발·C-E4 정부지출·C-P 비상권한·C-E2 원자재/시장 예약, 무상 생산 금지 |

- 법률 채택 `m`의 기본 효력은 `m+1` stage0; 이달 사업장 생산·가격/임금·재고/고용·투자에 소급효과 없음. 정책의 시행은 유효 재원/정부·현장 인력/기관 역량이 필요.
- 역사적 정부의 규제·보호무역/길드·농노·식민지/종속권·군수조달·국유화/민영화는 제도/법/소유권의 **시대별 규칙**과 실제 사건으로 구성; 현대적 자유시장이나 보편적 강제 산업정책을 모든 연대에 적용하지 않는다.
- 정책 성공/실패·기업 성장/공장 파산·임금 상승/노동운동은 실효 생산·세수/분배·POP 상태/선거권·정치조직 관계에서 비롯된다. `policy_increase_industry_output_directly(100)` 같은 원장 외부 경제 효과는 금지.

## I5-5. 산업화의 시차·연쇄효과

~~~text
Investment intent (m stage9a)
    -> money + site/permits + contract reservation (m+1 stage1)
    -> actual construction + workforce + machinery purchases (future months)
    -> inspected commissioned asset (stage0 of later month)
    -> real production with resource/energy/labor bottlenecks (stage4)
    -> sales/employment/income/tax/financial settlement (stages5~8)
    -> profits/credit/risk/POP political views (stage9)
    -> demographic/job/migration and war shocks (stage10)
    -> revised investment possibilities (future month)
~~~

- 군수·철도·기계·중간재와 건설업·금융기관은 상호 의존하고, 설비/노동/원료 부족으로 공공·민간 투자가 상호 밀어내기도 한다(crowding-out). 반대로 실효 인프라/교육·시장 확대로 민간 투자 수익 기대가 개선될 수 있다.
- 상품·노동시장/기술 확산/조세·정치사회적 반응은 다른 C/D 분야가 **각자 유일한 원장에** 기록한다. 산업 시스템은 이 결과를 읽어 다음 달 계획에 반영할 뿐 원장 외부에서 실업/정당 지지/은행예금을 임의 변경하지 않는다.
- 지리적 산업 이전·지역격차/도시화는 `Region`·실효 운송 서비스·POP 이주, 실제 토지/공장·가구/고용/계좌 이전으로 처리하며, 행정 경계 변경 자체가 공장을 새로 만들지 않음.

## I5-6. 경기순환·장기회귀 및 운영

- 모델 결과: 산업 흥망·경제 공황·물가폭등·장기 성장둔화·자원 공급 위기·전시 생산붕괴·회복·노동시장 갈등 등은 **정상 결과**일 수 있다. 원본 인구/현금/재고·금융·자산 권리가 유령 창출·실종하지 않는지 별도로 검사.
- 산업 관련 결정론적 예측·부도/신규기업 설립·조달은 `ruleset_version`·stable event id·seed·checked fixed-point arithmetic 및 C-D4 worker 1/N 정렬 규칙을 따른다. 병렬 지역 청산의 결과가 CPU/worker 수로 바뀌면 검증 실패.
- 1,200개월 인구·건설/산업·금융·정치/전쟁 충격의 결합 장기 검증에서 지역산업별 생산/부가가치/실업·재고 부족·기업생멸·불균형/미래재원 오류의 로그를 모두 보고. 성능은 10만/100만 희소 POP 및 다양한 사업장/Recipe·시장·운송 경로에서 실제 계측 후 보고.
- **초기 세부 구현 순서:** I1 분류/활동관계 조회 → I2 원료/유효 레시피·검증된 자원 채취 → I3 설비·공정 선택/실제 기계화·재교육 연계 → I4 지역별 시장·운송/입지 → I5 신규/퇴출·정책/구조변화 → D-V 전분야 인수.
- I2의 `I2-DISPATCH`(비저장 실시간 전력)처럼 상위 C-E1/C-D4 변경이 필요한 경우 명시적 **호환 ADR/버전 증가/회귀** 이전에 사용 금지. 실제 전력 구현 완료를 주장하지 않는다.
