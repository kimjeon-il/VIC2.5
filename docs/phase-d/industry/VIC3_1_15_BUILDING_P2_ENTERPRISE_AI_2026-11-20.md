# VIC2.5 P2 — 기업·시장·투자 AI 실행 경로 (2026-11-20)

> **소스 구현, C++ 빌드/회귀 결과 미확인.** 기존 C/D/E/G 통합 일간 12단계·실물/고용·은행/시장·도급/소유 원장만 사용한다. 원작 Victoria 3의 기업/건물 고정 계수 및 가상 '투자점수'는 복제하지 않는다.

## 범위

| 동작 | 구현 |
|---|---|
| 산업별 예상 채산성 | `enterprise_ai::evaluate`: 실제 `IndustryRecipe` 산출품의 현지 시장 시세, 필수 중간재 시세·현지 실제 재고, 기취업자의 지역별 관측 임금, 확인된 타 지역 G 운송간선의 운임을 반영한 **관측 기반** 배치당 이윤 추정 |
| 신설 | 기존 시나리오에 **실제로 등록된** 미준공 `ConstructionProject` 및 그 사업장/레시피 가운데 기대수익·수요·자재·근로 인력·자금/등록 신용한도를 충족하는 프로젝트의 공정 시작 |
| 증설 | 매월 첫날, 이미 준공된 기존 시공·생산 설계를 기반으로 지역·상품별 가능한 후보를 모두 평가하고, 연간 추정 영업잉여(1년 단순 비교)에서 설비·이자 부담을 고려해 회사별 **하나만 선택**. 유효 원료·시공사 노동/자재 및 법률·설비 조건 없으면 거절. 기존 `Stage::propose_firm_expansion`을 재사용 |
| 전환 | **동일 사업장에 이미 등록되고 기술적으로 호환되는** 복수 `IndustryRecipe`가 있으면 현재 가격·비용·투입 가능성을 비교해 수익성 높은 조합 하나를 생산 계획으로 선택. 연구 미완료·설비개조 필요 시 무상으로 자동 전환하지 않음 |
| 자금·대출 | `enterprise_ai::approved_credit_remaining` 및 `draw_documented_credit`: 기존 G `CreditFacility`의 유효기간·실재고 담보·미사용 한도 및 C 은행부실 여부만 조회. 실제 Stage1 대출 시 반드시 C `lend`와 G 동일 신용계약 원장에 차입·예금/채무가 기록됨 |
| 원료·물류 | 현지 실재고는 Stage3 C `trade`로 실제 비용 지급·재고 이전. 외지 공급은 동일 국가의 실제 소유 재고와 날짜 검증된 G 운송간선의 잔여 처리용량·운임을 확인한 경우에만 *미래 조달 가능성*으로 평가하며, G 계약·운송 없이는 재고를 즉시 이동하지 않음 |
| 노동 | 자동 운영 계획에 필요한 지역 고용을 `Staffing`·기존 POP 근로자/고용/관측 임금으로 시도. 허구 인구·무료 임금 지급 없음. 원료/공정 한계는 기존 Stage4·월 가동용량에서 최종 거부 |
| 채취업 | 현존 `ResourceSite`의 매장량 아닌 월별 채굴유량, 생물량, 직원·설비와 실제 운영 소모품을 차감. 소모재 가격도 이윤판정에 포함 |
| 건설 | Stage1 자금·자재·시공인력 예약 → Stage4 실제 작업 → Stage5 실제 지급 → Stage8 원장 자본화 → 다음 날 유효 실물시설 준공. 담보신용 출처 없이 자동 신규대출/현금·상품 생성 금지 |

## 경계 및 미지원

- 증설 설계를 복제하려면 등록된 역사·시나리오의 기존 완공 설비·시공 원가·생산 레시피가 필요하다. **새 산업·기술의 미지 공장을 무에서 발견해 임의 생성하지 않음.**
- 산림·광산·경작지 확장 등은 실재 채굴권/농지 및 설비·탐사 증명이 필요하므로 원형만 보고 무허가 신규 광산/농장을 생성하지 않음.
- 건물의 전환에 추가 설비·훈련·재공사가 필요한 경우 기존 D-C 공정과 기술 도입을 별도로 완료해야 한다. 호환 레시피 사이의 운영 선택만 자동이다.
- 타 지역 공급망의 경로 *조회*는 원자재 구매·선적·통관의 실행 계약이 아니다. 상품·현금·운임·시간은 G/F 실제 계약과 사용 실적에 따라 결정.
- 연간 기대이익은 **현재가격이 유지된다는 단순 시나리오**이며 수요변화, 가격충격, 장기 전망, 지역별 시장위험의 정확한 예측이 아님.
- 상세 기간별 건설·매장 채굴 효율, 기술별 근로자 적격성, 본사 자율 회사 설립/인수합병, 모든 시기별 실측 인프라 및 전력 급전은 P2의 이 범위에서 완성됐다고 주장하지 않는다.
