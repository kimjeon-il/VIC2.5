# VIC2.5 D-I1~I5 — 산업 시스템 인수시험·불변조건

> **설계 확정 / C++ 인수시험 구현·실행 전** · `phase-d-industry/1.0` · 2026-11-04  
> 25개 산업 불변조건 `DI-INV-01..25` + 45개 인수시험 `DI-T01..45`.  
> 상위 [D-D0 인수시험](../D-D0_ACCEPTANCE_TESTS.md)(14 불변조건/24 시나리오), D-C 25/45, 기존 POP/C-E/C-P/C-M/C-D4 회귀를 대체하지 않는다.

## 검증 원칙/시험세계

- 3개의 가상 Region(A 광산/농촌, B 제조/도시, C 소비시장), 2 Government, 복수 시장과 E5 두 달짜리 운송 간선, 광상·농지/벌채, 광산/제철/직물/식품/전력·연구/건설 업체, 주택/군수 생산시설, POP 직무/교육·기업/가계·은행/세금·실물 자재·설비/구축공사 및 전쟁/기후 충격을 포함.
- `Money`는 통화와 최소단위, `GoodId/Quantity`는 상품별 스케일, `People`은 정수 인구; 시간 `month_index`와 0..11 공개 단계. 테스트 수치는 `fictional_test_value`로만 사용.
- 정상 결과의 재고부족·적자·농작물 실패·광산고갈·기업부도·지역실업/탈산업화는 **원장 정합성 위반이 아니면 PASS 가능한 시뮬레이션 결과**. 잘못된 유령 노동·자원·상품/현금, 공정 이중생산, 불법 조기 가동, 타 단계 미래자재 투입·법률 소급, 멱등성/월 커밋 위반은 **HARD ERROR**.
- 예외 시 예상한 `DI_ERR_*`와 원인 `D4_ERR_*` 매핑·월 전체 `StagingWorld` abort, ID 발행·원장/캐시·예약·month index/해시 그대로 유지. 성공 시 해당 `JournalBatch`의 실제 입력/출력·고용/재정·결정론 해시 검사.
