# POP 데이터 모델 · 인구구성 · 건강

## 1. 모델

```
Pop { pop_id, PopKey, demographics: Map<CohortKey, integer_people> }
PopKey { region, culture, religion, profession, livelihood, wealth_band, legal_status }
CohortKey { birth_month_index, sex, health, functional_limitations, military_status }
```

S0 초기 6개 POP는 예시 데이터로 쓸 수 있으나 개수 제한은 없다. POP 분류 키는 지역·문화·종교·직업·생계유형·자산계층·법적 지위이며, 개별 POP 안에서 출생월·성별·건강·복무 상태별 인원수를 유지한다. POP 객체에 기업 지분, 취업계약, 은행 예금의 별도 진실값을 복제하지 않는다.

`sex`는 모형상 성별 인구구성을 기록하기 위한 분류값이며, 사회적 성역할·법률상 권한·결혼 제도는 별도 정책 데이터로 관리한다. 역사별 노동 참여율과 징병/교육 접근권의 차이를 생물학적 특성처럼 하드코딩하지 않는다.

## 2. 연령

월 단위 `birth_month_index`를 사용하여 연령과 취업·교육·징병 적격 여부를 계산한다. 인구가 5세 구간으로 표시되어도 내부에서는 출생월 조합을 유지할 수 있다. 신생아를 즉시 노동자로 간주하지 않는다. 출생·사망은 사건으로 인구 원장에 기록한다.

실제 출생·사망률 계산과 12개월 시간 경과 자동 연령 이동은 후속 구현이다. 현재 코드는 출생월 데이터와 사람 수의 보존만 지원한다.

## 3. 건강·장애·전투 부상

- `health`: 건강/일시 부상/장기 기능 손상/질병의 최상위 상태. 복합 상병·재활 과정은 `HealthLedger`와 하위 상태에 확장한다.
- `functional_limitations`: 개별 직무에 필요한 능력과의 적합성을 평가하기 위한 마스크. 장애를 전체 직업에 대한 일률적인 고용 금지로 다루지 않는다.
- `military_status`: 민간/현역/예비역/포로·실종. 군인은 전체 인구에 포함되며 민간 노동력과 이중 계산되지 않는다.
- 전투 상태 전이: 건강한 현역 코호트 중 `killed`, `temporarily_injured`, `long_term_impairment`을 구별한다. 사망만 총인구를 감소시킨다. 포로·실종은 별도 상태이며 자동으로 사망 처리하지 않는다.

예시: 현역 1,000명 → 전사 50, 일시 부상 180, 장기 손상 70, 기타 700. 기말 총인구는 950명. 단순 예시 수치이며 역사적 전투 손실율이 아니다.

## 4. 불변조건 및 상태 전이

- `POP 총인구 = Σ 코호트 인구`, 코호트별 인원은 0 이상의 정수.
- `기말 인구 = 기초 인구 + 출생 − 사망 + 순유입`.
- 직업 변경·지역 이동·부상 전이는 해당 인구가 출발 상태에서 정확히 차감되고 도착 상태에 정확히 가산된다.
- `현역 + 예비역 + 민간 + 포로/실종`의 상태 분할을 유지하고 복수 고용을 별도 계약으로 검증한다.
- 장애·부상의 경제적 효과는 능력 요구조건, 치료·보조기술, 법적 권리, 차별, 건강상태를 분리하여 평가한다.
- 자산/채무/예금은 사람 수에 비례해서 무조건 나누지 않는다. 분할된 사람들의 경제적 특성이 불명확하면 명시적인 배분 규칙을 요구한다.

## 5. 구현 상태

코호트·부상/사망·기초 인구 이동은 신규 골격에 구현됐다. 자연 인구 증감, 교육, 건강 회복, 치료, 복지, 장애인의 직업 적합성, 군 복무 인구의 노동시장 연계는 설계만 확정됐다.
