# Phase B — 인구·사회 기초 구현 보고서

기준일: 2026-11-03 · 계약: `pop-design/1.1` · 신규 C++20 구현: `vic25::phaseb`

## 목적과 범위

기존 `vic25::Pop` / `MonthlyPipeline`의 초기 스캐폴드를 삭제하거나 이전 엔진의 복원본이라고 주장하지 않는다. 이 단계에서는 신규 `World` 안에서 D0~D3 계약의 **인구 단일 원본과 월별 인구·사회 기초 연산**을 실제 실행할 수 있도록 구현한다. 기존 금융·상품·시장 원장과의 완전한 트랜잭션 통합은 후속 작업이다.

|---|---|---|---|

## 데이터 소유와 변경 경계

- `Demographic`, `Economic`, `Household`는 공유할 수 있는 분류/프로필이며 **인원수는 `Slice.count`에만** 보유한다. 가구수 추정치는 주민 인구와 별개다.
- 셀에는 `demographic_id`, `economic_id`, `household_id`, `partition_id`가 존재한다. 복수 고용주가 동일 인구를 중복 채용하지 않도록 partition을 분리한다.
- 성별은 출생과 정책별 교육 접근을 구분하는 입력이며 법적 제약은 `LaborRule/JobRequirements`로 명시한다. 직무 적합성은 장애 여부 자체가 아니라 요구 능력·기능제약·편의제공으로 판단한다.
- 실업이 직업 분류를 없애지 않으며, 아동의 직업은 `not_assigned`. 노동 가능 연령이 되면 `unskilled_worker/wage/unemployed`로 전환된다.
- 출생·사망과 직업·병역·질병 전이는 `Event`에 기록한다. 실패할 수 있는 외부 명령에는 `apply_once(external_id, ...)`를 사용하여 재전송 중복/부분 실패를 방지한다.
- 인구·고용 원장을 바꾸는 월별 처리는 `World`의 사본(staging)에 수행하고 불변조건과 인구 항등식 확인 후 한 번에 확정한다. **이 원자성은 Phase B World 범위**이며 기존 S0 Financial/Inventory 원장까지 포함하지 않는다.
- 역사적 입력이 5세·연령 구간뿐이면 추정 출생월과 출처를 생성하는 데이터 로더가 별도로 필요하다. 현재 입력 API는 이미 월별 출생 코호트로 변환된 정수 인원을 받는다.

## 월별 12단계와 경제 모듈의 경계

기존 `vic25::MONTH_STAGES`의 12단계 순서를 재사용한다.

- 단계 2 (`labor_clearance`): 설정된 **새 채용 슬롯**에 대해 임금·자격 순으로 배치. 실물 기업의 이윤 계산은 아직 없다.
- 단계 10 (`pop_demography_and_health`): 사망 → 출생 → 질병·부상·회복 → 진학/숙련 → 경제적 성인·퇴직 전환 → 외생 이주.
- 다른 단계: Phase B 단독 실행에서는 의도적으로 아무 작업도 하지 않는다. 기업 회계·재고·실물 소비는 기존/후속 경제 모듈에서 담당한다.
- 월말 `month_index`를 증가시키며, 12단계 중 오류가 나면 staged state를 폐기한다. 월말 기준 새 출생아가 해당 월에 노동자가 되는 일은 없다.

## 정밀도와 해석

- 인구 수량은 64-bit 정수이며 rate는 월별 100만 명당 노출 인원수(ppm); 소수인원 잔여량은 사건/셀별로 누적하고 분할 이동 시 잔여 일부도 이전한다.
- 전역 난수 호출 없이 결정론적 정수 기대값 계산을 사용한다. 이 모형은 소규모 인구의 *확률적 변동성*까지 재현하지 않으므로 필요 시 이벤트별 난수 스트림을 추가한다.
- 예제의 가임·사망·학력·산업재해 계수는 **설명용 가상 수치**이며 연구자료로 검증되거나 역사지리 범위에 맞춰 보정된 값이 아니다.
- 1세/출생월 정보가 정확하지 않은 역사적 입력과 일부 복잡한 다중 장애 유형에는 추정·모형 단순화가 필요하며, 이를 실제 기록처럼 표기해서는 안 된다.
- 현 구현은 `std::map`과 월별 `World` 전체 복사로 재현성과 롤백 검증을 우선했다. 대규모 실제 시나리오는 변경집합(COW) 및 SoA로 개선해야 한다.

### Phase B 인수 판정

**Phase B의 기본 인구·사회 연산과 연동 시험 구현 완료**. 단, D0~D3 문서 전체(은행/재고/기업 원장의 원자적 결합, 저장 형식, 멀티스레드 재현성) 및 S0-A~D 실물경제 전체 완료는 아님. 엔진 전체가 POP 중심으로 전환되었다고 간주해서는 안 된다.
