> **현행 기본 플레이 범위:** [건설](phase-d/construction/README.md)은 자재·인력·공사비·준공을 중심으로 합니다. 허가·검수·재시공은 시나리오가 명시적으로 선택한 경우에만 쓰며, 일반 공사·자동 증설·기본 UI의 요구사항이 아닙니다. [학교](phase-i/I-E1_EDUCATION_SERVICES_ATTAINMENT.md)는 운영 인력·가용 정원과 교육법이 집계 교육 효과에 영향을 주는 범위를 유지합니다. 학생별 등록·배정·출석·수업량 누적은 보류하며 현행 구현·인수 목록에 넣지 않습니다. 아래의 S0 단계 및 과거 Phase C 상태 기록은 이 범위를 넓히지 않습니다.

> **금융·물류·전쟁 기본 범위:** 은행은 예금·대출·상환·부실·파산을 단일 원장으로 처리합니다. 담보부 신용의 자동 인출은 명시적 시나리오만 선택할 수 있고, 이미 체결된 채무는 기존 지급 순서를 따릅니다. 운송 용량·운임·도착 시간, 자동 환적, 전선·보급·봉쇄는 유지합니다. 화물별 보험·환적 관리, 부대별 전술, 전 노선의 실측 운임 입력은 기본 플레이나 첫 캠페인 인수 조건이 아닙니다.

> **지도 없는 핵심 산업 정비:** 기본 생필품 수요는 지역의 기존 식량·의류 시장을 사용하고, 없으면 실제 가공식품·의복 시장을 사용합니다. 재고·거래의 품목 ID는 합치지 않으며, 시나리오의 명시적 장바구니·구매가 있으면 같은 품목군의 기본 수요를 중복 생성하지 않습니다. 공장과 채굴의 동일 품목 투입량은 합산해 생산 가능량을 판정합니다. 식품·방직공장의 임금·원천징수·실물 소비와 공구 부족 시 채굴 중단·재실행을 검증했습니다. 일반 공사는 시공사의 가용 현금으로 지역 시장에서 다음 작업 단위의 부족 자재를 사며, 실제 작업은 그다음 날부터 자재·인력·공사비에 맞춰 진행합니다. 철과 석탄으로 생산한 철강의 구매·소비·준공, 같은 재고의 이중 배정 방지, 자재를 구할 수 없는 앞 주문이 뒤 주문을 막지 않는 경우를 확인했습니다. 타 지역 자재는 실제 운송이 필요하며, 공급자 여러 곳의 공사용 예약분을 뺀 잉여를 쪼개 사는 기능, 전 산업 사슬과 여러 국가의 장기 충격 회복은 이번 범위가 아닙니다.

> **지도 없는 경제 순환·회복 검증:** 자동 레시피 선택은 생산방식만 고르며, 신규 고용은 기존의 지역 임금·수요·가용 현금 검사를 거치는 한 경로에서만 결정합니다. 시험 지역에서 실제 임금으로 상품을 사고 판매대금으로 공사를 완료한 뒤, 미취업 주민을 새로 고용해 임금과 세수를 늘리는 흐름을 확인합니다. 이 시험에서는 자동 채용을 끄면 공장이 준공돼도 신규 인력이 필요한 생산은 늘지 않습니다. 두 시험 지역의 유료 운송로가 끊기면 도착 대기분을 소진한 뒤 생산·판매가 줄고, 대체로의 화물이 실제 도착한 뒤에만 생산·판매가 재개되는지 검증합니다. 개별 기업 주문장이나 실제 세계 교통망을 추가하지 않으며, 두 시험은 세계 캠페인 인수를 대신하지 않습니다.

> **D0~D3 설계 단계 완료 (코드 이식 전)**: [새 POP 설계 색인](pop/README.md)과 [인수 조건](pop/ACCEPTANCE_TESTS.md)을 참조. 구현은 기존 S0-P1 이전에 3계층 레지스트리/PopulationSlice → 상태 전이 → staging/rollback 순서로 진행합니다. 아래 S0-P1~P6은 구현 단계이며 아직 완료되지 않았습니다.
