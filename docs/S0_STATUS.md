# S0 결과물 및 근거 현황

**기준일:** 2026-11-03. 구분: `확정된 설계` / `신규 구현·로컬 테스트` / `이전 대화의 기록(원본 미확보)`.

## 이전 S0 기록(원본 미확보)

과거 작업 대화에서 S0는 C++20, 지도 없는 소규모 가상국가(3개 지역, 6개 POP, 8개 상품, 24개 기업), 월별 시뮬레이션, 장기 검증을 지향했습니다. 이후 S0-A 금융·자금순환, S0-B 노동시장, S0-C 가격·생산, S0-D 장기 검증을 진행하기로 결정했습니다. S0 v0.2의 은행·예금·대출·설비·생계생산 구현 및 100년 테스트에 관한 보고가 있었으나, 이 저장소 작업 시 실제 ZIP/로그/소스 원본을 확보하지 못했습니다.

따라서 당시의 성공/실패 또는 구현 정도를 **현재 새 저장소에서 재현해 검증했다고 주장하지 않습니다.** 원본을 확보하면 별도 `legacy/` 아래 출처와 검증 수준을 기록한 뒤 이식/비교합니다.

## 이번 작업에서 새로 확보한 것

- `include/vic25/population.hpp`: POP 기본 키, 코호트, 정수 인구 전이, 전투 사망/부상 분류.
- `include/vic25/ledgers.hpp`: 고용/지분/재고 원장과 복식부기 기본 원장.
- `include/vic25/monthly.hpp`: 월별 12단계 일정 정의 및 훅.
- `src/main.cpp`, `tests/test_core.cpp`: 실행 예제와 스모크 테스트.
- 이 폴더의 설계 계약과 테스트 계획.

## 테스트 범위

GCC 14.2, CMake 빌드 성공, CTest 단위/스모크 테스트 한 개 통과. POP 1,000명 중 50명 사망·180명 일시부상·70명 장기손상 예제에서 기말 인구 950명 확인. **100년 경제 시뮬레이션을 실행한 것이 아닙니다.**
