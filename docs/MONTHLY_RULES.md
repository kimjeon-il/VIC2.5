# 월별 연산 계약 (S0-POP v1.0)

월 = 원자적 거래 묶음. 개별 계산의 입력 기준 시점을 고정하고, 같은 달의 판매 수익으로 그 이전 단계의 생산비를 소급 조달하지 않는다. 의도된 경제적 충격과 회계 정합성 오류는 구별한다.

## 12단계

| 순서 | 단계 | 주요 입력 → 결과 |
|---:|---|---|
| 0 | opening_snapshot | 월초 POP·재고·가격·재무 상태 고정 |
| 1 | planning_and_credit | 기업 가동·투자 계획, 정부 예산, 대출 승인 |
| 2 | labor_clearance | 직업별 구인·자격·고용·임금 및 임금 지급재원 확보 |
| 3 | intermediate_goods | 원자재 구매 및 실제 수량 이전 |
| 4 | production | 설비·투입·노동력 제약에 따른 생산 |
| 5 | wages_and_transfers | 임금·세금 원천징수·급여·보조금 실제 지급 |
| 6 | pop_consumption_plans | 소득·가용 예금·자급소비 기반 POP 수요 계산 |
| 7 | final_goods_market | 가계 소비, 정부조달·건설재 거래 및 재고 청산 |
| 8 | closing_accounts | 손익·이자·세금·채무 상태·현금흐름 결산 |
| 9 | saving_and_investment | 예금·출자·배당 선언·다음 달 투자계획 |
| 10 | pop_demography_and_health | 소비 충족률·영양·건강·출생·사망·이주·직업변화 |
| 11 | repricing_and_validation | 차월 가격 결정, 원장 일치·재현성 검사, 월말 커밋 |

**지급시점**: 당월 받은 임금·정부이전소득은 당월 소비 가능. 월말 선언한 배당은 원칙적으로 다음 달 지급. 설비투자는 자금·중간재·건설 기간을 거친 다음 달 이후 가동. 출생·사망·이직은 당월 말 확정하여 다음 달 노동공급에 반영.

## 노동·생산

기업별 직종별 채용 상한은 `min(기업 구인계획, 지역의 자격 갖춘 가용 인력, 기업의 임금 지급재원에 의해 고용 가능한 수)`이다. 노동시장은 여러 기업이 같은 사람을 중복 채용하지 않도록 집합적으로 청산한다.

생산량 상한은 `min(설비 생산능력, 실제 노동 공급으로 가능한 생산, 각 필수 중간재 투입 상한)`을 사용한다. 자급농·자영업 생산은 현금 임금만으로 환산하지 않고 현물 소비와 시장 판매를 따로 기록한다.

## 소비·시장

필요량 `N[p,c] = population[p] × per_capita_need[p,c]`. POP는 욕구별 가용예산을 배분하고, 상품별 수요량을 `planned_purchase[p,g] = budget[p,g] / price[g]` 기준으로 산정하되 대체재 선호·공급 한도·자급생산을 반영한다. 실제 체결량은 `min(자금이 확보된 구매 주문량, 판매 가능 재고량)`을 넘을 수 없다. 미체결 주문은 실제 구매가 아니다. 필수 욕구의 대체상품 재배분은 최대 두 차례 실시한다.

## 가격 (S0 독자 계산식 — Victoria 3 원본 공식 아님)

```
next_price = price * exp( clamp(
    alpha*(demand - supply)/max(demand,supply,eps)
  + beta*(target_stock - stock)/max(target_stock,stock,eps),
    -delta, +delta))
```

`demand`: 실제 지불 가능한 수요, `supply`: 인도 가능 매도량, `stock`: 월말 실제 재고. `alpha/beta/delta`는 게임 데이터로 관리하고 S0-D에서 보정한다. 수요·공급 모두 0이면 별도 휴면시장 로직을 적용한다. 한 달의 거래 가격은 이미 고정된 당월 가격이며 차월 가격을 소급 적용하지 않는다.

## 금융

기업은 월초에 가진 운전자금 또는 *실제 실행된* 신용으로 임금·중간재를 조달한다. 이익은 현금이 아니며, 배당은 금전 이전이 일어날 때만 POP에 지급된다. 모든 거래는 계정별 차변·대변으로 기록하고 은행대출이 예금을 생성할 수 있음을 인정한다. 별도 사유 없는 화폐 생성·소멸 금지.

## 구현 경계

이 파일은 **연산 계약**이다. 현재 `MonthlyPipeline::advance()`는 단계 순서를 노출하고 훅을 호출할 뿐, 위 경제 연산을 실행하지 않는다. 실제 시장·기업·정부·POP 계산은 후속 단계에서 연결한다.
