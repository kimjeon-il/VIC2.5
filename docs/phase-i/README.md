POP 인구·EducationProfile 단일 원본, 기존 C-E/P·D-T·E 및 CommitDay/달력상 월말 규칙 준수. 사회지표는 파생값이며, 교육은 학교 운영 인력·가용 좌석·교육법과 기존 POP 집계 학력 및 숙련만 사용한다. 학생 등록·배정·출석·수업량 누적은 기본 범위가 아니다. **언어는 문화의 정적 하위 속성**이며 별도 언어 숙련/학습·언어별 POP 인원 원장은 폐기한다. **종교는 POP 구성 정보로 보유하되 관련 법률·제도·실제 집행/기관 활동에 따라서만 사회적 차등효과**를 발생시킨다. Phase I 전체 통합 수락시험은 미실행이다.
