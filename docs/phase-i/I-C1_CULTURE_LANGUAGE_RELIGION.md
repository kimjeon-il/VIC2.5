# I-C1 — 문화 중심·언어 하위 정보·종교 법률 연동 상세 설계

> phase-i-culture/1.1 · SPECIFIED / NOT IMPLEMENTED · 상위: I-D0, POP-D0~D3, C-P2/P3, I-E1, E-D0
>
> v1.0에서 지나치게 세분화했던 개별 POP 언어 숙련/학습과 상시 개종·종교 전파 계산은 기본 범위에서 폐기한다. 문화는 제한적 동적 요소, 언어는 문화의 하위 정보, 종교는 법률·제도·실제 집행에 따른 조건부 속성으로 축소한다.

## C1-1. 정보·원본 소유권

| 항목 | 기존 정본 또는 데이터 | 실제 처리 |
|---|---|---|
| 문화별 인구 | POP DemographicCohortKey.culture_id / PopulationSlice.count | 인원 가중 집계, 드문 실제 전이는 POP-D2 |
| 대표·보조 언어 | CultureDefinition.primary_language_id / optional other_language_ids | **문화의 정적 하위 메타데이터**. 언어별 인구/숙련도 원장 없음 |
| 공용어·학교 교육언어 | C-P 법률 / I-E1 EducationProgram.instruction_language | 행정·교육 접근조건의 정책 입력. 개별 언어 학습·진도 계산 없음 |
| 종교별 인구 | POP DemographicCohortKey.religion_id | 구성비 조회 및 종교 관련 법률의 대상 판단 |
| 종교 관련 특권·차별·중립 | C-P2 LegalNorm / PolicyProvision / RuleEvaluation / 유효 관할·집행 | 해당 법률과 실제 집행을 통해서만 사회적 차등효과 발생 |
| 실제 고용·수입·학력·정치 | C-E/C-P/I-E1 및 실제 운영기관·시설 원장 | I-C1이 별도 보너스·재무·정치 원장을 생성하지 않음 |

한 문화는 복수 언어를 가질 수 있고 여러 문화가 동일 언어를 사용할 수 있다. 문화와 언어를 동일시하지 않되, 언어를 독립적인 POP 분류키나 동적 시뮬레이션 대상으로 삼지 않는다. 종교 없음/미상/불명과 실제 0명을 구별하고 역사적 분류의 출처를 유지한다.

## C1-2. 문화의 최소 동적 규칙

1. 이주·세대교체·장기 지역사회 변화 및 실효 교육·차별정책의 영향으로 **문화 정체성 변화가 실제 발생한 인원만** POP-D2 사건으로 전이한다. 변화가 없는 대부분의 POP는 연산/전이하지 않는다.
2. 문화별 지수나 국가별 동화 포인트, 모든 POP 간 문화 접촉 그래프, 언어별 학습 진도·숙련도 프로필을 만들지 않는다. 실제 전이 원인·시점·데이터 품질은 보존한다.
3. 공용어/교육언어 정책이나 다른 언어로 진행된 수업은 문화 ID 자동 변경 또는 문해율 자동 증가를 뜻하지 않는다.
4. 국경·행정구역·군사 점령 변경만으로 문화·종교를 교체하지 않는다. 실제 변경 시 출발·도착 셀 인원, 가구/고용·자산·교육 참조를 POP-D2로 보존한다.
5. 문화·종교 자체에 타고난 기술·생산성·군사·정치 성향 보너스를 부여하지 않는다.

## C1-3. 종교는 법률·제도에 따라 사회적 영향이 달라진다

종교는 **인구의 구성 속성**이지 독립적인 상시 변화 엔진이 아니다. 차등효과의 유일한 기본 경로는 다음과 같다.

종교 식별 → 유효한 국교/종교의 자유/권리·의무·특권·차별 관련 법률·관할 → 실제 집행기관·교육시설·조직/예산 → 기존 고용·교육·조세·정치 원장의 결과.

- **국교 및 법률상 차별:** 종교별 공직 접근, 교육기회, 세금, 종교기관 운영·공적 혜택 등의 조건이 실제 법률/행정 규범에 있다면 대상 POP와 관할·효력시점에 한정하여 적용한다.
- **정교분리 및 법적 중립:** 종교 ID 자체에 따른 고용·소득·교육·정치충성도 보너스/패널티는 0. 다만 실제 종교 단체·학교·자선 조직이 있다면 다른 단체와 마찬가지로 실재하는 자금·인력·권한·서비스·조직 활동을 통해 영향 가능.
- **법과 실효의 차이:** 법률만 제정하거나 폐지했다고 실제 학교·기회·자산·권리·사회적 태도가 즉시 전면 변경되지는 않는다. C-P2 법적 자격과 집행 실적, 기타 원장 거래/행정 역량을 구분한다.
- **시대별 중요도:** 특정 시대·국가에서 국교·종교별 신분 차별·권리 제한이 강하면 실제 영향이 크고, 중립적 제도 아래에서는 직접 영향이 거의 없을 수 있다. '19세기 종교 +X / 현대 종교 -Y' 같은 전역 고정 보너스 금지.
- **종교 변경:** 월별 자동 개종률·종교 전파·신앙강도·종파 경쟁·종교별 갈등점수 시스템은 구현하지 않는다. 필요한 역사 사건 등 근거가 있는 드문 종교 변화만 POP-D2 인원 보존 전이로 처리한다. 종교법이 바뀌었다고 자동 개종시키지 않는다.
- 실제 종교 관련 정치운동·사회갈등의 발생과 규모는 C-P3가 법적 권리/차별·조직·자원·구체적 사건을 기반으로 계산한다. I-C1은 종교 인구수로 급진화나 정당지지율을 직접 조정하지 않는다.

## C1-4. 월별 12단계 연계

| Stage | I-C1의 역할 |
|---|---|
| 0 | POP 문화·종교, 문화 언어정보, C-P의 유효 공용/교육언어·종교법과 관할을 동결 |
| 1~4 | 유효 정책·교육/기관의 자격·시설·노동·서비스를 기존 영역에서 판단; 별도의 언어학습·상시 개종 단계 없음 |
| 5~8 | 실제 종교 관련 법률이 필요한 세금·교육/기관 지원·고용·복지를 타 분야 원장으로만 처리 |
| 9 | 법률·학교 언어 등 정책개정 승인; 통상 다음 달 0단계 발효 |
| 10 | 드문 문화·종교 실제 변화만 POP-D2 인원 보존 전이; 강제/일괄 변경 금지 |
| 11 | POP 인원·이력·법률 효력/관할·중복효과 및 저장/결정론 검증 후 월말 단일 커밋 |

Stage10에서 발생한 새 문화·종교 전이는 이미 종료한 Stage2/4에 소급 적용하지 않는다.

## C1-5. 최소 읽기 API와 예외적인 전이

- GetCultureComposition / GetReligionComposition(scope, month, snapshot) → PopulationSlice 기반 인원·비율·출처 조회.
- GetCultureLanguageMetadata(culture_id, catalog_version) → 문화에 종속된 대표/보조 언어 코드; POP 숙련도와 학습 진도를 반환하지 않음.
- ResolveReligionApplicableRules(religion_id, scope, month, snapshot) → C-P2 규칙·관할·효력·실제 집행 근거의 **조회**. 법률 판정의 원본은 C-P2.
- ProposeCulturalTransition(slice_id, count, cause_refs, stage10) → 근거가 있는 경우에만 POP-D2 전이를 요청.
- ExplainCultureReligionEffects(scope, period, snapshot) → 법률·기관·실제 경제/교육/정치 결과의 원본 사건 경로 표시.

미지원/폐기: LanguageCompetenceProfile, LanguageLearningOutcome, GetLanguageCompetence, ProposeLanguageProgress 및 개종·종교전파 월별 루프/종교별 정서 포인트.

## C1-6. 수락 시나리오 (I-C1-T01~T10)

| ID | 기대 결과 |
|---|---|
| T01 | 문화의 언어 코드 조회만으로 추가 POP 숙련/학습상태 생성하지 않음 |
| T02 | 복수 문화의 동일 언어 및 한 문화의 복수 언어 지원·인구 분할 없음 |

| T09 | 상시 개종률·언어 숙련/학습 계산·종교별 선천적 정치성향 없음 |
| T10 | 동일 시드/세이브/워커·대규모 희소 POP 캐시 재현성 (향후 실측) |
